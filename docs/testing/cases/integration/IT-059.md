# Ignored events are logged when the include-ignored option is enabled

## Scenario

For deep debugging, an operator can opt in to recording every event Stripe sends, including ones the plugin ignores. This verifies that turning on the include-ignored setting causes ignored outcomes to be written and read back with their status intact.

## Steps

1. Start with the webhook log reset.
2. Turn on the include-ignored setting.
3. Record an ignored outcome for a sample event.
4. Read the log entries back.

## Expected result

At least one entry is written and the first entry's status is ignored, confirming opt-in logging captures ignored events.

## Edge cases

- This is intended for short diagnostic windows; the setting warns to enable it only when inspecting all Stripe traffic.
