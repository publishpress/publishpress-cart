# Nested Account Tab Blocks Show Sample Data In Block-Editor Preview

## Scenario

The Account Orders block must still show sample placeholder orders when it is nested inside the Account Navigation and Account Tab blocks during a block-editor preview. This verifies that the preview behavior carries through the nested blocks, so an editor previewing an Orders tab sees representative data rather than the current customer's real orders.

## Steps

1. Sign in as a customer who has real orders.
2. Preview an Orders tab in the block editor, with the Account Orders block nested inside the Account Navigation and Account Tab blocks.

## Expected result

The preview shows sample placeholder orders even when the block is nested, and the customer's real orders are not shown.

## Edge cases

- Skipped if the temporary customer cannot be created.
