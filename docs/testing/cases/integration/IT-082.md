# Account Page Builder Supports Native Padding And Margin Styles

## Scenario

The Account Page Builder must honor WordPress's native spacing controls, applying the author's configured padding and margin to the rendered account layout.

## Steps

1. As a logged-in customer, render the Account Page Builder with padding set on all four sides and a top and bottom margin, containing the Account Navigation.

## Expected result

- The rendered account layout reflects the configured padding on every side and the configured top and bottom margins.

## Edge cases

- Skipped when a temporary account customer cannot be created.
