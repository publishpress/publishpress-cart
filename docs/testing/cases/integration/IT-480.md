# Sync leaves a manual refund that does not match Stripe alone

## Steps

1. Set up the same two orders, but with a manual refund of $20.00 and a refund amount of 20.00.
2. Stripe fully refunded each $39 charge with one refund.
3. Sync both orders twice, as above.

## Expected result

The refund log and the refund amount don't change, and the order stays refunded. The payment method becomes "stripe". The order log has "Stripe refund re_... (39.00) was not recorded because the manual refund total (20.00) is different. Check the refunds in Stripe and update this order." once. No integrations run, no email is sent, and every Stripe request is a GET.
