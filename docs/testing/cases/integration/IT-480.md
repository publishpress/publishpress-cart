# Sync leaves a manual refund that does not match a partial Stripe refund alone

## Steps

1. A refunded order migrated as "cod" has a pi_ transaction ID, a manual refund of $20.00 and a refund amount of 20.00. One order is a one-time order; the other belongs to a subscription.
2. Stripe partly refunded each $39 charge: one refund of $10.00.
3. Run order-level Sync with Stripe on the one-time order and sync the subscription invoice of the other order. Do both twice.

## Expected result

Order-level sync returns "Order synced. The refund needs a check: see the order log." The refund log and the refund amount don't change, and the order stays refunded. The payment method becomes "stripe". The order log has "Stripe refund re_... (10.00) was not recorded because the manual refund total (20.00) is different. Check the refunds in Stripe and update this order." once. No integrations run, no email is sent, and every Stripe request is a GET.
