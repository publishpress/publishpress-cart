# Only an editor of the product can preview an embed layout before saving it

## Scenario

The admin live preview asks for a layout with `ppcart-embed-layout` before the
product is saved. A visitor who adds the same query arg must still get the
saved layout.

## Steps

1. Save the 2-step layout on a product.
2. Render the shell with `ppcart-embed-layout=standard` as a visitor.
3. Render it again as an administrator.

## Expected result

1. The visitor gets skin `2-step` and the `ppcart-embed--layout-2-step` body class.
2. The administrator gets skin `normal` and no layout class.

## Edge cases

- An unknown layout value is ignored and the saved layout applies.
