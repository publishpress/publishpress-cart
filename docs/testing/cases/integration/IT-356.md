# Email modal preview reads TinyMCE body via canonical ppcart editor id

## Scenario

Settings email template modals render WP editors with `ppcart-{optionId}` ids.
`ppcart-settings.js` must look up TinyMCE content with the same prefix when
building the email preview AJAX payload.

## Steps

1. Render `ppcart-admin-field-editor.php` for a representative email body
   option id.
2. Assert the emitted editor `id` is `ppcart-{optionId}` and not `sc-{optionId}`.
3. Assert `ppcart-settings.js` builds `editorId` as `'ppcart-' + optionId` when
   reading TinyMCE content for preview/reset.

## Expected result

PHP and JS agree on the canonical TinyMCE editor id prefix for email template
fields. Preview and reset flows can read the live editor body.

## Edge cases

- Hard cutover only; no Compatibility Mode JS aliases for leftover `sc-` ids.
- Pro must match Free TinyMCE id prefix and jQuery data keys.
