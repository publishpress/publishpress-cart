# Product notification sanitizes personalized HTML at send time

## Scenario

Product-notification templates are sanitized when saved, but customer merge
tags and the downloads shortcode add data later. Text merge tags are
HTML-escaped at insert. The completed HTML still passes through the
transactional-email allowlist immediately before delivery.

## Steps

1. Create an order with markup in the customer name.
2. Build a product-notification email whose body contains `{customer_name}` and
   allowed email markup.
3. Inspect the returned body.

## Expected result

Customer script and img payloads are entity-escaped (`&lt;script&gt;`,
`&lt;img …&gt;`), so they are not live tags. Supported email markup, including
links, inline style, and paragraphs, remains.
