# Scalar diagnostic context values are retained in the log entry

## Scenario

When recording an outcome, callers attach diagnostic context such as charge ids, amounts, and flags to help operators triage. This verifies that simple, single-value context survives sanitization and is stored with the entry.

## Steps

1. Start with the webhook log reset.
2. Record a webhook outcome that includes a simple diagnostic value (a charge id) in its context.
3. Read the first log entry and inspect its context.

## Expected result

The stored context keeps the charge id, confirming simple diagnostic values passed by the caller are sanitized and persisted.

## Edge cases

- Entries with empty or invalid keys are dropped during sanitization; only non-empty keys with simple, single values are kept.
