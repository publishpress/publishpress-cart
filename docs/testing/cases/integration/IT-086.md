# Account Tab Script Normalizes Hash Tab Links

## Scenario

The public account tab behavior must work out which tab to show from the link's hash target rather than its full address, so clicking a tab link reliably reveals the matching panel.

## Steps

1. Inspect the public account tab behavior.

## Expected result

- The account tabs identify the target tab from the link's hash and reveal the matching panel.
- The earlier behavior that relied on the link's full address is no longer used.

## Edge cases

- The account tab behavior is located within the plugin before it is inspected.
