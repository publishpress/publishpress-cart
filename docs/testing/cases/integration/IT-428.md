# A legacy StudioCart subscription uses its Stripe subscription ID

## Scenario

Subscriptions migrated from old StudioCart versions keep StudioCart's own ID (for example 61981d21edda0) in subscription_id, and the Stripe ID in stripe_subscription_id.

## Steps

1. Create a subscription with a StudioCart ID in subscription_id and a sub_ ID in stripe_subscription_id.
2. Create a second subscription with sub_ IDs in both fields.
3. Read each subscription's Stripe subscription ID.

## Expected result

The first subscription returns its stripe_subscription_id. The second returns its subscription_id.
