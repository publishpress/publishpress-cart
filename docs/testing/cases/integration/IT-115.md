# FSE product template helper honors filtered product post types

## Scenario

Sites can register additional product-like content types through the product-type filter, and the product template feature must respect them so custom product types also get the block template. The list of product types must reflect anything added through that filter.

## Steps

1. Load the plugin.
2. Add a custom product type through the product-type filter.
3. Read the list of product types the product template applies to, then remove the filter.

## Expected result

The list of product types includes the custom type added through the filter, proving the feature merges in filtered product types rather than only using the built-in cart product type.

## Edge cases

- Skipped when the product template feature is unavailable.
