# Checkout block shows the "Due Today" label for recurring plans

## Scenario

For recurring/subscription products, the checkout must show a "Due Today" line so the buyer can see the amount charged now versus the recurring amount. This verifies that a recurring product shows that label by default, with no custom wording set.

## Steps

1. Add a Checkout Form block for a configured recurring product, leaving the wording at its defaults.
2. View the page on the frontend.

## Expected result

The checkout shows the default "Due Today" line for the recurring plan.

## Edge cases

- Requires a configured recurring product to be available.
