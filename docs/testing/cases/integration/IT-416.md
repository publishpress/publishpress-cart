# A cancellation scheduled in Stripe marks the subscription pending cancellation

## Scenario

A customer cancels in the Stripe portal, or an admin cancels in the Stripe dashboard, at the end of the period. Stripe sets `cancel_at` and keeps the subscription active. Cart must show it as "Cancellation Pending", the same as its own cancel-at-period-end action.

## Steps

1. Start with an active Stripe subscription that has no cancellation.
2. Sync a Stripe subscription that is still active, with `cancel_at` set and `canceled_at` set to the day of the request.
3. Check the stored status, `cancel_date`, `cancel_at`, and next bill date.

## Expected result

The status stays active. `cancel_date` is the day of `canceled_at`. `cancel_at` is stored, and the next bill date is empty. The subscription now matches the "Pending cancellation" filter.

## Edge cases

- When Stripe gives no `canceled_at`, `cancel_date` is the day of the sync.
