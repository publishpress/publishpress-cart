# Importing a payment that is already an order is refused

## Steps

1. Import a charge as a one-time order for a product.
2. Import it again, by its ch_ ID and by its pi_ ID.
3. A checkout order stores a PaymentIntent ID. Import that PaymentIntent's charge.

## Expected result

The first import creates an order. The others are refused and name the existing order.
