# Legacy tracking meta is not executed and the admin notice can be dismissed

## Scenario

Products that still store `_ppcart_tracking_main` or `_ppcart_tracking_lead` must not have that markup printed on `wp_footer`. Posting those keys through the product metabox save path must not change the stored meta. Admins on a Cart screen see a dismissible notice listing affected products.

## Steps

1. Create a product with a unique legacy tracking snippet in post meta.
2. Run the footer tracking callback and the metabox save with that snippet posted.
3. Render the legacy-tracking notice on a Cart settings screen, then after per-user dismissal.

## Expected result

The snippet is absent from the inline script, metabox save leaves the original meta unchanged, the notice lists the product, and a dismissed notice prints nothing.

## Edge cases

- Notice is hidden for users without `manage_options`.
