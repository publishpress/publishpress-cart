# An order with a malformed child order row still loads

## Scenario

Older or imported orders can store a child order row as a serialized string, a plain string, or an array without an ID. Loading the order must not stop with a fatal error, for example on the Orders list.

## Steps

1. Create a parent order with one valid child row, one child row stored as a serialized string, one plain string row and one row without an ID.
2. Load the order data and its child orders.

## Expected result

The valid row and the serialized row load as child orders. The rows without an order ID are skipped. No error occurs.

## Edge cases

- A bare numeric row still loads as a child order ID.
