# PayPal Standard cart payment

## Scenario

PayPal Standard sends the buyer to PayPal and back. A cart order is complete
only when PayPal confirms the payment of that order. Buy now with PayPal must
keep its own product data and URLs.

## Steps

1. Set PayPal to the redirect experience and the cart confirmation to a
   redirect URL. Submit a cart with PayPal.
2. Confirm the order from the browser.
3. Run the PDT check with a transaction that names another local order, another
   amount, another currency, and another merchant. Run it with the transaction
   that matches.
4. Store a Buy now PayPal order.

## Expected result

The checkout answers with a redirect to PayPal. PayPal receives the cart order
name and total, and no product number. The cancel URL is the checkout page from
the Cart settings. The return URL starts with that page and not with the
merchant redirect URL. The completed payment that matches completes the cart
order one time.

## Edge cases

- A browser status cannot complete the pending order.
- PDT rejects another local order, amount, currency, or merchant before any
  write. The order stays pending.
- Buy now keeps its product ID and its product return and cancel URLs. It
  stores no cart checkout type.
