# PayPal Standard cart payment

Standard receives the cart order name and total, no product number, and the
Cart settings URLs. A browser status cannot complete the pending order. PDT
reads the transaction from PayPal and rejects a different local order,
currency, amount, or merchant before any write. A matching completed payment
completes the cart order once.

Buy now retains its product ID and its product return and cancel URLs. It
stores no cart checkout type.
