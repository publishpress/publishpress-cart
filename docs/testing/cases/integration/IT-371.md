# Checkout query vars use ppcart-coupon and ppcart-pay-plan

## Scenario

WordPress.org requires public query vars to carry the plugin prefix. Checkout
pay-plan preselect must use `ppcart-pay-plan`, not the account subscription
var `ppcart-plan` and not bare `plan`. URL coupons register as `ppcart-coupon`.
Bare `coupon` and `plan` must stay off the `query_vars` whitelist.

## Steps

1. Apply the `query_vars` filter to an empty list.
2. Create a product with two pay options. Set `ppcart-pay-plan` to the second
   option id. Call `ppcart_checkout_selected_plan()` and render
   `ppcart_payment_plan_options()`.
3. Clear `ppcart-pay-plan` and set bare `plan` to the second option id. Call
   `ppcart_checkout_selected_plan()` again.

## Expected result

- The filter list includes `ppcart-coupon` and `ppcart-pay-plan`, and does not
  include `coupon` or `plan`.
- The prefixed query var selects the second plan and checks that radio.
- The unprefixed `plan` query var leaves the first visible plan selected.
