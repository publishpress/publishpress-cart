# Checkout block renders its frontend wrapper

## Scenario

The Checkout Form block must produce a recognizable frontend container so theme styling and scripts can target it. This verifies the configured block renders the plugin's checkout wrapper on the frontend.

## Steps

1. Add a Checkout Form block for a configured product, with a chosen style and payment plan.
2. View the page on the frontend.

## Expected result

The page shows the plugin's checkout form wrapped in its own checkout container.

## Edge cases

- Requires a configured product to be available.
