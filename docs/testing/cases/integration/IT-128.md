# Checkout block pre-selects the configured payment plan

## Scenario

A product can offer multiple payment plans, and the block lets the editor choose which plan is pre-selected. This verifies that the chosen plan is the one selected when the checkout form loads, rather than the default first plan.

## Steps

1. Add a Checkout Form block for a configured product that offers more than one payment plan, and choose a non-default plan to pre-select.
2. View the page on the frontend.

## Expected result

The checkout form loads with the editor's chosen payment plan already selected.

## Edge cases

- Requires a configured product offering multiple payment plans.
