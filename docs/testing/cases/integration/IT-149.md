# Products REST route rejects users lacking product-editing capability

## Scenario

Being logged in is not enough to reach the products endpoint; the user must also be allowed to edit cart products. This access-control case verifies that an authenticated user with only the author role, who cannot edit cart products, is denied.

## Steps

1. Sign in as a user with only the author role.
2. Attempt to reach the products endpoint as that user.

## Expected result

Access is denied for the author, who cannot edit cart products.

## Edge cases

- Skipped if the temporary author user cannot be created.
