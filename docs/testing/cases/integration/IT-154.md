# Products REST route honors filtered product post types

## Scenario

Add-ons can register additional product types, and the products endpoint should include those extra types in its results. This case verifies that a product of a custom type appears in the products list once that type has been registered.

## Steps

1. Register a custom product type so the cart treats it as a product, and create a product of that type.
2. As a user who is allowed to edit cart products, request the products list.

## Expected result

The returned product list includes the custom-type product.

## Edge cases

- Skipped if the custom-type product cannot be created or no user allowed to edit cart products is available.
