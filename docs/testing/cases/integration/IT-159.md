# Account Downloads Block Shows Sample Data In Block-Editor Preview

## Scenario

When the Account Downloads block is previewed in the block editor, it must show a representative sample downloadable file rather than the current customer's real downloads. This lets editors lay out and style the Downloads block without surfacing real purchase data.

## Steps

1. Sign in as a customer.
2. Preview the Account Downloads block inside the block editor.

## Expected result

The preview shows a sample downloadable file as placeholder content.

## Edge cases

- Skipped if the temporary customer cannot be created.
