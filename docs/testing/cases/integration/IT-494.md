# A renewal created by a webhook for a Cash subscription is not flagged

## Steps

1. A subscription stored with the payment method "cod" has a paid first order.
2. An invoice.payment_failed webhook creates a failed renewal order for the invoice charge.
3. An invoice.payment_succeeded webhook arrives for the same invoice.

## Expected result

The renewal is never flagged with migrated_stripe_sync. It becomes paid with the payment method "stripe", and its integrations run once on recovery, as on development.
