# Account Page Builder Supports Percentage Content Max Width

## Scenario

A content width set with a percentage unit must render as a percentage-based maximum width, not be mistakenly treated as pixels.

## Steps

1. As a logged-in customer, render an Account Page Builder whose content width is set to 100 percent, wrapping an Account Navigation block.

## Expected result

- The content is constrained by a container.
- The maximum width is applied as 100 percent.
- It is NOT applied as 100 pixels.

## Edge cases

- Skipped when a temporary account customer cannot be created.
