# Removing the scheduled cancellation in Stripe clears pending cancellation

## Scenario

A subscription that is pending cancellation is un-canceled in Stripe. Stripe clears `cancel_at` and the subscription stays active. Cart must clear the pending state.

## Steps

1. Start with an active Stripe subscription that has `cancel_at` and `cancel_date` set.
2. Sync a Stripe subscription that is active with an empty `cancel_at`.
3. Check the stored `cancel_date`, `cancel_at`, and next bill date.

## Expected result

`cancel_date` and `cancel_at` are removed. The next bill date comes back from the current period end.

## Edge cases

- A subscription that Stripe has canceled keeps its `cancel_date`.
