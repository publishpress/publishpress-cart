# Checkout completion claim fires once per order

## Scenario

`ppcart_claim_checkout_complete()` must grant only the first authorized fire per
order while leaving an accurate counter for later blocked attempts.

## Steps

1. Claim completion on one order twice and on a second order once.
2. Read `ppcart_checkout_complete_fire_count()` after each attempt.

## Expected result

The first claim succeeds, repeats fail, and counts stay at one per order.
