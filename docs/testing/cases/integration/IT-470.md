# The AJAX import creates a one-time order for a product

## Steps

1. Sign in as a Cart manager.
2. Send the Import payment AJAX request with a pi_ ID, no subscription ID and a product.

## Expected result

The response succeeds with "Imported as a one-time order." and the order number. The order is paid, for the product, with no subscription.
