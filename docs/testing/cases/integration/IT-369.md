# Account and downloads shortcodes kses frontend HTML

## Scenario

Account and order-download shortcode callbacks must return HTML passed through
`ppcart_kses_frontend_html()` so extension hooks cannot inject executable markup.

## Steps

1. As a logged-in customer, filter `ppcart_my_account_tab_content` to append a
   script tag and allowed paragraph markup, then render `ppcart_account`.
2. Seed a paid order with a download for the customer and render
   `ppcart_order_downloads`.

## Expected result

- My account output keeps allowed markup such as `ppcart-my-account` and
  `ppcart-kses-ok`.
- No `<script` appears in my account output.
- Downloads shortcode output includes `ppcart-download-list`, the file name, and
  a download link.

## Edge cases

- Filter runs on the assembled tab HTML before the shortcode return wrapper applies kses.
