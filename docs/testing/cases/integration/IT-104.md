# Cart does not register the leftover Gutenberg checkout block

## Scenario

Slice 60 removes leftover `sc-products-shortcode/product-shortcode` from Cart. First-party registers only `publishpress-cart/checkout-form`. Persisted leftover blocks render only while Compatibility Mode dual-registers them (IT-351).

## Steps

1. Load the plugin so blocks register.
2. Check whether the leftover checkout block is registered.

## Expected result

The leftover checkout block is not registered by Cart.

## Edge cases

- Canonical checkout block stays registered (IT-103).
- Leftover dual-register is Compat-on only; no silent migrate.
