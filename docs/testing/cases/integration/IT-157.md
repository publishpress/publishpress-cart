# Account Orders Block Shows Sample Data In Block-Editor Preview

## Scenario

When the Account Orders block is previewed inside the block editor, it must show representative placeholder orders instead of the signed-in user's real orders. This lets editors arrange and style the block in the editor without exposing any real customer data.

## Steps

1. Sign in as a customer who has real orders.
2. Preview the Account Orders block inside the block editor.

## Expected result

The preview shows sample placeholder orders, and the customer's real orders are not shown.

## Edge cases

- Skipped if the temporary customer cannot be created.
