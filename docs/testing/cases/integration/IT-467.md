# One-time import refuses an uncaptured payment and uses the captured amount

## Steps

1. Stripe has an uncaptured charge, and a $50 charge of which $39 was captured.
2. Import both as one-time orders for a product with a $39 one-time plan.

## Expected result

The uncaptured charge is refused and creates no order. The other becomes a paid $39 order on the $39 plan.
