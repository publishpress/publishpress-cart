# Required checkout fields are exposed to assistive technology

## Scenario

A checkout renders required and optional fields, with labels shown or hidden.

## Steps

1. Render a required text field and an optional one with `ppcart_do_field()`.
2. Render a required select with `hide_labels` set to `hide`.
3. Pass required controls through the frontend kses allow-list.

## Expected result

Required controls carry `aria-required="true"` (not native `required`), and the visual asterisk is `aria-hidden`. Optional controls have no `aria-required`. A select with hidden labels keeps a screen-reader-only `<label>`. Kses keeps `aria-required`.

## Edge cases

Radio and checkbox groups do not get `aria-required` on individual inputs.
