# Events with status "ignored" are not logged by default

## Scenario

Stripe sends many event types the plugin does not act on; logging all of them would flood the log with noise. By default, outcomes marked as ignored are not written unless the operator explicitly opts in.

## Steps

1. Start with the webhook log reset and the include-ignored setting off.
2. Record an ignored outcome for a sample event.
3. Read the log entries back.

## Expected result

No entries are written, because the include-ignored setting is off by default.

## Edge cases

- The event is still marked as having a final outcome for the request, so duplicate ignored outcomes for the same event are also skipped.
