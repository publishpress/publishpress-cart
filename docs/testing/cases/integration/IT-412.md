# Settings row labels

## Scenario

A screen reader or speech input user moves through the PublishPress Cart Settings fields.

## Steps

1. Register the settings fields.
2. Render each section the way WordPress core does.
3. Find the row for each text, textarea, upload and select setting that the audit reported.

## Expected result

Each row label is a `<label for>` that points at a control with that id, and the label text is the field title. The "Test email" row label points at the email type select.

## Edge cases

Fields that set their own `label_for` keep it. Radios, editors, repeaters and HTML fields are not given a `label_for`.
