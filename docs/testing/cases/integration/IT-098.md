# Account Detail REST Route Denies Another Customer's Order

## Scenario

The account detail endpoint must reject requests for an order owned by a different customer, returning a forbidden response rather than leaking the order. This is the server-side access-control guard for the detail endpoint.

## Steps

1. As a logged-in customer, request the detail view for an order owned by a different customer from the account detail endpoint.

## Expected result

- The request is rejected as forbidden.
- The response does not reveal the other customer's order details.

## Edge cases

- Skipped when the temporary account customer or the second customer's order cannot be created.
