# Checkout block keeps the order total price visually aligned

## Scenario

In the block checkout, the order total row must keep its label and price neatly lined up and centered rather than falling back to the older misaligned layout. This verifies the order total stays visually aligned.

## Steps

1. Add a Checkout Form block for a configured product with a payment plan.
2. View the page on the frontend and look at the order total row.

## Expected result

The order total row shows its label and price aligned and centered together.

## Edge cases

- Requires a configured product to be available.
