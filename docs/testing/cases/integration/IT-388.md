# Admin write paths check the nonce and capability before using request data

## Scenario

The WordPress.org review asks for a visible nonce check
and a capability check in each handler that reads request data. The order
title filter, the product metabox save, and the debug log page each check the
nonce and the capability in the hooked handler before they use request data.

## Steps

1. Filter order post data with a posted first name and no edit-post nonce.
2. Do step 1 again as a subscriber with a valid edit-post nonce.
3. Do step 1 again as an administrator with a valid edit-post nonce.
4. Save a product metabox with no `ppcart_fields_nonce`, as a subscriber with
   the nonce, and as an administrator with the nonce.
5. Render the debug log page as an editor, as an administrator with no view
   nonce, and as an administrator with the view nonce.

## Expected result

- The order title changes only in step 3.
- `ppcart_before_validate_meta` fires only for the administrator with the nonce.
- The debug log page stops with `wp_die()` for the editor and for the request
  with no nonce, and renders for the administrator with the nonce.
