# Unrecognized Stripe subscription status is logged via the debug logger

## Scenario

When the subscription mapping receives a Stripe subscription whose status is not one of the recognized values, it must record a diagnostic message rather than silently ignoring it. The message is sent to the debug log so operators can spot statuses the plugin does not yet handle.

## Steps

1. Start with a Stripe subscription whose status is an unrecognized value.
2. Capture the debug log output.
3. Map the subscription.
4. Inspect what was written to the debug log.

## Expected result

A debug message is recorded, and it reports an unknown Stripe subscription status, confirming the unrecognized status was logged.

## Edge cases

- Recognized statuses must not produce this message; only statuses outside the known set trigger the unknown-status warning.
