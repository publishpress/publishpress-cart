# A confirmation page opened with a valid order token renders inside the embed shell

## Scenario

A product can confirm on a page the merchant picked. After an embedded order the
frame opens that page with `ppcart-order` and its access token. The page has no
checkout content, so only the token can admit it to the shell.

## Steps

1. Create a plain page and an order with an access token.
2. Load the page with `ppcart-embed=1`, the order id and a wrong token.
3. Render it again with the right token.

## Expected result

1. It is not an embed request.
2. The page content renders inside the shell with the `ppcart-embed` body class
   and the frame bridge.

## Edge cases

- Without a token, the page keeps the site's framing policy (IT-397).
