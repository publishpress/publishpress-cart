# Cart option lists leave the edited post of another plugin alone

## Steps

1. Create a published post of another plugin's post type, a published Cart product and a published upsell path.
2. Open wp-admin/post.php for the other plugin's post. The main query has no post, and the global $post is that post.
3. Build the upsell path list and the product list that the product metabox uses.

## Expected result

Both lists include the Cart records. The global $post is still the other plugin's post, so its edit screen keeps its own title and permalink.
