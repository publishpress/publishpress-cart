# Duplicate checkout blocks emit only one live form

## Scenario

Two Checkout Form blocks for the same product on one page must not produce two separate live payment forms, which would conflict with each other. This verifies that two identical checkout blocks collapse into a single live form.

## Steps

1. Add two identical Checkout Form blocks for the same configured product to one page.
2. View the page on the frontend.

## Expected result

Only one live checkout form appears on the page.

## Edge cases

- Requires a configured product to be available.
