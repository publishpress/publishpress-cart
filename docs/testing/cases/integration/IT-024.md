# Backed-Post Helper Detects A Stripe Subscription Via Legacy Meta

## Scenario

Subscriptions created by older plugin versions stored their Stripe reference under a legacy field instead of the current one. To avoid leaving historical records unguarded, detection must still recognize a subscription carrying only the legacy reference as Stripe-backed. This guarantees backward compatibility for the data guard.

## Steps

1. Start with a published subscription that has only the legacy Stripe reference set, with neither the current reference nor a payment method.
2. Check whether the subscription is detected as Stripe-backed.

## Expected result

The subscription is detected as Stripe-backed based on the legacy reference alone.

## Edge cases

- Only the legacy reference is set, confirming pre-existing subscriptions remain protected after upgrades.
- Complements IT-023, which exercises the current reference.
