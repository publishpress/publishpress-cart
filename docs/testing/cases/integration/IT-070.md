# Account Page Builder Shows Login And Hides Navigation When Logged Out

## Scenario

When a visitor is not logged in, the Account Page Builder should still render its account shell and surface the login form from the nested Account Login block, while hiding account navigation that only makes sense for authenticated customers.

## Steps

1. As a logged-out visitor, render an Account Page Builder containing an Account Login block and an Account Navigation block.

## Expected result

- The account page builder shell is rendered.
- The login form is present.
- The account navigation tab list is absent.

## Edge cases

- No account data is required; the logged-out view renders without a customer.
