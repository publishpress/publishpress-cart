# Screen context uses the edited post, not the global post

## Steps

1. Open wp-admin/post.php for another plugin's post, with the global $post left on a Cart product.
2. Open wp-admin/post.php for a Cart product, with the global $post left on another post.

## Expected result

The first screen is not a Cart product screen or a Cart screen. The second screen is both.
