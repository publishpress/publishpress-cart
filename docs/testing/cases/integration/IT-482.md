# Screen context uses the screen post type, not the global post or a post ID

## Steps

1. Open wp-admin/post.php for another plugin's post, with the global $post left on a Cart product.
2. Open the Pages list (edit.php?post_type=page) with a Cart product ID as `post` in the URL.
3. Open wp-admin/post.php for a Cart product, with the global $post left on another post.

## Expected result

The first two screens are not a Cart product screen or a Cart screen. The third screen is both.
