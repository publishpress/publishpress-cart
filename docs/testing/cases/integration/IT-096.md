# Account Detail REST Route Returns Owned Order Detail HTML

## Scenario

The account detail endpoint must return the rendered detail view for an order owned by the requesting customer, applying the requested slide-in presentation and a cleaned-up back link. This powers the in-page detail view without a full page reload.

## Steps

1. As the logged-in customer who owns the order, request that order's detail view from the account detail endpoint, asking for a slide-in presentation and supplying a return address that still carries the order detail parameters.

## Expected result

- The request succeeds.
- The returned detail view shows the owned order using the requested slide-in presentation, including the order, its order-details summary, and its invoice.
- The receipt-only layout is not included.
- The back link returns to the account page with the order detail parameters removed.

## Edge cases

- Skipped when a temporary account customer or their order cannot be created.
