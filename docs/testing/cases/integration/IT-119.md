# Classic themes keep the legacy PHP checkout renderer

## Scenario

Classic themes cannot rely on block templates, so the plugin must keep serving its own legacy checkout template for product pages. When product block templates are turned off, the plugin must use its bundled checkout template.

## Steps

1. Load the plugin and start from a product.
2. Turn off product block templates to emulate a classic theme.
3. Ask the plugin which template to use for that product page, then restore the setting.

## Expected result

The plugin returns its bundled legacy checkout template, confirming the legacy renderer is chosen instead of handing control back to the theme.

## Edge cases

- Skipped when no product is available.
