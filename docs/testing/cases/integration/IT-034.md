# Stripe Reconciliation Cron Hook Is Registered

## Scenario

Periodic reconciliation of stale Stripe subscriptions runs on a scheduled task. For that to work, the plugin must attach a handler to the reconciliation schedule when it loads. This case verifies the schedule has a handler registered after the plugin loads.

## Steps

1. With the plugin loaded, check whether the reconciliation schedule has a handler registered.

## Expected result

The reconciliation schedule has a handler registered, confirming reconciliation is wired up.

## Edge cases

- The handler must be registered automatically on plugin load, without requiring any admin page visit or manual setup.
