# Products REST route denies anonymous visitors

## Scenario

The products endpoint exposes cart product data only to users who are allowed to edit products. This access-control case verifies that an anonymous, not-logged-in visitor is denied, preventing unauthenticated access to the product list.

## Steps

1. As an anonymous visitor who is not logged in, attempt to reach the products endpoint.

## Expected result

Access is denied for the anonymous visitor.
