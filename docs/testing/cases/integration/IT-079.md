# Account Navigation And Tab Blocks Emit Style Classes And CSS Variables

## Scenario

Navigation and tab style settings chosen in the editor — tab style, alignment, spacing, colors, panel style, padding, corner radius, and border — must be reflected in the rendered account page so the customer sees the configured styling.

## Steps

1. As a logged-in customer, render an Account Navigation block styled with a pill tab style, center alignment, a set tab spacing, and an accent and active-tab color, containing an Account Tab styled as a card with a set padding, corner radius, and border color, wrapping an Account Orders block.

## Expected result

- The navigation reflects the chosen pill style, center alignment, spacing, accent color, and active-tab color.
- The tab panel reflects the chosen card style, padding, corner radius, and border color.

## Edge cases

- Skipped when a temporary account customer cannot be created.
