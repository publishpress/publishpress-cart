# An empty Embed field deletes its meta and a zero radius stays

## Scenario

Emptying a field means "keep the Cart default". The metabox save deletes
the meta for an empty value, but `0` is a real corner radius.

## Steps

1. Save the Embed tab with accent `#ff5a1f` and radius `8`.
2. Save it again with an empty accent and radius `0`.

## Expected result

1. After the first save the `_ppcart_embed_accent` meta exists.
2. After the second save the meta is gone and the accent reads back as `''`.
3. The radius reads back as the integer `0`.

## Edge cases

- None.
