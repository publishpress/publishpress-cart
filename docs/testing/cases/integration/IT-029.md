# Successful Sync Stores The Last Sync Timestamp

## Scenario

After a subscription successfully syncs with Stripe, reconciliation records when the last good sync happened so the batch can later skip recently-synced records. This case verifies a successful sync records that time, even when the subscription was previously in a failed state.

## Steps

1. Start with an active Stripe subscription.
2. Put it into a failed state by recording a sync failure.
3. Record a successful sync.

## Expected result

The subscription's last sync time is set to a non-empty value, recording when the successful sync happened.

## Edge cases

- The last sync time must be written on success regardless of any prior recorded failures.
