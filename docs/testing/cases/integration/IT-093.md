# Account Login Block Renders When Hide-When-Logged-In Is Disabled

## Scenario

When an author turns off the hide-when-logged-in option, the Account Login block must render even for logged-in customers (for example, to support switching accounts).

## Steps

1. As a logged-in customer, render the Account Login block with the hide-when-logged-in option turned off.

## Expected result

- The Account Login block renders the login form even though the customer is already logged in.

## Edge cases

- Skipped when a temporary account customer cannot be created.
