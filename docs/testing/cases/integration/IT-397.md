# Only pages with checkout content render inside the embed shell

## Scenario

The embed shell removes `X-Frame-Options` and lets other sites frame the page.
So the `ppcart-embed` flag must work only on products and on pages that show a
checkout or a receipt (a same-site thank-you page after an embedded order).
Any other page, such as an account page, keeps the site's own framing policy.
The `ppcart_embed_allows_post` filter can allow more pages, for example an
upsell page.

## Steps

1. Create a published page with plain content and load it with `ppcart-embed=1`.
2. Allow it through the `ppcart_embed_allows_post` filter and load it again.
3. Remove the filter, add `[ppcart_receipt]` to the page content, and render the shell.

## Expected result

1. It is not an embed request, and the theme template is kept.
2. It is an embed request, and the shell template is chosen.
3. The page paragraph is inside the `ppcart-embed__main` landmark, the body has
   the `ppcart-embed` class, the frame bridge is enqueued, and no checkout submit
   button is rendered.

## Edge cases

- A page with the checkout form block or `[ppcart_form]` is allowed the same way.
