# A non-product page renders its content inside the embed shell

## Scenario

After an embedded order, a same-site thank-you or upsell page opens inside the
frame. Such a page is not a product, so the shell renders its post content
through `the_content` instead of the checkout form.

## Steps

1. Create a published page with a known paragraph.
2. Load it with `ppcart-embed=1` and render the shell template.

## Expected result

The paragraph is in the output inside the `ppcart-embed__main` landmark, the
body has the `ppcart-embed` class, the frame bridge is enqueued, and no checkout
submit button is rendered.

## Edge cases

- A page's own blocks and shortcodes still run through `the_content`.
