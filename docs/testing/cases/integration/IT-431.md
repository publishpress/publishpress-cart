# Importing a Stripe subscription that Cart already has is refused

## Scenario

Importing the same subscription twice would duplicate it and its orders.

## Steps

1. Create a Cart subscription linked to a Stripe subscription.
2. Import that Stripe subscription.

## Expected result

The import returns an error with the existing subscription's ID, and nothing is created.
