# Checkout block plus Elementor popup can render two live forms

## Scenario

An Elementor popup checkout is intentionally a separate checkout from an inline one, so it must not be merged with the inline form. A popup checkout is allowed to appear alongside an inline Checkout Form block for the same product. This verifies the popup checkout is exempt from de-duplication.

## Steps

1. Add an inline Checkout Form block for a configured product, and add an Elementor popup checkout for the same product on the same page.
2. View the page on the frontend.

## Expected result

Both the inline checkout and the popup checkout render their own live forms, for two forms total.

## Edge cases

- Requires a configured product to be available.
