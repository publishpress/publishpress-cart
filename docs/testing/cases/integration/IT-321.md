# Stranger with only an order ID cannot view public order data

## Scenario

`?ppcart-order=` is enumerable. Without an Order access token or owner session, the downloads shortcode, order-detail field shortcode, and confirmation page must not reveal the order. Failed proof looks like a missing order.

## Steps

1. Create a paid guest order with an Order access token.
2. Request it by id only.
3. Render the downloads shortcode, `[ppcart_order_detail]`, and payment confirmation.

## Expected result

No download links, no order fields, confirmation HTML matches the no-order closed message.

## Edge cases

- Do not `wp_die` or say the order exists.
