# Successful Sync Clears The Reconciliation Failure Count

## Scenario

Once a previously-failing subscription syncs successfully, its accumulated failure count must be reset so backoff does not keep applying. This case verifies the failure count is cleared after a successful sync.

## Steps

1. Start with an active Stripe subscription.
2. Record a failure so its failure count is one.
3. Record a successful sync.

## Expected result

The subscription's reconciliation failure count is cleared to empty.

## Edge cases

- A successful sync must reset the count to empty even after multiple prior failures.
