# Account Block CSS Is Served From The Gutenberg Integration Directory

## Scenario

The registered account stylesheets must point at the styles shipped inside the plugin's block integration folder. This confirms each registered account stylesheet resolves to the expected file within the plugin.

## Steps

1. Load the plugin so assets register.
2. Read the registered location of the account front-end stylesheet.
3. Read the registered location of the account editor stylesheet.

## Expected result

The account front-end and editor stylesheets are both served from the plugin's block integration folder, pointing at the expected account style files.

## Edge cases

- The location is checked by path within the plugin, so it tolerates the site address prefix and any cache-busting suffix while still pinning the file location.
