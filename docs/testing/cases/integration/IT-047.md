# Active subscription with `pause_collection` void maps to local paused

## Scenario

A Stripe subscription can report a status of active while actually being paused, with its billing temporarily suspended. When billing is paused in this way, the mapping overrides the active status and marks the local subscription as paused, so PublishPress Cart reflects that billing is suspended.

## Steps

1. Start with a Stripe subscription that reports active but has its billing paused.
2. Map the subscription.
3. Check the resulting local status.

## Expected result

The resulting local status is paused, overriding the incoming active status because billing is suspended.

## Edge cases

- The Stripe status is active, yet the paused-billing condition takes precedence and forces a paused local status.
