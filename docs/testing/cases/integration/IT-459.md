# A normal request recreates a missing cart table

## Scenario

A site that updates the plugin files without running activation has no cart
table. The first add to the cart must still work.

## Steps

1. Drop the cart table.
2. Run the table setup that every normal request runs.
3. Add a one-time plan of a published product to the cart.

## Expected result

The cart table exists again. The cart has one line for the product, and the
cart cookie holds the key of the stored row.

## Edge cases

- The order items table already exists. The setup still creates the cart table.
