# Account Orders Block Denies Another Customer's Order Detail

## Scenario

A customer must never see another customer's order through the in-page detail view. When a request asks to view an order that belongs to a different customer, the Account Orders block must refuse to show it. This is the access-control guard of the order detail feature.

## Steps

1. As a logged-in customer, request the detail view for an order owned by a different customer, from within the account page that contains the Account Navigation with an Orders tab set to the slide-in detail presentation.

## Expected result

- A permission-denied message is shown instead of the order.
- The other customer's order details are not revealed.

## Edge cases

- Skipped when the temporary account customer or the second customer's order cannot be created.
