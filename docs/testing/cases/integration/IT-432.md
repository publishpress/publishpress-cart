# Importing needs a product when no product sells the Stripe price

## Scenario

An old Stripe price may not belong to any Cart product.

## Steps

1. Import a Stripe subscription whose price no Cart product sells.
2. Import it again with a product chosen.

## Expected result

The first import returns a product error and creates nothing. The second creates the subscription on the chosen product.
