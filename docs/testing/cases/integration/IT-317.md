# First-party checkout emits and reads canonical request field names

## Scenario

First-party checkout emits and reads canonical request keys. Leftover
StudioCart POST/GET copy lives in `publishpress-cart-compat`.

## Steps

1. Confirm first-party checkout markup emits `name="ppcart-nonce"` and
   `name="ppcart_product_id"`.
2. Confirm leftover `sc-nonce` / `sc_product_id` names are absent from that
   markup.

## Expected result

First-party emit/read is canonical.

## Edge cases

- `ppcart_filter_input` / `ppcart_filter_input_array` remain first-party APIs.
