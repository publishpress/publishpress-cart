# A flagged order runs refund integrations from a webhook but not from a manual sync

## Steps

1. Two paid Stripe orders carry the migrated_stripe_sync flag. Stripe fully refunded both charges.
2. Sync the first order's refund as the charge.refunded webhook does.
3. Run order-level Sync with Stripe on the second order.

## Expected result

Both orders become refunded. The webhook runs the first order's refund integrations once. The manual sync runs none for the second order.
