# Checkout HTML uses canonical submit and terms ids and names

## Scenario

Slice 19 hard-cut leftover checkout `id` attributes to `ppcart_*`. Slice 26
hard-cut leftover form `name=` attributes. The submit button and terms checkbox
must emit the canonical ids and names.

## Steps

1. Set `_ppcart_terms_url` so the terms checkbox renders.
2. Render a Checkout Form block for a configured product.
3. Inspect the HTML for submit-button and terms-checkbox attributes.

## Expected result

- `id="ppcart_card_button"` and `id="ppcart_accept_terms"` are present.
- Leftover `id="sc_card_button"` and `id="sc_accept_terms"` are absent.
- `name="ppcart_accept_terms"` is present.

## Edge cases

- Terms checkbox only renders when a terms URL is configured.
