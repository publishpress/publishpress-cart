# Backed-Post Helper Detects A Stripe Subscription Via Current Meta

## Scenario

A subscription tied to Stripe stores its gateway subscription reference. Detection must treat the presence of that reference as proof the subscription is Stripe-backed, even when no payment method is set. This ensures subscriptions are guarded based on their Stripe subscription reference.

## Steps

1. Start with a published subscription that has the current Stripe subscription reference set and no payment method.
2. Check whether the subscription is detected as Stripe-backed.

## Expected result

The subscription is detected as Stripe-backed solely because the current Stripe subscription reference is present.

## Edge cases

- No payment method is set; the presence of the current Stripe subscription reference alone is sufficient for detection.
- This is the modern reference; the legacy reference is covered separately in IT-024.
