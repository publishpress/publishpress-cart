# Payment intent AJAX rejects a request without the checkout nonce

## Scenario

`create_payment_intent()` verifies `ppcart_purchase_nonce` in the AJAX handler
before its template reads any other request field.
Guests use this endpoint, so the nonce is the CSRF defense.

## Steps

1. As a guest, call the handler with a product ID and no `ppcart-nonce`.

## Expected result

- The handler returns a JSON error with `Invalid Request`.
