# Checkout block omits the coupon section when coupons are unavailable

## Scenario

The coupon field is a Pro feature; even when the editor places a coupon section in the custom checkout order, no empty coupon section should appear if coupons are not available for this checkout. This verifies the coupon section is skipped rather than shown blank.

## Steps

1. Add a Checkout Form block for a configured product and include a coupon section in the custom section order, on a setup where coupons are unavailable.
2. View the page on the frontend.

## Expected result

No coupon section appears on the checkout when coupons are unavailable.

## Edge cases

- Applies only when the Pro coupon feature is active; otherwise the case is skipped.
