# Account Navigation Editor Lists Downloads Tab Hidden On Frontend

## Scenario

The Account Navigation block's tab picker in the editor must offer every account tab an author could enable, including the Downloads tab, even when that tab is not part of the default public account navigation. This guards against the editor's list of selectable tabs and the live frontend tab list drifting apart.

## Steps

1. As an administrator, open the Account Navigation block's list of selectable tabs in the editor.
2. Look at the default account tabs shown on the frontend.
3. Compare both lists for the Downloads tab.

## Expected result

- The editor's selectable tabs include Downloads.
- The default frontend tabs do NOT include Downloads, so it stays out of the default public navigation.

## Edge cases

- Skipped when the account navigation or account tabs are unavailable.
- Skipped when the temporary administrator cannot be created.
