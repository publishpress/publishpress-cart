# Admin kses keeps settings data attributes and SVG stroke

## Scenario

Settings panels and nav icons are echoed through `wp_kses()` with
`ppcart_admin_allowed_html()`. Admin JS needs `data-pp-*` attributes; nav SVGs
need stroke attributes. Scripts and event handlers must not survive.

## Steps

1. Pass an `<aside>` payment panel with `aria-modal` / `aria-labelledby` /
   `data-pp-payment-detail`, an input with `form=` (Stripe webhook footer
   form), `data-pp-payment-toggle`, `data-pp-secret-stored`, `onclick`, an SVG
   with `stroke` and a classed `<circle>`, and a `<script>` tag through
   `wp_kses($html, ppcart_admin_allowed_html())`.
2. Assert allowed attributes and SVG markup remain.
3. Assert `onclick` and `<script` are stripped.

## Expected result

Settings panel ARIA, webhook `form=`, `data-pp-*`, and SVG stroke survive.
Executable markup does not.

## Edge cases

- Custom `data-pp-*` attributes added by Pro can be allowed via
  `ppcart_admin_allowed_html`.
