# Subscription Next Bill Date Is Recognized As Stripe-Owned

## Scenario

A subscription's next billing date is determined by the Stripe billing cycle, so the plugin must never let a local edit drift it out of step with the gateway schedule. The owned-field registry must flag the next billing date as Stripe-owned for subscriptions so the data guard preserves the Stripe value. This case checks the registry in the context of a subscription.

## Steps

1. Ask the registry whether the subscription next billing date is Stripe-owned, in the context of a subscription.

## Expected result

The subscription next billing date is reported as Stripe-owned.

## Edge cases

- The check is scoped to a subscription; the billing date is owned in the subscription context specifically.
