# The Import payment AJAX refuses a subscription number that is not a number

## Steps

1. Sign in as a Cart manager.
2. Send the Import payment AJAX request with the subscription ID "abc", "#", "12a" and "0".

## Expected result

Each request fails with "Enter the Cart subscription number, for example 1234." Nothing is sent to Stripe.
