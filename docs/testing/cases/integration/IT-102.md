# Account Detail REST Route Denies Another Customer's Subscription

## Scenario

The account detail endpoint must reject requests for a subscription owned by a different customer, returning a forbidden response rather than leaking it. This is the server-side access-control guard of the detail endpoint.

## Steps

1. As a logged-in customer, request the detail view for a subscription owned by a different customer from the account detail endpoint.

## Expected result

- The request is rejected as forbidden.
- The response does not reveal the other customer's subscription details.

## Edge cases

- Skipped when the temporary account customer or the second customer's subscription cannot be created.
