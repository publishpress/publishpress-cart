# Account detail REST route requires a logged-in customer

## Scenario

The account detail endpoint returns a customer's own order and subscription data, so it must reject visitors who are not logged in. This access-control case verifies that an unauthenticated request is blocked with an authorization error rather than returning account data.

## Steps

1. As an anonymous visitor who is not logged in, request order detail from the account detail endpoint.

## Expected result

The request is rejected with an authentication/authorization error rather than returning any account data.

- None documented.
