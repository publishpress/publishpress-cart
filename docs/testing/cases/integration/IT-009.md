# Subscription Sync Stores The Mapped Status While Clearing Meta

## Scenario

While a cancellation sync removes date-related details (see IT-007/IT-008), it must still record the subscription's status. This verifies the sync, when handling a canceled Stripe subscription, sets the local subscription's status to canceled.

## Steps

1. Start with an active subscription (and its first order).
2. Run a canceled Stripe subscription through the sync.
3. Check the subscription's status.

## Expected result

The subscription's status is canceled, confirming the incoming Stripe status is applied to the local subscription even as cleared dates are removed.

## Edge cases

- The status is recorded independently of the date clearing covered by IT-007 and IT-008.
