# PayPal cart background sync

A forged completion webhook cannot pay an unapproved cart order. Hourly
reconciliation reads an approved order from PayPal, captures it, and runs the
cart completion work once. A later webhook does not repeat that work.

Refund sync reads the refund and its capture from PayPal, marks the cart order
refunded, and records one refund entry across retries. Product meta is absent
on the parent order throughout.
