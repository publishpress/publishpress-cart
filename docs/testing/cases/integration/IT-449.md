# Cart page

## Scenario

The Cart page shows the lines, the notices, and the totals of the visitor's
cart. The block, the shortcode, and the REST fragment must show the same cart.

## Steps

1. Put two products in a cart. Render the cart through the block, the
   shortcode, and the REST fragment.
2. Change a price and render the cart two times.
3. Send the rendered remove form of the last line, with its own nonce.
4. Make a product in the cart not eligible and render the cart.
5. Render the cart with style settings and with a row that an extension adds
   through the totals filter.

## Expected result

The same rows and the current server totals are in each render, and the page is
not cached. The price notice is in both renders. After the last removal the
page shows the empty state and the configured Shop link, and the cart cookie is
gone. The line of the product that is not eligible is removed, and the page
shows its notice. The wrapper has the shared style tokens. The summary shows
the added row and the display total.

## Edge cases

- A notice stays after a second render. It is not shown only one time.
- The priced subtotal stays the sum of the server prices when an extension
  changes the display total.
