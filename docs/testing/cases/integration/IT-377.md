# Empty admin orders save without checkout warnings

## Scenario

An administrator can publish a new order before selecting a product or payment
option. The checkout hydration path must treat the missing plan as an empty order
instead of reading properties from `false` or `null`.

## Steps

1. Sign in as a Cart Manager and create a new order post.
2. Submit the order save action without product or payment-option fields.
3. Reload the stored order.

## Expected result

- The save completes without PHP warnings.
- The stored order has no product or plan and has a zero amount.
- The manual-order log entry is recorded.

## Edge cases

- Missing product and payment-option values produce no main order item.
