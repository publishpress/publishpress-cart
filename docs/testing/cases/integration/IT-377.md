# Maintenance database schema check and repair

## Scenario

`PPCart_DB_Schema_Service` validates Free custom tables, repairs missing
columns and indexes (including atomic unique index rebuilds), exposes results
on Settings → Maintenance, and rejects AJAX repair without `manage_options`.

## Steps

1. Check a fresh install.
2. Drop a table, column, the AUTO_INCREMENT primary key column, or the downloads
   `order_key` index and repair.
3. Rebuild a non-unique `order_key` index; attempt repair with duplicate keys
   (also with `$wpdb->show_errors` on).
4. Run repair twice after index drift.
5. Register an extra schema via `ppcart_db_table_schemas` and repair; also
   register schemas with unsafe identifiers, an inline `UNIQUE` column, column
   definitions carrying a comma, `;`, comment, unterminated quote or unbalanced
   parenthesis, an unprefixed table and a WordPress core table; register a
   schema with quoted defaults and `decimal(10,2)`; repair a dropped column
   whose fragment has `DEFAULT '%s off'`.
6. Widen `downloads.file_id` beyond its definition, store a longer value, and
   repair.
7. Call the AJAX repair handler as a subscriber, then as an administrator on a
   passed schema and on a failed schema.
8. Render the Maintenance markup through `ppcart_admin_allowed_html()` on a
   passed schema and on a failed schema; render the Settings placeholder and
   call the status AJAX handler as an administrator and as a subscriber.

## Expected result

Healthy when aligned; issues reported when drifted; repair restores schema
without duplicate index names; duplicate keys leave the old index and surface
`fix_errors` without printing database errors; filtered tables are created
while unsafe filtered schemas are skipped with a `_doing_it_wrong` notice; unauthorized AJAX returns 403 without repairing;
AJAX on a passed schema returns 409 and runs no repair; AJAX on a failed schema
repairs it; the Repair row is hidden when the schema passed; when it failed,
the Fix button keeps its `data-ppcart-fix-db-schema` and `data-nonce` hooks
after admin kses; legitimate quoted defaults and decimals are accepted; a
widened column is reported but repair keeps its type and data; the Settings
placeholder runs no database queries; the status AJAX returns the checked panel
for administrators and 403 without markup for subscribers.
