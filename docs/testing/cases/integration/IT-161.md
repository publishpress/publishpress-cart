# Cart does not ship includes/compat

## Scenario

StudioCart Compatibility Mode and Data migration live in
`publishpress-cart-compat`. PublishPress Cart Free must not ship
`includes/compat/` (including the old `legacy.php` loader).

## Steps

1. Boot the integration suite (Cart active, companion not required).
2. Assert `includes/compat` is not on disk.
3. Assert `includes/compat/legacy.php` is not on disk.

## Expected result

The directory and that file do not exist.

## Edge cases

- Helper-load and Compatibility Mode bootstrap coverage is IT-161 in
  publishpress-cart-compat.
