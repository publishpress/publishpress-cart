# A scheduled `cancel_at` clears the local next bill date

## Scenario

When a Stripe subscription is scheduled to cancel, there is no future renewal to bill. The mapping returns an empty next billing date in this case, even though the subscription status is still active and a current period end is present.

## Steps

1. Start with an active Stripe subscription that has a scheduled cancellation date and a current period end.
2. Map the subscription.
3. Check the resulting next billing date.

## Expected result

The next billing date is empty because a cancellation is scheduled, despite the active status and the present current period end.

## Edge cases

- With no cancellation scheduled, a next billing date would instead be derived; only a scheduled cancellation clears it.
