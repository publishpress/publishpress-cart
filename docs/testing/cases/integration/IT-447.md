# Shopping cart REST API

## Scenario

The Mini Cart, the Cart page, and the Shop forms read and change the cart
through `ppcart/v1/cart`. The response is the only cart data that the browser
gets, so it must hold server prices and no storage field.

## Steps

1. Read an empty cart with `GET /ppcart/v1/cart`.
2. Add two lines. Send a price in the request body of one add.
3. Send an add without a REST nonce and with a stale nonce. Send a quantity
   change and a remove without a nonce. Read the cart without a nonce.
4. Add a product that is not eligible, a plan that is not eligible, and a
   duplicate key. Set a quantity that is not available, and set the quantity of
   a missing line. Send malformed input. Add with the cart turned off.
5. Remove a line. Remove a line that is not in the cart.
6. Add a row through the totals filter, store a notice, and read the cart.
7. Add a line as a signed-in visitor. Read the cart and remove the line as a
   guest who holds that cart key. Read the cart as the signed-in visitor.
8. Change and remove a line whose plan ID has colons, a slash, and a literal
   percent escape, with the key URL-encoded in the route.

## Expected result

The empty read returns the cart shape, a valid REST nonce, and the no-store
cache header. No row and no cookie exist. After the adds, the prices are decimal
strings from the server, and the price in the request body is ignored. The
response never holds the cart key, the user ID, or the seen price. A change
without a valid REST nonce is refused with 403, and a read needs no nonce. The
totals filter row and the stored notice are in the response. The signed-in
visitor keeps the line: the guest reads an empty cart and removes nothing. The encoded key is decoded one
time and identifies the same line for PATCH and DELETE.

## Edge cases

- Each cart error carries its HTTP status and the current cart: 422 for a
  product, plan, or quantity that is not eligible, 409 for a duplicate key, 404
  for a quantity change of a missing line, 400 for malformed input, and 403 for
  a cart that is off.
- The remove of a missing line returns 200.
