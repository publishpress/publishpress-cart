# Stripe sync with a cart order

Sync a Stripe charge whose metadata names a cart order but whose payment is not
the one the order stored. The order stays pending. Sync the charge of the stored
payment. The order is paid, the completion work runs once, and the cart is
empty. A later confirmation from the browser does not run it again.

Post a cart order ID to the Buy now Stripe status endpoint. The request is
refused. The order stays pending and the response holds no order token.
