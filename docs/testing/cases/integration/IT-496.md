# A refunded Cash order whose charge has no refund stays refunded

## Steps

1. A refunded order migrated as "cod" has a pi_ transaction ID. Stripe shows its charge as succeeded with no refund.
2. Run order-level Sync with Stripe twice.

## Expected result

Each sync returns "Order synced. The refund needs a check: see the order log." The order stays refunded, gets the charge ID and the payment method "stripe". The order log has "Stripe shows no refund for this payment; the order stays refunded. Check the refunds in Stripe." once. No integrations run.
