# Subscription Customer First Name Stays Locally Editable

## Scenario

The subscriber's first name is store-owned profile data that a merchant may edit freely, so it must be excluded from Stripe data-guard preservation. The owned-field registry must report the first name as not Stripe-owned for subscriptions, ensuring local edits persist. This case confirms the locally-editable boundary on a subscription.

## Steps

1. Ask the registry whether the subscription customer first name is Stripe-owned, in the context of a subscription.

## Expected result

The subscription customer first name is reported as not Stripe-owned, so it remains locally editable and is not preserved by the data guard.

## Edge cases

- Contrasts with Stripe-owned subscription fields like the next billing date; the first name must stay editable even on a Stripe-backed subscription.
