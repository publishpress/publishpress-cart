# FSE product template registers carrying the checkout-form block

## Scenario

Block themes render single product pages from a registered block template instead of a classic single-product template. The plugin must register a product block template that already embeds the Checkout Form block, so the checkout form appears without any classic template file.

## Steps

1. Load the plugin and register the product block template.
2. Look up the registered product block template and inspect its contents.

## Expected result

The product block template is registered and already contains the Checkout Form block, so the checkout form is built into the product template for block themes.

## Edge cases

- Skipped on WordPress versions that do not support registering product block templates, or when the product template feature is unavailable.
