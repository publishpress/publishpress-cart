# A full Stripe refund replaces a manual refund that does not match

## Steps

1. A paid order migrated as "cod" has a pi_ transaction ID and a manual refund of $10.00.
2. Stripe fully refunded the $39 charge with two refunds: $10.00 and $29.00.
3. Run order-level Sync with Stripe.
4. A paid Stripe order with the same manual refund gets the charge.refunded sync for a charge fully refunded the same way.

## Expected result

Both orders become refunded. Each refund log has only the two Stripe refunds, and the refund amount is 39.00. The first order log says "Manual refund of 10.00 replaced by Stripe refund re_a, re_b, because Stripe fully refunded this payment." The migrated order runs no integrations. The Stripe order runs its refund integrations once, as before. Every Stripe request is a GET.
