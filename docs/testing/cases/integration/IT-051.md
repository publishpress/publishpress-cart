# Recorded webhook outcome is persisted and readable back from the log file

## Scenario

A recorded webhook outcome must be durably written to the log file and retrievable when the log is read back. This verifies the round trip: an outcome that is recorded can later be read back as a log entry.

## Steps

1. Start with the webhook log reset.
2. Record a webhook outcome for a sample event.
3. Read the log entries back.

## Expected result

Reading the log returns at least one entry, confirming the recorded outcome was written to the log and successfully read back.

## Edge cases

- An empty result would mean the entry was never written or the file could not be read; the reader returns an empty list for a missing or unreadable log rather than erroring.
