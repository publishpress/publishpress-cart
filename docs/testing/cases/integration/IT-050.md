# Stripe webhook log lazily creates its randomized file option on first write

## Scenario

The webhook log file name is not chosen up front; it is generated the first time an entry is written. This verifies that recording a webhook outcome creates the on-disk log and remembers its randomized file name so later reads and rotation can find it. The randomized name keeps the log path unguessable from the public web.

## Steps

1. Start with the webhook log reset so no file name is remembered and no log files exist.
2. Record a webhook outcome for a sample event.
3. Check the remembered log file name.

## Expected result

After the first write, a randomized log file name is remembered (no longer the empty default), confirming the log file was created and registered on demand.

## Edge cases

- Logging is enabled by default, so the first write must create the log rather than being silently skipped.
