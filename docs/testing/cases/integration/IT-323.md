# Logged-in owner can view downloads without a token

## Scenario

A User whose id matches the Order `user_account` may see downloads without presenting the Order access token.

## Steps

1. Create a subscriber and a paid order owned by that user, with a file entitlement.
2. Set the current user to that owner.
3. Render the downloads shortcode with no `token`.
4. Read native order downloads with omitted options and with `status=active`.
5. Hide the product file, then compare the default native read with an explicit `status=all` read.

## Expected result

Download list includes the file name. Omitted status uses the active-download defaults. Hidden files are excluded from the default read and included by the explicit native `status=all` option.
