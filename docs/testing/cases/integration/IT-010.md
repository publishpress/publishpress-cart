# Invoice Line Selection Picks The Subscription Product Line

## Scenario

A Stripe invoice can contain multiple line items, but only the line tied to a subscription represents the recurring product. Invoice processing must select the line associated with a subscription item and ignore unrelated product lines, so renewals are matched to the correct subscription product.

## Steps

1. Start with an invoice that has two lines: one ordinary product line not tied to a subscription, and one line tied to a subscription item.
2. Run invoice line selection over that invoice.

## Expected result

The line tied to the subscription item is chosen over the non-subscription line.

## Edge cases

- Selection is driven by which line is tied to a subscription item, not by product ordering or value.
