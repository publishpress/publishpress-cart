# Arranged content keeps payment methods inside the payment-info group

## Scenario

Even when the checkout sections are rearranged, the payment method selector must stay grouped within the payment info section so the payment fields appear together. This verifies that with a custom section order the payment method remains inside the payment info group.

## Steps

1. Add a Checkout Form block for a configured product and set a custom section order.
2. View the page on the frontend and look at the payment info section.

## Expected result

The payment method selector stays nested inside the payment info section rather than being separated from it.

## Edge cases

- Requires a configured product to be available.
