# Account order detail shows only the customer's own order

## Scenario

`[ppcart_account_order_detail]` takes an order ID from the request or the
`order` attribute. Order IDs are easy to guess. Another customer must not see
the receipt, address, or invoice link.

## Steps

1. Customer A owns a paid order.
2. Log in as customer B and render the shortcode for A's order.
3. Log out and render it again.
4. Log in as customer A and render it again.
5. As customer B, render the `my-account/order-detail` template directly.

## Expected result

- Customer B and the guest get no receipt.
- Customer A sees the receipt.
- The template itself shows "No orders found." to customer B.
