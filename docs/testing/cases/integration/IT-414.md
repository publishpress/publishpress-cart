# Checkout radio groups are grouped and named

## Scenario

A checkout renders payment plan radios and payment method radios.

## Steps

1. Render payment plan options for a product with two plans.
2. Render payment methods with Cash on Delivery enabled.
3. Pass a fieldset with `aria-labelledby` through the frontend kses allow-list.

## Expected result

Each radio set sits in a `<fieldset>` whose `aria-labelledby` points at the visible section heading. Kses keeps `aria-labelledby`.

## Edge cases

Several checkout forms on one page get unique heading ids.
