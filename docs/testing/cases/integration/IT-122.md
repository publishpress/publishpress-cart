# Global template disable hands rendering back to WordPress

## Scenario

A site-wide setting lets admins disable the plugin's product template entirely. When that setting is enabled, PublishPress Cart must let WordPress and the theme render product pages, even on a classic theme. This verifies that the global toggle hands rendering back to WordPress.

## Steps

1. Enable the site-wide setting that disables the plugin's product template.
2. View a configured product's page on a classic theme.

## Expected result

PublishPress Cart leaves the theme's template in place rather than substituting its own checkout template, so product pages are rendered by WordPress.

## Edge cases

- Requires a configured product to be available.
