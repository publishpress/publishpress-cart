# Administrator bypasses public-page proof

## Scenario

`manage_options` may preview another Customer's thank-you URL without the Order access token.

## Steps

1. Create a guest order with a file entitlement.
2. Log in as an administrator.
3. Render the downloads shortcode with no `token`.

## Expected result

Download list includes the file name.
