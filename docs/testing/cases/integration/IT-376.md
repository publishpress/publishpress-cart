# Plain-text prices decode currency entities

## Scenario

Checkout order-summary totals are inserted as plain text. Currency symbols are
stored as HTML entities, so a dollar sign must be the `$` character in that
string. The real symbol is the same path and must stay `R$`.

## Steps

1. Set the currency symbol to `&#36;` and format `23` with `ppcart_format_price`
   in plain-text mode.
2. Set the currency symbol to `&#82;&#36;` and format `23` the same way.

## Expected result

- Dollar plain text is `$23.00`.
- Real plain text is `R$23.00`.

## Edge cases

- HTML price output still wraps the stored entity in the currency span.
