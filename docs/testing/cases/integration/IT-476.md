# The Import payment AJAX accepts a subscription number with # and spaces

## Steps

1. Sign in as a Cart manager.
2. Send the Import payment AJAX request with a ch_ ID and the subscription ID written as " # 4762 " (with the real subscription number).

## Expected result

The response succeeds with "Imported as an order of subscription #4762." and the order belongs to that subscription.
