# Scheduled report data counts orders and refunds and keeps the global post

## Steps

1. Create a paid $25 order, a completed $15 order, a pending-payment $40 order and a refunded $30 order with a $12.50 refund log entry.
2. Set the global $post to a page and call `ppcart_schedule_report_data()`.

## Expected result

The report has 2 completed orders, 1 pending payment, a total of 110, a refunded amount of 12.5 and 1 refund. The global $post is still the page.
