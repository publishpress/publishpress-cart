# Receipt shortcode needs the same order access proof as the confirmation page

## Scenario

`[ppcart_receipt]` (also used by `[ppcart_form]` on confirmation) reads
`?ppcart-order=`. The receipt lists the order's download links. A visitor with
only the order ID must not see it. A guest buyer with the Order access token
from the thank-you URL must still see it.

## Steps

1. Set `ppcart-order` to customer A's order. Render as a guest, then as customer B.
2. Render as customer A.
3. Set `ppcart-order` to a guest order. Render with no token, with a wrong
   token, and with the correct token.

## Expected result

- The guest, customer B, and the wrong token get no receipt.
- Customer A and the guest with the correct token see the receipt.
