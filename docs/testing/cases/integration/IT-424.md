# Subscriptions list shows pending cancellations at a glance

## Scenario

A store owner wants to see which subscriptions are set to cancel, and when, without opening each one. The Subscriptions list shows a "Pending Cancellation (N)" view, and each subscription that is set to cancel shows "Cancels <date>" instead of a next payment.

## Steps

1. Create one subscription pending cancellation, one active subscription and one canceled subscription.
2. Build the Subscriptions list views.
3. Render the Status and Next Payment columns for the pending and the active subscription.

## Expected result

A "Pending Cancellation (1)" view follows Active and links to the pending cancellation filter. The pending subscription's status reads "Cancels Nov 26, 2026" and its next payment is "-". The active subscription keeps its Active status and next payment.

## Edge cases

- When no subscription is pending cancellation, the view is hidden unless it is the current view.
