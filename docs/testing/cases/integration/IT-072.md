# Account Page Builder Adds Account Page Body Class

## Scenario

A page whose content uses the Account Page Builder must be recognized as an account page, so the plugin adds the account-page body class used for account-specific styling.

## Steps

1. Create a published page whose content is an Account Page Builder containing an Account Login block.
2. With that page as the current page, ask the plugin which body classes apply.

## Expected result

- The body classes include the account-page class.

## Edge cases

- Skipped when the temporary page cannot be created.
- Skipped when the plugin's body-class handling is unavailable.
