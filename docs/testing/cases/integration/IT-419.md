# A payment plan end date in Stripe is not a pending cancellation

## Scenario

Cart creates payment-plan subscriptions in Stripe with `cancel_at` set to the end of the plan. That date alone is not a cancellation request.

## Steps

1. Start with an active Stripe payment plan with three installments and a planned end date.
2. Sync a Stripe subscription that is active with `cancel_at` on the planned end date.
3. Check the stored status and `cancel_date`.

## Expected result

The status stays active and no `cancel_date` is stored.

## Edge cases

- A `cancel_at` earlier than the planned end date is a cancellation request and marks the plan pending cancellation.
