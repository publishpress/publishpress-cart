# Checkout block consumes the shortcode instead of leaking it

## Scenario

The Checkout Form block builds on the legacy checkout shortcode internally, but that shortcode must be fully expanded into the finished form, never shown to the visitor as raw shortcode text. This verifies the block produces a rendered checkout form, not a leaked shortcode.

## Steps

1. Add a Checkout Form block for a configured product with a payment plan.
2. View the page on the frontend.

## Expected result

The visitor sees the rendered checkout form, with no raw shortcode text appearing on the page.

## Edge cases

- Requires a configured product to be available.
