# Account Profile Block Renders Current Customer Profile Form

## Scenario

The Account Profile block must render the editable profile form pre-filled with the logged-in customer's details, including their email address.

## Steps

1. As a logged-in customer, render the Account Profile block.

## Expected result

- The Account Profile block renders the editable profile form, pre-filled with the current customer's details including their email address.

## Edge cases

- Skipped when a temporary account customer cannot be created.
