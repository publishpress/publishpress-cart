# Checkout block renders sections in the configured content order

## Scenario

The Checkout Form block lets editors rearrange the checkout sections (submit button, contact info, payment plan, and so on), and the rendered page must follow that order. This verifies a custom order placing the submit button first, then contact info, then the payment plan is reflected on the page.

## Steps

1. Add a Checkout Form block for a configured product and set a custom section order beginning submit button, contact info, payment plan.
2. View the page on the frontend and check where each section appears.

## Expected result

All three sections are present and appear in the configured order: submit button before contact info before payment plan.

## Edge cases

- Requires a configured product to be available.
