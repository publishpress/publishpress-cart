# Syncing a $0 invoice twice keeps one order

## Scenario

A Stripe invoice paid by a coupon or the customer's credit balance has amount_paid 0 and no charge or PaymentIntent.

## Steps

1. Create a Stripe subscription with a first order.
2. Sync a paid $0 invoice for it.
3. Sync the same invoice again.

## Expected result

The first sync adds one $0 order and stores the invoice ID on it. The second sync adds nothing.
