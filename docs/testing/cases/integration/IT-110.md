# Account Page Builder Block Wires Its Dedicated Account Style Handles

## Scenario

The Account Page Builder block must associate the account-specific stylesheets with the block, so the editor and front end load the dedicated account styles rather than the checkout or a generic stylesheet.

## Steps

1. Load the plugin so blocks register.
2. Look up the Account Page Builder block.
3. Check that the block associates the account front-end stylesheet and the account editor stylesheet.

## Expected result

The Account Page Builder block is wired to its own account front-end stylesheet and account editor stylesheet.

## Edge cases

- Skipped on WordPress builds that do not let a block declare its associated stylesheets, since that association cannot be inspected.
