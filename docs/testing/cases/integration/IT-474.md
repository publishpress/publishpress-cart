# Subscription sync fills in the missing refund record of a refunded renewal

## Steps

1. A refunded subscription order has a pi_ transaction ID and no refund record. A second refunded order already has a record for its Stripe refund ID.
2. Stripe fully refunded both charges.
3. Sync each invoice twice, as Sync with Stripe on the subscription does.

## Expected result

The first order gets one refund log entry with the Stripe refund ID, amount and date, and the refund amount. It stays refunded. The second order keeps its refund record unchanged and its refund total is not doubled. No integrations run, no email is sent, and every Stripe request is a GET.
