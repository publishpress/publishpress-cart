# Subscription Quick Edit is populated from the selected subscription

## Scenario

An administrator opens Quick Edit from the custom Sub ID column. Although the
standard WordPress title column is not displayed, the row must still provide the
core inline data used to populate the form.

## Steps

1. Create a published subscription with a known title and date.
2. Render its Sub ID list-table column.
3. Inspect the inline data emitted for WordPress Quick Edit.

## Expected result

- The inline data is associated with the selected subscription ID.
- The stored title and publication status are present.
- The stored day and time are present instead of blank/default values.
