# Cart page

Render two products through the block, shortcode, and REST fragment. The same
rows and current server totals appear in each. Cart rendering disables page caching.

Change a price and render twice. The notice stays. Submit the rendered remove
form with its own nonce. The last removal shows the empty state and the configured
Shop link, and clears the cookie. A product that becomes ineligible is removed
with a notice when the page renders.

Apply style settings and extension total rows. The wrapper gets the shared tokens
and the summary shows the added row and display total. The priced subtotal stays
the sum of server prices.
