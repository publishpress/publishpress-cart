# The embed shell renders the product form with the saved appearance

## Scenario

A product embedded through `?ppcart-embed=1` renders its checkout form inside
the shell, with the saved `_ppcart_embed_*` values as body classes and CSS
variables, the embed stylesheet and frame bridge enqueued, the optional web font
stylesheet enqueued, and no admin bar.

## Steps

1. Save an accent color, a radius of 12, and a font URL on the product.
2. Load the product with `ppcart-embed=1` and render the shell template.

## Expected result

The output contains the submit button (`#ppcart_card_button`, testid
`ppcart-order-submit`), `:root{--ppcart-embed-accent:#ff5a1f;--ppcart-embed-radius:12px;}`,
a body with `ppcart-embed`, `ppcart-embed--accent`, and `ppcart-embed--radius`
but no `ppcart-embed--text`, the `ppcart-embed__main` landmark, links to
`ppcart-embed.css`, `ppcart-embed-frame.js`, and the font URL, and the
`show_admin_bar` filter returns false.

## Edge cases

- Unset values produce no class and no variable, so the Cart default stays.
