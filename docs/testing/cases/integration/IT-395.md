# Related Product box shows on pages and on posts that link a product

## Scenario

The Related Product box links a post to a product. When the product's checkout
closes, the post redirects. The box shows on every page, but on other post types
only when the post already links a product, so blog posts do not get it by default.

## Steps

1. Register the box for a new page.
2. Register the box for a new post with no related product.
3. Save a related product on a post, then register the box for it.
4. Add `post` with the `ppcart_related_product_post_types` filter, then register the box for a new post.
5. Run `add_metaboxes()` and check the `add_meta_boxes` action.

## Expected result

1. The page gets the `ppcart-product` box.
2. The post gets no box.
3. The post that links a product gets the box, so the link stays editable.
4. The post gets the box.
5. `add_related_product_metabox()` is hooked on `add_meta_boxes` at priority 10.
