# Checkout Block Type Wires Its Dedicated Checkout Style Handles

## Scenario

Beyond the stylesheets merely being registered (see IT-106), the Checkout Form block itself must associate them with the block, so the editor and front end load the correct checkout-specific styles rather than a shared or generic stylesheet.

## Steps

1. Load the plugin so blocks register.
2. Look up the Checkout Form block.
3. Check that the block associates the checkout front-end stylesheet and the checkout editor stylesheet.

## Expected result

The Checkout Form block is wired to its own checkout front-end stylesheet and checkout editor stylesheet.

## Edge cases

- Skipped on WordPress builds that do not let a block declare its associated stylesheets, since that association cannot be inspected.
