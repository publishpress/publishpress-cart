# A renewal for a subscription without a price option saves its line item

## Scenario

Imported subscriptions can have no price option. The renewal order's line item then got a NULL price, and the database refused to save it.

## Steps

1. Start with a Stripe subscription that has no price option and no first order.
2. Sync a paid invoice of that subscription.
3. Read the new order's line items.

## Expected result

The order has one main line item with an empty price ID.
