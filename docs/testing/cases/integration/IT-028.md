# Failed Sync Stores The Last Error Message

## Scenario

For diagnostics, a failed Stripe sync must record the human-readable reason it failed so administrators can see why a subscription is out of sync. This case verifies the failure reason is stored verbatim.

## Steps

1. Start with an active Stripe subscription.
2. Record a sync failure for it with a specific reason.

## Expected result

The subscription's last sync error is exactly the failure reason that was given.

## Edge cases

- The stored value must be the actual failure reason, not a generic placeholder.
