# Supported block themes hand product rendering back to WordPress

## Scenario

Under a supported block theme, the plugin should not force its own legacy checkout template; instead it lets WordPress render the product through the registered product block template. The plugin must leave the theme's template choice untouched for block themes.

## Steps

1. Load the plugin with a supported block theme active and start from a product.
2. Ask the plugin which template to use for that product page, providing the theme's own template.

## Expected result

The plugin returns the theme's own template unchanged, deferring to WordPress and the product block template rather than substituting a legacy checkout template.

## Edge cases

- Skipped when no supported block theme is active or no product is available.
