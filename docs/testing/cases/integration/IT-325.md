# Trusted email caller emits download links without login

## Scenario

`ppcart_build_product_notification_email()` already holds an Order. It must render `[ppcart_order_downloads]` via the trusted HTML helper, not the public shortcode gate. Otherwise guest-order emails are empty.

## Steps

1. Create a paid guest order with a file entitlement.
2. Stay logged out.
3. Build a notification whose message contains `[ppcart_order_downloads]`.

## Expected result

Email body contains the file name and a `/file/` Download key URL.
