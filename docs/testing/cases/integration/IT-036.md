# Reconciliation Query Filters On Stale Sync Metadata

## Scenario

Reconciliation should only revisit subscriptions whose last successful sync is missing or old enough to be considered stale. This case inspects the lookup that reconciliation builds and verifies a stale-sync filter is present.

## Steps

1. Trigger reconciliation and capture the lookup it builds.
2. Inspect the lookup for a stale-sync filter.

## Expected result

The lookup includes a filter that selects subscriptions by stale last-sync information.

## Edge cases

- The stale-sync filter must combine "never synced" and "synced long ago" so both kinds of subscriptions are selected.
