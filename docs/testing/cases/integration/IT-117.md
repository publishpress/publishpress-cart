# FSE product template cover prefers the featured image over the fallback

## Scenario

When a cart product does have a featured image, the product block template cover must use that featured image instead of the bundled fallback. This confirms the precedence: a set featured image wins and the fallback is not shown.

## Steps

1. Load the plugin and start from a product that has a featured image set.
2. Render the product block template for that product.

## Expected result

The product page shows the product's featured image as its cover, and the bundled fallback image is not used.

## Edge cases

- Skipped when the product template feature is unavailable, no product is available, or a featured image cannot be set up for the product.
