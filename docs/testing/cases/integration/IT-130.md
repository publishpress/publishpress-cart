# Checkout block resolves current products from filtered post types

## Scenario

Some sites register their own custom product types through the cart's extension points, and a Checkout Form block with no specific product set should still recognize those products on their own pages. This verifies that a bare block on a custom-product page renders a working checkout form.

## Steps

1. Register a custom product type so the cart treats it as a product.
2. Add a Checkout Form block with no specific product selected to a page for one of those custom products.
3. View that page on the frontend.

## Expected result

The block recognizes the current custom product and renders a working checkout form for it.

## Edge cases

- Requires a configured custom-type product to be available.
