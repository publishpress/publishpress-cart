# Orders list has a Partially Refunded view

## Scenario

An admin wants to list every order that has a partial refund.

## Steps

1. Create orders with a partial refund (stored `refund_amount`, a refund log, a formatted amount, and a manual refund that set the status to refunded).
2. Create a fully refunded order, an order with no refund, an order with a `0` refund, and a trashed partially refunded order.
3. Read the status views on the Orders list.
4. Select the Partially Refunded view.

## Expected result

A "Partially Refunded (N)" view appears right after Refunded. N counts the orders that show the "Partially refunded" label. Selecting the view lists only those orders. Fully refunded, not refunded, zero-refund and trashed orders are not listed.

## Edge cases

The view is hidden when no order is partially refunded, unless it is selected. Subscription lists don't get the view.
