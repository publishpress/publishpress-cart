# Arranged mode still fires checkout field extension hooks

## Scenario

Third-party extensions add their own fields to the checkout's payment details area. Rearranging the checkout sections must not drop those extension fields, or add-ons would silently lose them. This verifies that an extension's added field still appears when the sections are rearranged.

## Steps

1. With an extension that adds a custom field to the checkout's payment details, add a Checkout Form block for a configured product and set a custom section order.
2. View the page on the frontend.

## Expected result

The extension's added field still appears on the checkout even with the sections rearranged.

## Edge cases

- Requires a configured product to be available.
