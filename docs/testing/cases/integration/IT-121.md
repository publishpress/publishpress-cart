# Per-product "theme" template override hands rendering back to WordPress

## Scenario

A product can opt out of the plugin's checkout template by choosing to use the theme's own page template instead. When a product is set to use the theme template, PublishPress Cart must not take over rendering, even on a classic theme. This verifies that the per-product override lets WordPress render the page.

## Steps

1. Start with a configured product that is set to use the theme's page template.
2. View that product's page on a classic theme.

## Expected result

PublishPress Cart leaves the theme's chosen template in place rather than substituting its own checkout template, so rendering is handed back to WordPress.

## Edge cases

- Requires a configured product to be available.
