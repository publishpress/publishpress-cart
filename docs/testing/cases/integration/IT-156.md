# Stripe service returns false when account credentials are unusable

## Scenario

When the configured Stripe account is missing required credentials, the integration must fail safely by not building a connection rather than creating a broken one. This case verifies that a missing secret key yields no connection.

## Steps

1. Configure the Stripe account in test mode but leave the secret key empty.
2. Ask the plugin to build its Stripe connection.

## Expected result

No Stripe connection is built because the account credentials are unusable.

## Edge cases

- Skipped if the Stripe integration is not available.
