# Reconciliation Query Caps Each Batch To Fifty Records

## Scenario

To keep each reconciliation run bounded and avoid timeouts, the routine processes subscriptions in limited batches rather than all at once. This case inspects the lookup that reconciliation builds and verifies its per-batch limit.

## Steps

1. Trigger reconciliation and capture the lookup it builds.
2. Inspect the per-batch limit on that lookup.

## Expected result

The lookup caps each reconciliation batch to fifty records.

## Edge cases

- The batch limit must be exactly fifty, not unlimited, so a large backlog of stale subscriptions cannot exhaust resources in a single run.
