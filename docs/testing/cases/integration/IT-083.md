# Account Page Builder Keeps Default Inner Layout Backward Compatible

## Scenario

When no inner layout is configured, the Account Page Builder must render the same way it did before the inner-layout option existed, so pages saved earlier keep their original appearance.

## Steps

1. As a logged-in customer, render the Account Page Builder with no inner layout selected, containing the Account Navigation.

## Expected result

- The rendered account layout applies no inner-layout styling, matching the original default appearance.

## Edge cases

- Skipped when a temporary account customer cannot be created.
