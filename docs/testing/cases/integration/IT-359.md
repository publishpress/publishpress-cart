# Frontend kses preserves plan radio data-price and data-installments

## Scenario

`ppcart_kses_frontend_html()` is the sanitizer for checkout shortcode and block
output. Plan radios must still carry `data-price` and `data-installments` after
kses so storefront JS can compute amount and treat recurring plans as
subscriptions.

## Steps

1. Pass a plan radio snippet with `data-price`, `data-installments`, and
   `data-testid` through `ppcart_kses_frontend_html()`.
2. Assert those attributes are still present on the sanitized HTML.
3. Assert a disallowed `onclick` attribute is stripped.

## Expected result

Checkout plan data attributes survive kses. Event-handler attributes do not.
