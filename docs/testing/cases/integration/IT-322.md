# Guest with matching Order access token can view downloads

## Scenario

Guest thank-you pages cannot require login. Query `token` matching `_ppcart_invoice_token` is public-page proof.

## Steps

1. Create a paid guest order with a file entitlement and token.
2. Set `$_GET['token']` to that token.
3. Render the downloads shortcode and order-detail email field.

## Expected result

Download list includes the file name. Order email field is returned.
