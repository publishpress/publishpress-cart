# Account Detail REST Route Returns Owned Subscription Detail HTML

## Scenario

The account detail endpoint must return the rendered detail view for a subscription owned by the requesting customer, applying the requested slide-in presentation and a cleaned-up back link.

## Steps

1. As the logged-in customer who owns the subscription, request that subscription's detail view from the account detail endpoint, asking for a slide-in presentation and supplying a return address that still carries the subscription detail parameters.

## Expected result

- The request succeeds.
- The returned detail view shows the owned subscription using the requested slide-in presentation.
- The back link returns to the account page with the subscription detail parameters removed.

## Edge cases

- Skipped when a temporary account customer or their subscription cannot be created.
