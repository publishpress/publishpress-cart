# Cart settings and page creation

Save all Shop & Cart fields through their native settings sanitizers, then read
the stored values and the typed settings. Invalid enums fall back to the declared
default. Non-page IDs are refused, lifetimes stay positive, URLs reject scripts,
and confirmation messages preserve safe HTML.

The checkout field list includes required contact fields and the configured
optional phone, address, and terms fields. The extension filter can add fields.
Confirmation uses the cart settings. A checkout page or confirmation page URL
carries the order access token. A merchant redirect URL does not.

Create missing pages twice. The first run creates Shop, Cart, and Checkout with
their required blocks. The second run creates none. Trash one created page and
run again. Only that page is created again. Configured merchant pages and their
content remain intact.

The admin action rejects GET requests, insufficient capability, and invalid nonces.
