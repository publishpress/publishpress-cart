# Importing a Stripe payment of another customer is refused

## Scenario

The admin enters a charge that belongs to a different Stripe customer than the subscription.

## Steps

1. Create a Stripe subscription for one Stripe customer.
2. Stripe has a succeeded charge for another customer.
3. Import the charge onto the subscription.

## Expected result

The import is refused with a customer mismatch error, and no order is created.
