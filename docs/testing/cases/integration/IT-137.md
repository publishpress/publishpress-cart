# Checkout block honors intentionally blank text settings

## Scenario

Clearing a section heading should be treated as "hide this heading", not as "use the default". This verifies that a blank contact info heading hides that heading rather than restoring the default "Contact Info" text.

## Steps

1. Add a Checkout Form block for a configured product and clear the contact info heading (leave it blank).
2. View the page on the frontend.

## Expected result

The checkout omits the contact info heading entirely instead of showing the default "Contact Info" text.

## Edge cases

- Requires a configured product to be available.
