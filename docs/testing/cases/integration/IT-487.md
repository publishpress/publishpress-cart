# Manual refunds match with a decimal comma and thousand dot

## Steps

1. Set the store number format to a decimal comma and a thousand dot.
2. A refunded order migrated as "cod" has a manual refund of "1.039,00".
3. Stripe fully refunded the $1,039 charge with one refund. Run order-level Sync with Stripe.

## Expected result

The manual refund matches. The refund log has only the Stripe refund with the amount "1.039,00", the refund amount is "1.039,00", and the order log says "Manual refund of 1.039,00 matched to Stripe refund re_comma." Amounts "1.039,00", "39,00" and "39.00" read as 103900, 3900 and 3900 cents.
