# Product list shortcode copy button name

## Scenario

An admin using speech input or a screen reader reaches the Shortcode column on the Products list.

## Steps

1. Render the Shortcode column for a product.
2. Read the copy button's visible text, copy value and accessible name.

## Expected result

The visible text is the product shortcode, the button copies that same shortcode, and the accessible name is "Copy shortcode" followed by the visible shortcode (WCAG 2.5.3 Label in Name).

## Edge cases

None.
