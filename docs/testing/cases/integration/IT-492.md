# The refund amount is the Stripe refunded total

## Steps

1. A Stripe order's charge is fully refunded ($39), but Stripe lists only one $10 refund.
2. A second Stripe order's log has a $10 refund that was pending and now failed; the charge also has a succeeded $5 refund.
3. A third Stripe order's log has a manual $39 entry and the recorded Stripe refund of $39.
4. Sync each charge's refunds, as the charge.refunded webhook does.

## Expected result

The first order is refunded with a refund amount of 39.00. The second order's log has only the $5 refund and its refund amount and total are 5.00. The third order's log has only the Stripe refund, its refund amount and total are 39.00, and the order log says "Manual refund of 39.00 removed, because Stripe refund re_recorded already records it." Every Stripe request is a GET.
