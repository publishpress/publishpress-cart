# The bulk sync logs when a refund needs a check

## Steps

1. A refunded order migrated as "cod" has a manual refund of $20.00; Stripe partly refunded its charge by $10.00. A second Stripe order is paid.
2. As a Cart manager, run the Sync with Stripe bulk action on both orders.

## Expected result

Both orders sync. The first order log says "Order synced from Stripe by admin. The refund needs a check." The second says "Order synced from Stripe by admin".
