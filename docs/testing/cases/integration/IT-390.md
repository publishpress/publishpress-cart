# Echo sites escape HTML with wp_kses and keep required markup

## Scenario

The email shell and the debug log viewer echo HTML that helpers build. Each
echo site passes that HTML through `wp_kses()` with an allowlist. The allowlist
must remove `<script>` and keep the tags, SVG icons and `data-*` hooks that the
page and its JavaScript need.

## Steps

1. Render the email shell with a body that has `<strong>`, a table and a `<script>` tag.
2. Render a debug log level badge and a workflow icon, then pass each through
   `wp_kses()` with `ppcart_log_viewer_allowed_html()`.
3. Render an inspector panel for a log line that contains a `<script>` tag, then
   pass it through the same allowlist.

## Expected result

1. The email keeps `<strong>`, the table and the `<style>` block. It has no `<script>`.
2. The badge is unchanged. The icon is unchanged except for attribute-name case.
3. The panel keeps `data-ppcart-debug-*` attributes, `hidden` and `disabled`. It has no `<script>`.
