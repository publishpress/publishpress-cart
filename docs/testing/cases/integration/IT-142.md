# Leftover product-shortcode block does not render checkout in Cart alone

## Scenario

Content created before the block was renamed still uses leftover `sc-products-shortcode/product-shortcode`. Cart does not recognize that name. Rendering leftover markup through Cart alone must not produce the checkout form.

## Steps

1. Use a page that contains the leftover product checkout block for a configured product.
2. Render that content without Compatibility Mode.

## Expected result

The leftover block does not render the current checkout form.

## Edge cases

- Leftover rendering while Compatibility Mode is on is IT-351.
- Requires a configured product to be available.
