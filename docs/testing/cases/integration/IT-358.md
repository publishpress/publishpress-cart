# Tax CSV importer registers on canonical ppcart_register_importers slug

## Scenario

When `WP_LOAD_IMPORTERS` is defined, `PPCart_Admin::register_importers()` must
fire `ppcart_register_importers` so Pro (or another extension) can call
`register_importer()` with slug `ppcart_tax_rate_csv`.

## Steps

1. Define `WP_LOAD_IMPORTERS` and load `wp-admin/includes/import.php`.
2. Listen on `ppcart_register_importers` and register `ppcart_tax_rate_csv`.
3. Call `PPCart_Admin::register_importers()`.
4. Assert the hook fired and `$wp_importers['ppcart_tax_rate_csv']` exists.
5. Assert leftover `ncs-cart_tax_rate_csv` is not registered.

## Expected result

The canonical importer extension point works end-to-end with slug
`ppcart_tax_rate_csv`. Pro must migrate off `sc_register_importers` and
`ncs-cart_tax_rate_csv`.

## Edge cases

- Free-only test uses a stub callback; Pro supplies the real importer class.
