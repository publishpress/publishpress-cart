# Sync with Stripe works for a legacy StudioCart subscription

## Scenario

"Sync with Stripe" sent the StudioCart ID to Stripe, which answered "No such subscription", so the subscription's payments never imported.

## Steps

1. Create a legacy subscription with a first order: StudioCart ID in subscription_id, sub_ ID in stripe_subscription_id.
2. Stripe has two paid invoices for the sub_ ID.
3. Run Sync with Stripe on the subscription.

## Expected result

The sync reads the sub_ subscription from Stripe and imports both invoices, so the subscription has three orders.
