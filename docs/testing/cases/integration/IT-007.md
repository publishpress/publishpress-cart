# Subscription Sync Clears Next Bill Date When Subscription Is Canceled

## Scenario

When a Stripe subscription becomes canceled, the local subscription's next billing date must be removed so no future renewal date lingers. This verifies the sync clears the next billing date for a canceled subscription rather than leaving a stale value.

## Steps

1. Start with a subscription (and its first order) that has a stored next billing date and a scheduled cancellation date.
2. Run a canceled Stripe subscription through the sync.
3. Check the subscription's next billing date.

## Expected result

The next billing date is empty — the previously stored value is removed because the subscription is now canceled.

## Edge cases

- Cancellation clears the next billing date regardless of any future renewal date the incoming subscription still carries.
