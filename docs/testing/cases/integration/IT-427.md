# Invoice sync links an existing order that has no subscription

## Scenario

An order can exist for a subscription's payment without being linked to the subscription, for example one created before this fix. Syncing the subscription found the order by its charge but left it unlinked.

## Steps

1. Start with a Stripe subscription and a separate paid order with the same charge ID, no subscription and no email.
2. Sync the paid invoice for that charge.
3. Open the order.

## Expected result

The order is linked to the subscription and gets the subscription's email and customer name. No integrations run again.
