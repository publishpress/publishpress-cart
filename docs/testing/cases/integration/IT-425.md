# A renewal for a subscription whose first order is gone keeps the customer

## Scenario

A subscription imported from StudioCart or Stripe can store a first order ID that no longer exists. A renewal order copies its details from the first order, so it used to be saved with no customer, product or subscription.

## Steps

1. Start with a Stripe subscription whose stored first order doesn't exist and that has no other orders.
2. Sync a paid invoice of that subscription.
3. Open the new order.

## Expected result

The renewal order exists and is linked to the subscription. It has the subscription's email, customer name and product.
