# Admin field tooltip naming

## Scenario

A screen reader user tabs to an admin field whose label has a "?" help tooltip.

## Steps

1. Render a text field with a label, a help line and a tooltip.
2. Read the field's aria-labelledby and aria-describedby targets.
3. Render a field without a tooltip.

## Expected result

The field is named by the label text alone. It is described by the help line and the tooltip. The tooltip is a focusable `role="img"` named by its text. Fields without a tooltip keep their plain label and help description.

## Edge cases

None.
