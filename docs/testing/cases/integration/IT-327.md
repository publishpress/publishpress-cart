# Canonical Stripe metadata matches with Compatibility Mode off

## Scenario

Stripe-sync finds a local Order from charge metadata using first-party
`ppcart_order_id`. Canonical metadata matches with Compatibility Mode off.

## Steps

1. Create an Order whose transaction id does not match the fixture charge id.
2. Call `find_order_for_charge` with canonical `ppcart_order_id` (and a
   leftover `sc_order_id` that must not win).

## Expected result

Canonical `ppcart_order_id` matches. A leftover-only id on the same object
does not override it.

## Edge cases

- Charge id must not equal the Order transaction id, or trans_id fallback
  would hide metadata matching.
- Leftover `sc_*` lookup while Compatibility Mode is on is UT-235 in
  `publishpress-cart-compat`.
