# Checkout block resolves the current sc_product when no pid is set

## Scenario

When a Checkout Form block is added without naming a specific product, it should fall back to the product whose page it appears on. This verifies that a Checkout Form block with no product set renders a working checkout form for the current product page.

## Steps

1. Add a Checkout Form block with no specific product selected to a product's page.
2. View that product's page on the frontend.

## Expected result

The block renders a working checkout form for the current product.

## Edge cases

- Requires a configured product to be available.
