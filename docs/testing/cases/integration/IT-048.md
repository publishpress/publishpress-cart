# Paused subscriptions clear the local next bill date

## Scenario

When a subscription has its billing paused, no further charge is scheduled. The mapping therefore returns an empty next billing date, ignoring the current period end that would otherwise produce a date.

## Steps

1. Start with a Stripe subscription that reports active but has its billing paused, and which still carries a current period end.
2. Map the subscription.
3. Check the resulting next billing date.

## Expected result

The next billing date is empty, even though a current period end is present, because the subscription is paused.

## Edge cases

- A present current period end is intentionally ignored while paused; no next billing date is derived from it.
