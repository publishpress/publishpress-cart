# Sync corrects a Cash order that already has a Stripe charge

## Steps

1. A one-time order has the payment method "cod" and a ch_ transaction ID. Open its order screen, then run order-level Sync with Stripe.
2. A subscription order has the payment method "cod", mode "test" and a ch_ transaction ID. Sync its live-mode invoice.
3. A third order has the payment method "cod" and no Stripe ID. Run order-level Sync with Stripe on it.

## Expected result

The order screen of the first order shows "Sync with Stripe". After sync it has the payment method "stripe", mode "test" and the order log entry "Payment method set to Stripe by Stripe sync." The second order gets "stripe" and "live". The third order shows no sync button, sync refuses it with "Stripe payment ID is missing for this order.", and it keeps "cod". No integrations run, no email is sent, and every Stripe request is a GET.
