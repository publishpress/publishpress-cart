# Sync reuses a $0 order from an earlier sync and keeps two invoices apart

## Scenario

An earlier sync made a $0 order with no charge ID and no stored invoice ID.

## Steps

1. Create a Stripe subscription whose only order is a paid $0 order with no charge ID.
2. Sync a $0 invoice paid at that order's date.
3. Sync a second $0 invoice paid six hours later.

## Expected result

The first invoice links to the existing order instead of adding one. The second invoice gets its own order, and the first order keeps its invoice ID.
