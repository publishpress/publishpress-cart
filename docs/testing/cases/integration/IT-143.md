# Unregistered leftover checkout block does not leak a checkout shortcode

## Scenario

Cart no longer registers leftover `sc-products-shortcode/product-shortcode`. Rendering that persisted markup must not expand into a raw `[ppcart_form` or `[studiocart-form` shortcode.

## Steps

1. Use a page that contains the leftover product checkout block for a configured product.
2. Render that content without Compatibility Mode.

## Expected result

No raw checkout shortcode text appears.

## Edge cases

- Requires a configured product to be available.
- Leftover rendering while Compatibility Mode is on is IT-351.
