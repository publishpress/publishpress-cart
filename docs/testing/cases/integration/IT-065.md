# Security: a JSON POST missing its signature is logged as a rejected request

## Scenario

A genuine-looking webhook delivery — a JSON POST — that lacks a valid signature is suspicious and worth recording for diagnostics, unlike random browser traffic. This verifies that such a request is accepted for rejection logging and recorded as a rejected request.

## Steps

1. Start with the webhook log reset.
2. Simulate a webhook-shaped JSON POST that is missing its signature.
3. Record a missing-signature rejection for that request.
4. Read the log entries back.

## Expected result

At least one entry is written and the first entry's status is rejected, confirming a webhook-shaped JSON POST with a missing signature is logged as a rejected request.

## Edge cases

- Abnormally large request bodies are refused to avoid logging oversized payloads.
