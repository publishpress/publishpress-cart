# Nested/array context values are stripped from the stored log entry

## Scenario

To keep the log flat, predictable, and free of accidentally-captured complex payloads, only simple single-value context is persisted. This verifies that nested or list-shaped context values are dropped during sanitization while sibling simple values are kept.

## Steps

1. Start with the webhook log reset.
2. Record a webhook outcome whose context mixes a simple value (a charge id) with a nested, list-shaped value.
3. Read the first log entry and inspect its context.

## Expected result

The stored context drops the nested value while keeping simple siblings such as the charge id; complex values are silently discarded during sanitization.

## Edge cases

- Deeply nested values are never written into the log, preventing large or sensitive payloads from leaking into the file.
