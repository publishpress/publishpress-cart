# The privacy exporter exports each order and keeps the global post

## Steps

1. Create two orders for export@example.test with different first names, and one order for another email.
2. Set the global $post to a page and run the Cart personal data exporter for export@example.test.

## Expected result

The export is done and has one item per order of that email, each with its order ID, item ID "order-<ID>", first name and email. The other email's order is not exported. The global $post is still the page.
