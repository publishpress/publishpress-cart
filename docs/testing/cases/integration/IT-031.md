# Successful Sync Clears The Backoff Timestamp

## Scenario

After a subscription recovers and syncs successfully, the "do not retry before" backoff time must be removed so the record becomes immediately eligible for normal reconciliation again. This case verifies the backoff time is cleared on success.

## Steps

1. Start with an active Stripe subscription.
2. Record a failure so a backoff time is set.
3. Record a successful sync.

## Expected result

The subscription's backoff time is cleared to empty.

## Edge cases

- Clearing backoff must happen even if the stored time was still in the future at the moment of the successful sync.
