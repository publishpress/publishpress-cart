# One-time import refuses a non-product and a payment with no email

## Steps

1. Import a charge for a page, then for a post ID that doesn't exist.
2. Import a charge with no billing email, no receipt email and a customer with no email.
3. Import a charge with no billing details whose Stripe customer has an email and name.

## Expected result

Steps 1 and 2 are refused with a clear message, and no order is created. Step 3 creates an order with the customer's email and name, not linked to any user.
