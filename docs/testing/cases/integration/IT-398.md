# Embed frame headers come from the frame ancestors filter

## Scenario

An embed response sends `Content-Security-Policy: frame-ancestors` built from
`apply_filters('ppcart_embed_frame_ancestors', ['*'])`, so a site can limit
which host pages may frame its checkout.

## Steps

1. Ask the controller for its header lines with no filter.
2. Add a filter that returns `https://merchant.example` and `'self'`, and ask
   again.

## Expected result

1. `Content-Security-Policy: frame-ancestors *`
2. `Content-Security-Policy: frame-ancestors https://merchant.example 'self'`

## Edge cases

- Sources that are not CSP source expressions are dropped (UT-373).
