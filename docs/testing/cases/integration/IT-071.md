# Account Page Builder Enqueues Frontend Detail View Script

## Scenario

Rendering the Account Page Builder on the frontend must load the script that powers in-page order and subscription detail views, so the slide-in detail views work without a full page reload.

## Steps

1. Render an Account Page Builder containing an Account Login block.

## Expected result

- The account detail view script is loaded for the page.

## Edge cases

- The script is loaded during block render regardless of login state.
