# Account Navigation Block Hosts Sortable Tab Blocks

## Scenario

The Account Navigation block can contain explicit Account Tab blocks, each wrapping its own component, letting authors build custom tabbed account pages while the shared shell and active-tab behavior stay consistent.

## Steps

1. As a logged-in customer, render an Account Page Builder with an Account Navigation block containing three Account Tab blocks: Orders (wrapping Account Orders), Subscriptions (wrapping Account Subscriptions), and My Profile (wrapping Account Profile).

## Expected result

- The shared account shell appears exactly once.
- The tab list and the custom tabs are present.
- Each tab's content renders: the order history, the active subscriptions, and the profile.
- Exactly one panel is active, and it is the first tab, Orders.

## Edge cases

- Skipped when a temporary account customer cannot be created.
