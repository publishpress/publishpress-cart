# Account Block Registers Both Frontend And Editor Stylesheets

## Scenario

The account blocks ship their own front-end and editor stylesheets, both of which must be registered so WordPress can load the account styling on demand. This catches cases where one of the two account stylesheets is dropped during asset registration.

## Steps

1. Load the plugin so assets register.
2. Check whether the account front-end stylesheet is registered.
3. Check whether the account editor stylesheet is registered.

## Expected result

Both the account front-end and editor stylesheets are reported as registered.

## Edge cases

- Being registered is distinct from being loaded on a page; this case only verifies registration, not that the styles are printed on a given request.
