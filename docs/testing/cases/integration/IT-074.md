# Account Navigation Block Renders Only Selected Tabs With Active State

## Scenario

The Account Navigation block should render exactly the tabs an author included and mark the configured active tab, so customers see only the chosen navigation links.

## Steps

1. As a logged-in customer, render an Account Navigation block that includes the Orders and Profile tabs, with Profile set as the active tab.

## Expected result

- The account navigation is rendered.
- Links to the Orders and Profile tabs are present.
- The Subscriptions tab link is absent.
- One tab link is shown as active.

## Edge cases

- Skipped when a temporary account customer cannot be created.
