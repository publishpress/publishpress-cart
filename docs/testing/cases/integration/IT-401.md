# An invalid saved accent reads back as the default

## Scenario

The save path stores what the merchant typed after `sanitize_text_field`.
Validation happens when the appearance is read, so an invalid color must
never reach the embed CSS.

## Steps

1. Save the Embed tab with accent `red;}` and text color `#1d2939`.
2. Read the appearance with `ppcart_embed_appearance()`.

## Expected result

1. The accent reads back as `''`, so the Cart default color stays.
2. The valid text color reads back as `#1d2939`.

## Edge cases

- None.
