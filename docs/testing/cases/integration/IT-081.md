# Account Page Builder Supports Relative Content Max Width Units

## Scenario

The Account Page Builder must let an author set the content's maximum width using a relative length unit with a fractional value, and apply that exact value to the rendered layout.

## Steps

1. As a logged-in customer, render the Account Page Builder with its content max width set to a fractional value in a relative unit, containing the Account Navigation.

## Expected result

- The rendered account layout is constrained to the configured content max width, preserving the fractional value and the relative unit exactly as entered.

## Edge cases

- Skipped when a temporary account customer cannot be created.
