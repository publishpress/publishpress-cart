# Checkout buffers kses strip script from hook output

## Scenario

Checkout section helpers buffer hook output then echo it. That echo must pass
through `wp_kses()` with the frontend allowlist so injected scripts never reach
the page.

## Steps

1. Register `ppcart_card_details_fields` and `ppcart_order_summary_items`
   callbacks that echo a `<script>` tag plus allowed paragraph and input markup.
2. Capture `ppcart_do_remaining_card_details_fields()` and
   `ppcart_render_order_summary_items()` output.

## Expected result

- Allowed paragraph class and `data-testid` remain.
- No `<script` appears in either buffer.

## Edge cases

- Empty buffers still return without echoing.
