# Account Page Builder Renders A Single Shared Account Shell

## Scenario

Even with multiple account component blocks, the page builder must wrap them in one shared account shell and show a single active tab panel, avoiding duplicated account containers.

## Steps

1. As a logged-in customer, render an Account Page Builder containing an Account Profile block, an Account Navigation block, and an Account Orders block.

## Expected result

- The shared account shell appears exactly once.
- Exactly one tab panel is active.
- The Orders panel is the active one.
- The Profile panel is present but inactive.

## Edge cases

- Skipped when a temporary account customer cannot be created.
