# First time a webhook event id is seen, the dedupe gate opens

## Scenario

Stripe can deliver the same webhook event more than once, so the deduplication gate guards processing by remembering events it has already handled. The very first time a given event arrives, the gate must allow processing to proceed.

## Steps

1. Start with a Stripe event that has not been seen before.
2. Pass it through the deduplication gate once.

## Expected result

The first pass is allowed, signaling the event has not been seen before and may be processed.

## Edge cases

- The gate decision is based solely on the event's identifier; a brand-new event must always pass on first encounter regardless of its payload.
