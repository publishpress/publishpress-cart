# Account Subscriptions Block Presents Owned Subscription Detail In-Page

## Scenario

When a request asks to view a subscription that belongs to the current customer, the Account Subscriptions block must show that subscription's details inline using the configured slide-in presentation and a back link, with the Subscriptions tab active. This is the owner-allowed path of the subscription detail feature.

## Steps

1. As the logged-in customer who owns the subscription, request that subscription's detail view from within the account page that contains the Account Navigation with an Orders tab and a Subscriptions tab (set to the slide-in detail presentation).

## Expected result

- The account tabs render with the Subscriptions tab active and its panel shown.
- The owned subscription's details render inline within the account page using the slide-in presentation.
- A back link returns to the account page with the subscription detail parameters removed.

## Edge cases

- Skipped when a temporary account customer or their subscription cannot be created.
