# The first sync of a completed Cash order keeps its status

## Steps

1. A completed order migrated as "cod" has a ch_ transaction ID. Stripe shows the charge as succeeded.
2. Run order-level Sync with Stripe twice.

## Expected result

Each sync returns "Order synced successfully." The order stays completed and its payment method becomes "stripe". No integrations run.
