# Syncing a completed Cash order keeps it completed

## Steps

1. A completed one-time order and a completed subscription order were migrated as "cod" with ch_ transaction IDs. Stripe shows both charges as succeeded.
2. Run order-level Sync with Stripe on the one-time order and sync the subscription invoice of the other order. Do both twice.

## Expected result

Order-level sync returns "Order synced successfully." Both orders stay completed, get the payment method "stripe" and the migrated_stripe_sync flag. No integrations run.
