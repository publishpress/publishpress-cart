# Invoice Line Selection Ignores Lines Without A Subscription Item

## Scenario

If an invoice contains only product lines that are not tied to a subscription, there is no recurring product line to act on. Invoice processing must report that no subscription line was found, so the caller does not mistake a one-off line for a subscription renewal.

## Steps

1. Start with an invoice that has a single product line not tied to any subscription.
2. Run invoice line selection over that invoice.

## Expected result

No subscription product line is returned, confirming a line that carries a product but is not tied to a subscription is not treated as the subscription product line.

## Edge cases

- Being a product line alone is not enough; without a subscription association, no line qualifies.
