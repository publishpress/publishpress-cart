# Sync replaces a matching manual refund with the Stripe refund

## Steps

1. A refunded order migrated as "cod" has a pi_ transaction ID and the refund log `{"manual":{"refundID":"manual","date":"2026-11-19 23:21","amount":"39.00"}}`. One such order is a one-time order; the other belongs to a subscription.
2. Stripe fully refunded each $39 charge with one refund.
3. Run order-level Sync with Stripe on the one-time order and sync the subscription invoice of the other order. Do both twice.

## Expected result

Each refund log has only the Stripe refund: its ID, $39.00 and its date. The refund amount and the refund total are 39.00, not 78.00. The order stays refunded. The order log has "Manual refund of 39.00 matched to Stripe refund re_..." once. No integrations run, no email is sent, and every Stripe request is a GET.
