# Importing refuses an invoice payment and a subscription whose only order is unpaid

## Scenario

Import a payment is for payments with no invoice. Saving an order onto a subscription whose only order isn't paid would replace that order.

## Steps

1. Create a Stripe subscription whose only order is pending payment.
2. Stripe has a charge that paid an invoice, and a charge with no invoice, both for the subscription's customer.
3. Import the invoice charge, then the other charge.

## Expected result

Both imports are refused. The pending order is unchanged and no order has the second charge.
