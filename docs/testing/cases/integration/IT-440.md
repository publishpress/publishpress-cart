# Mini Cart and live Shop forms

Render the Mini Cart through its block and shortcode. Both produce the same
cacheable shell without a row. A disabled cart renders nothing. The count cookie
cannot change server output. Attributes control the link, badge, and style tokens.

Add a plan whose ID contains a colon. The Shop renders a live submit button and
marks only that plan as in the cart. A different plan stays available.

POST without a valid operation nonce fails without a write. A valid add takes
the server price and redirects to Cart for both drawer and Cart settings, or to
Checkout for that setting. A duplicate keeps one line. Remove needs its own
nonce and removes the line.

Request the drawer fragment. It renders escaped names, current totals, persisted
price notices, nonce-protected remove forms, and the extension slot with the
priced cart. Unknown fragment names produce no output.
