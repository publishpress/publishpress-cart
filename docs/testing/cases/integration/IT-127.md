# Checkout block uses the configured anchor as its style scope

## Scenario

When an editor gives the Checkout Form block a custom anchor, that anchor must identify the block on the page and scope its styling, so multiple checkout blocks on one page can be styled independently. This verifies the configured anchor is used both to label the block and to scope its styles.

## Steps

1. Add a Checkout Form block for a configured product and give it a custom anchor.
2. View the page on the frontend.

## Expected result

The rendered block carries the chosen anchor as its identifier, and its styling is scoped to that anchor so it does not affect other blocks.

## Edge cases

- Requires a configured product to be available.
