# Paid Invoice Sync Skips Redundant Write For Already-Synced Order

## Scenario

When an "invoice payment succeeded" event is processed for a subscription whose renewal order is already recorded as paid with the matching charge, the invoice sync must not re-save the order. This prevents Stripe invoice retries from re-touching an order that is already reconciled.

## Steps

1. Start with a subscription whose renewal order is already paid and already records the invoice's charge.
2. Note the order's last-modified time.
3. Replay the matching Stripe invoice through the sync.
4. Check the order's last-modified time again.

## Expected result

The order's last-modified time is unchanged, proving the invoice sync skips a renewal order that is already in step with the invoice's charge.

## Edge cases

- The invoice's charge must match the order's recorded transaction for the skip to happen.
