# FSE product template is scoped to the live product post type

## Scenario

The registered product block template must apply only to cart products and not take over every kind of content. The template must be scoped to the live cart product type (`sc_product` before CPT migration, `ppcart_product` after) so WordPress only uses it for products.

## Steps

1. Load the plugin and register the product block template.
2. Look up the registered product block template and read which content types it applies to.

## Expected result

The product block template is registered and scoped to the live cart product type, confirming it is bound to products only.

## Edge cases

- Skipped on WordPress versions that do not support registering product block templates, or when the product template feature is unavailable.
