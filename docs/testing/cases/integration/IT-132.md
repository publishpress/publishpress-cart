# Checkout blocks for different products render multiple live forms

## Scenario

The de-duplication only suppresses repeats of the same product, not legitimately distinct checkouts. Two Checkout Form blocks for two different products on one page should each render their own live form. This verifies distinct products yield two live forms.

## Steps

1. Add a Checkout Form block for one configured product and another for a different configured product on the same page.
2. View the page on the frontend.

## Expected result

Both products each render their own live checkout form, for two forms total.

## Edge cases

- Requires a second, distinct configured product (such as a recurring product) to be available.
