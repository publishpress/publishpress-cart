# Order table email escapes customer text fields

## Scenario

The order-details email table prints customer name, company, email, and phone.
Those values must be HTML-escaped when the table is rendered, matching the PDF
invoice bill-to block.

## Steps

1. Create a paid order whose customer fields contain markup.
2. Render the order table email partial via `ppcart_do_order_table()`.
3. Inspect the captured HTML.

## Expected result

Customer payloads are entity-escaped (`&lt;img`, `&lt;script`, `&lt;a`) so they
are not live tags. Plain name text remains. Address line breaks still use
`<br>` while street text is escaped.
