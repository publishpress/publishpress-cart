# Every Account Component Block Is Registered

## Scenario

The account experience is composed of a family of smaller component blocks (navigation, tabs, orders, and so on) that must each be registered so they can be nested inside the Account Page Builder. This case checks the whole set, failing fast if any single component block is missing.

## Steps

1. Load the plugin so blocks register.
2. Check that each account component block is registered.

## Expected result

Each of the account component blocks is reported as registered: the Account Page Builder, Account Navigation, Account Tab, Account Orders, Account Subscriptions, Account Payment Plans, Account Profile, Account Login, and Account Downloads.

## Edge cases

- The case checks the full set of account component blocks; adding or removing one requires updating the expected set.
