# Disabling the webhook log prevents any file from being created

## Scenario

Administrators can turn the webhook log off. When disabled, recording an outcome must do nothing on disk, so no log file is created and no file name is remembered.

## Steps

1. Start with the webhook log reset.
2. Turn the webhook log off.
3. Record a webhook outcome for a sample event.
4. Check whether a log file name was remembered.

## Expected result

No log file name is remembered (it stays the empty default), confirming the write was skipped before any file was created.

## Edge cases

- Logging defaults to on when the setting is unset; only explicitly turning it off disables it.
