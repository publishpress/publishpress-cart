# Update cart amount AJAX returns plain summary fields

## Scenario

Checkout order-summary refresh (`ppcart_update_cart_amount`) must not return HTML
for product titles, coupon codes, prices, or subscription terms. The storefront
builds DOM nodes and sets `.text()` from plain JSON. Receipt/item-list coupon
rows still use a badge span with an escaped coupon id.

## Steps

1. Build an in-memory order with a product name containing angle brackets and a
   coupon id containing markup. Run `calculate_final_amounts()` and
   `ppcart_prepare_update_cart_amount_response()`.
2. Load the same order through `ppcart_get_item_list()` (via the `ppcart_order`
   filter) and read the discount row `product_name`.

## Expected result

- Product summary `name` still contains `Size < 10` and has no badge span.
- Coupon summary row includes `coupon_id` with the raw code and a plain `name`
  without `<span`.
- Response `subtotal`, `total_price`, and `sub_summary` strings contain no
  `ppcart-Price-currencySymbol`, `<br>`, or `<script>`.
- Item-list discount `product_name` contains `&lt;B&gt;SAVE&lt;/B&gt;` inside the
  badge span. Coupon ids are uppercased before escaping.

## Edge cases

- Proration discount rows without `coupon_id` stay plain text in JSON.
