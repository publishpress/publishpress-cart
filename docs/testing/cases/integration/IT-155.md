# Stripe service builds a client when keys are usable but webhook id is missing

## Scenario

The Stripe integration should produce a working connection whenever the account has usable keys, even if the optional webhook identifier has not been configured. This case verifies that a missing webhook identifier does not block the connection.

## Steps

1. Configure the Stripe account in test mode with usable keys, but leave the webhook identifier unset.
2. Ask the plugin to build its Stripe connection.

## Expected result

A usable Stripe connection is created despite the missing webhook identifier.

## Edge cases

- Skipped if the Stripe integration is not available.
