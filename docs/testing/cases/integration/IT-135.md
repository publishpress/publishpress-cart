# Checkout block renders customized section headings and labels

## Scenario

The Checkout Form block lets editors rename the checkout section headings and the due-today label. Those custom names must appear in the rendered checkout. This verifies the editor's custom text replaces the default wording.

## Steps

1. Add a Checkout Form block for a configured product and rename the contact info, payment plan, payment info, and order total headings, plus the due-today label.
2. View the page on the frontend.

## Expected result

The checkout shows the editor's custom headings and the custom due-today label in place of the defaults.

## Edge cases

- Requires a configured product to be available.
