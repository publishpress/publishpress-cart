# Metabox URL, textarea, and choice fields use sanitize APIs before storage

## Scenario

`PPCart_Sanitize::clean()` stores sanitized values. It does not store HTML-escaped
values. Escaping happens at output (publishpress/publishpress-cart#917).

## Steps

1. Clean a URL with a query string, and a `javascript:` URL, as `url`, `file-upload`, and `secure-file-upload`.
2. Clean a multi-line textarea value with `&`, quotes, and a `<script>` tag.
3. Clean a `select`, `radio`, and `color` value with `&`, quotes, spaces, and a tag.

## Expected result

1. The URL is unchanged (`&` is not `&#038;`). The `javascript:` URL is empty.
2. Line breaks, `&`, and quotes stay as plain text. The tag is removed.
3. The value is trimmed, the tag is removed, and `&` and quotes are not entity-encoded.

## Edge cases

- Values saved before this change can still hold entities. Readers that decode (field maps) keep working.
