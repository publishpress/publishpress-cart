# Cart checkout form and confirmation

Render the checkout block with source Cart on a product page. It shows the cart
form with the fields from the Cart settings, the cart revision, the items, and
the total. It shows no product, plan, bump, or coupon field of the product.
`[ppcart_cart_checkout]` renders the same form. An empty cart shows the empty
state. The page is not cached.

Open the confirmation with the order ID. Without the order token the visitor
sees no order. With the token and before payment the page waits for the
payment. After payment it shows the Cart settings message and every item.

The editor preview of source Cart needs the product capability and returns the
form with a disabled Pay button and the block style tokens.
