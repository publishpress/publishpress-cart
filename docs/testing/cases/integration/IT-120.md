# Order confirmation requests keep the legacy checkout renderer

## Scenario

Order confirmation (thank-you) requests reuse the product page route but must render the legacy confirmation and checkout template rather than the block template, regardless of theme. For an order confirmation request, the plugin must use its bundled legacy template.

## Steps

1. Load the plugin and start from a product.
2. With the request treated as an order confirmation, ask the plugin which template to use for that product page.

## Expected result

The plugin returns its bundled legacy checkout template, confirming order confirmation requests stay on the legacy renderer instead of being handed back to WordPress block templates.

## Edge cases

- Skipped when no product is available.
