# Account Orders Block Presents Owned Order Detail In-Page

## Scenario

When a request asks to view an order that belongs to the current customer, the Account Orders block must show that order's details inline using the configured slide-in presentation, with a back link that returns to the account page. This is the owner-allowed path of the order detail feature.

## Steps

1. As the logged-in customer who owns the order, request that order's detail view from within the account page that contains the Account Navigation with an Orders tab (set to the slide-in detail presentation) and a Subscriptions tab.

## Expected result

- The account tabs render with the Orders tab active and its panel shown.
- The owned order's details render inline within the account page using the slide-in presentation, including the order, its order-details summary, and its invoice.
- The receipt-only layout is not shown.
- A back link returns to the account page with the order detail parameters removed.

## Edge cases

- Skipped when a temporary account customer or their order cannot be created.
