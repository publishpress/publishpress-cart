# First-party transients write and read canonical ppcart keys

## Scenario

Slice 24 stores first-party transients as `ppcart_*`. Leftover `_transient_sc_*`
copy-on-read lives in `publishpress-cart-compat`.

## Steps

1. Run `PPCart_Stripe_Sync::event_dedupe_gate()` and assert `ppcart_stripe_evt_*`
   exists and leftover `sc_stripe_evt_*` does not.
2. Write a canonical hosted-session transient and resolve return context from it.

## Expected result

First-party writes and reads `ppcart_*` only.

## Edge cases

- Object-cache leftover transients are not copied (documented gap in the
  companion leftover half).
