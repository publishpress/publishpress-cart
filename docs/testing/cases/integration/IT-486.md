# A failed Stripe charge never marks an order paid

## Steps

1. A pending-payment order migrated as "cod" has a pi_ transaction ID whose latest charge failed.
2. Run order-level Sync with Stripe, then sync the failed charge directly.

## Expected result

Order-level sync fails with "The Stripe payment for this order has not succeeded, so the order was not changed." The charge sync returns false. The order keeps its status, transaction ID and payment method. No integrations run.
