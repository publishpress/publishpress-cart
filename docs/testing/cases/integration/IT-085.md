# Account Page Builder Renders Left, Center, And Right Inner Layout Classes

## Scenario

Each alignment-based inner layout (left, center, right) must align the inner content accordingly within the container.

## Steps

1. As a logged-in customer, render the Account Page Builder once for each inner layout alignment (left, center, and right), each containing the Account Navigation.

## Expected result

- For each alignment, the rendered account content is aligned left, centered, or aligned right to match the selected inner layout.

## Edge cases

- Skipped when a temporary account customer cannot be created.
