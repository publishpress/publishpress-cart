# Account Page Builder Preserves Saved Child Block Order

## Scenario

Child blocks inside the Account Page Builder are sortable in the editor, and the frontend must render them in the exact saved order rather than a fixed sequence.

## Steps

1. As a logged-in customer, render an Account Page Builder containing, in order, an Account Profile block, an Account Navigation block, and an Account Orders block.

## Expected result

- The account page builder shell is rendered.
- All three sections are present: the profile, the navigation, and the order history.
- They appear in the saved order: profile first, then navigation, then order history.

## Edge cases

- Skipped when a temporary account customer cannot be created.
