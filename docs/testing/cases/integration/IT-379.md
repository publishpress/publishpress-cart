# Order Quick Edit is populated from the selected order

## Scenario

An administrator opens Quick Edit from the custom Order # column. Although the
standard WordPress title column is not displayed, the row must still provide the
core inline data used to populate the form.

## Steps

1. Create a published order with a known title and date.
2. Render its Order # list-table column.
3. Inspect the inline data emitted for WordPress Quick Edit.

## Expected result

- The inline data is associated with the selected order ID.
- The stored title and publication status are present.
- The stored day and time are present instead of blank/default values.
