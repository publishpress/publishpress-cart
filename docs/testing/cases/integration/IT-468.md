# One-time import matches the plan by a plain amount

## Scenario

The store uses a comma as its thousand separator. The product has a $49 Basic plan and a $1,250 Pro plan.

## Steps

1. Import a $1,250 USD charge for the product.
2. Import a 49 JPY charge for the product. JPY has no minor unit.

## Expected result

The first order is on the Pro plan, and its amount and item total are stored as the plain number 1250. The second order is on the Basic plan with amount 49 JPY.
