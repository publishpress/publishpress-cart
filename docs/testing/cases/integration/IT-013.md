# Status Meta Key Is Recognized As Stripe-Owned

## Scenario

An order or subscription's lifecycle status (such as paid or refunded) is authoritatively driven by Stripe. The owned-field registry must classify the status field as Stripe-owned so the data guard later refuses local edits to it outside a sync. This case checks the registry without any specific resource, confirming the status field is owned globally rather than only for one resource type.

## Steps

1. Ask the registry whether the status field is Stripe-owned, without naming a specific resource.

## Expected result

The status field is reported as Stripe-owned, marking the order and subscription status as a field that Stripe owns.

## Edge cases

- No resource is supplied, so the status field must be treated as Stripe-owned independent of order vs. subscription context.
