# Clearing the log deletes rotated files, not just the active one

## Scenario

When an operator clears the webhook log, every generation must be removed so no historical data lingers on disk. This verifies that clearing the log deletes the numbered backup files in addition to the active log.

## Steps

1. Start with the webhook log reset, then record enough padded entries to create a numbered backup.
2. Confirm the numbered backup exists.
3. Clear the log.

## Expected result

After clearing, the numbered backup no longer exists; clearing removes the active log, all backup generations, and the lock file.

## Edge cases

- Clearing is safe when files are missing; each file is only deleted if it exists.
