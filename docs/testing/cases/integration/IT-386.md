# Customer cancel acts only on the gateway subscription of their own record

## Scenario

The `ppcart_unsubscribe_customer` AJAX handler checks that the customer owns
the local subscription record (`id`). It also receives a `subscription_id`
gateway ID. A customer must not cancel another customer's gateway subscription
by posting that ID with their own record.

## Steps

1. Customer A owns a subscription. Log in as A and post A's record `id` with a
   different `subscription_id`.
2. Log in as customer B and post A's record `id`.

## Expected result

- For A, the cancel runs with the gateway ID stored on A's record, not the
  posted one.
- For B, no cancel runs.
