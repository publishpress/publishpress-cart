# Account downloads block kses strips script from tab hook output

## Scenario

Gutenberg account block render callbacks must return HTML passed through
`ppcart_kses_frontend_html()`. Hook output on the downloads tab must not inject
executable markup.

## Steps

1. As a logged-in customer, register a `ppcart_tab_content_tab-files` callback
   that echoes a `<script>` tag and allowed paragraph markup.
2. Render the Account Downloads block.

## Expected result

- The block wrapper is present.
- Allowed paragraph markup remains.
- No `<script` appears in the rendered output.

## Edge cases

- Same hook pattern as IT-091; this case asserts sanitization, not only presence.
