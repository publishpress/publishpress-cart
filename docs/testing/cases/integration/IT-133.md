# Checkout block plus legacy shortcode emits only one live form

## Scenario

A page may mix the new Checkout Form block and the legacy checkout shortcode for the same product, for example during migration. Both must be treated as the same checkout so only one live form appears. This verifies the block and the legacy shortcode de-duplicate together.

## Steps

1. Add a Checkout Form block for a configured product, then add the legacy checkout shortcode for the same product on the same page.
2. View the page on the frontend.

## Expected result

Only one live checkout form appears on the page.

## Edge cases

- Requires a configured product to be available.
