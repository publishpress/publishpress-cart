# The Embed tab saves its seven fields through the product metabox

## Scenario

The merchant sets the embedded checkout look on the Embed tab of a product and
updates the product. The values go through the same save path as every other
product tab, so the embed shell reads them back.

## Steps

1. Post the seven Embed tab fields with a valid metabox nonce as an administrator.
2. Run the product metabox save (`validate_meta`).
3. Read the appearance with `ppcart_embed_appearance()`.

## Expected result

1. Every value comes back: accent `#ff5a1f` (lowercased), text `#1d2939`,
   background `#fafafa`, the font stack, the Google Fonts URL with its `&`,
   radius `12` as an integer, and the button text.
2. The layout stays empty, because Free has no Layout field.

## Edge cases

- Without the `embed` field group the fields render but never save; the test then fails.
