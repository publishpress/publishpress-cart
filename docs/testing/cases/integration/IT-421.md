# Cancel at period end in Stripe marks the subscription pending cancellation

## Scenario

Stripe marks a subscription to cancel at the end of the period with `cancel_at_period_end`. Cart must show it as "Cancellation Pending" even when `cancel_at` is empty.

## Steps

1. Start with an active Stripe subscription that has no cancellation.
2. Sync a Stripe subscription that is active, with `cancel_at_period_end` true, `cancel_at` empty and `canceled_at` set.
3. Check the stored status, `cancel_date` and `cancel_at`.

## Expected result

The status stays active. `cancel_date` is the day of `canceled_at`. `cancel_at` is the current period end.

## Edge cases

- None.
