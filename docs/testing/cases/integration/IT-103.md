# New Checkout Block Registered Under PublishPress Cart Namespace

## Scenario

Loading the plugin must register the modern Checkout Form block so the editor can offer it. This guards against the block silently disappearing from the inserter when its registration fails to run.

## Steps

1. Load the plugin so blocks register.
2. Check whether the modern Checkout Form block is registered.

## Expected result

The modern Checkout Form block is reported as registered and available in the editor.

## Edge cases

- Block registration happens during WordPress initialization; the case ensures registration has run before checking.
