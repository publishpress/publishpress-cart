# Invoice Sync Does Not Restore Next Bill Date For Paused Subscriptions

## Scenario

A paused subscription intentionally has no next billing date. When an invoice arrives carrying a future period end, the invoice sync must not repopulate the next billing date for a paused subscription, otherwise a paused subscription would appear scheduled to renew.

## Steps

1. Start with a paused subscription that has no next billing date.
2. Run a Stripe invoice carrying a future period end through the sync.
3. Check the subscription's next billing date.

## Expected result

The next billing date stays empty — the future period end is not written back because the subscription is paused.

## Edge cases

- The guard keys off the paused status; an active subscription would have its next billing date updated from the invoice period end.
