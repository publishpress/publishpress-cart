# Subscription sync links a migrated Cash order and sets it to Stripe

## Steps

1. A subscription order migrated from StudioCart has the payment method "cod" (Cash), no mode and no transaction ID. Its amount and date match a paid live-mode Stripe invoice of the subscription.
2. Sync the invoice, as Sync with Stripe on the subscription does.

## Expected result

The order gets the invoice charge ID, the payment method "stripe" and the mode "live". It stays paid. No integrations run, no email is sent, and every Stripe request is a GET.
