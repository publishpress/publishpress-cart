# Failed Sync Records A Reconciliation Failure Count

## Scenario

When a Stripe sync attempt for a subscription fails, reconciliation must remember how many times it has failed so it can apply increasing backoff. This case verifies the failure count is recorded on the subscription on the first failure.

## Steps

1. Start with an active Stripe subscription.
2. Record a sync failure for it.

## Expected result

The subscription's reconciliation failure count is one after a single failure.

## Edge cases

- A first failure must start the count at one rather than leaving it empty.
