# Account Downloads Block Renders Downloads Tab Hook Output

## Scenario

The Account Downloads block must render the downloads tab and offer an extension point so files and downloads content (often supplied by add-ons) appears there.

## Steps

1. As a logged-in customer, register an add-on that adds content to the downloads tab.
2. Render the Account Downloads block.

## Expected result

- The Account Downloads block renders the downloads tab, including the content contributed by the add-on through the downloads extension point.

## Edge cases

- Skipped when a temporary account customer cannot be created.
