# Account Page Builder Renders Stretch Inner Layout Class

## Scenario

Selecting the stretch inner layout must make the inner content span the full width of the container.

## Steps

1. As a logged-in customer, render the Account Page Builder with the stretch inner layout selected, containing the Account Navigation.

## Expected result

- The rendered account content stretches to fill the full container width.

## Edge cases

- Skipped when a temporary account customer cannot be created.
