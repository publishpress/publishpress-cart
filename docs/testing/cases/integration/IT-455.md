# Stripe sync with a cart order

## Scenario

A Stripe charge can reach the site through the sync and not through the
browser. A cart order has no product metadata, so the sync must find it by the
checkout type and by the payment that the order stored.

## Steps

1. Place a cart order with Stripe. Sync a charge whose metadata names that
   order but whose payment is not the one the order stored.
2. Sync the charge of the stored payment. Then confirm the order from the
   browser.
3. Post the cart order ID to the Buy now Stripe status endpoint.

## Expected result

After the first charge the order stays pending. After the charge of the stored
payment, the order is paid and stores the charge ID. The completion work runs
one time and the cart is empty. The Buy now endpoint refuses the request, and
the order stays pending.

## Edge cases

- A later confirmation from the browser does not run the completion work again.
- The response of the Buy now endpoint holds no order token.
