# Unknown Webhook Event Type Is Ignored

## Scenario

Stripe delivers many event types, but PublishPress Cart only acts on the ones it recognizes. Any unrecognized event type must be safely ignored without side effects or errors. This case verifies the webhook handling reports an unknown event type as not handled.

## Steps

1. Hand the webhook handling an event of an unrecognized type.

## Expected result

The handling reports the event as not handled, signalling no further processing occurred.

## Edge cases

- An unrecognized event type must be reported as not handled rather than throwing or reporting a handled result.
