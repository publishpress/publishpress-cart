# Checkout Block CSS Is Served From The Gutenberg Integration Directory

## Scenario

The registered checkout stylesheets must point at the styles shipped inside the plugin's block integration folder, not a stale or external location. This confirms each registered checkout stylesheet resolves to the expected file within the plugin.

## Steps

1. Load the plugin so assets register.
2. Read the registered location of the checkout front-end stylesheet.
3. Read the registered location of the checkout editor stylesheet.

## Expected result

The checkout front-end and editor stylesheets are both served from the plugin's block integration folder, pointing at the expected checkout style files.

## Edge cases

- The location is checked by path within the plugin, so it tolerates the site address prefix and any cache-busting suffix while still pinning the file location.
