# FSE product template cover falls back to the bundled image without a featured image

## Scenario

The product block template shows a cover image at the top of the product page. When the product has no featured image, the template must show the plugin's bundled fallback image instead of an empty cover.

## Steps

1. Load the plugin and start from a product that has no featured image.
2. Render the product block template for that product.

## Expected result

The product page shows the bundled fallback image once as its cover, confirming the fallback is used when no featured image is set.

## Edge cases

- Skipped when the product template feature is unavailable or no product is available to render.
