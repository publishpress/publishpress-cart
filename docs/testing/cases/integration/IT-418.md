# A cancellation requested in Cart keeps its cancel date on sync

## Scenario

Cart already stored a `cancel_date` for a cancellation requested from Cart. A later sync of the same scheduled cancellation must not change the request date.

## Steps

1. Start with an active Stripe subscription that already has a `cancel_date`.
2. Sync a Stripe subscription that is active with `cancel_at` set and a different `canceled_at`.
3. Check the stored `cancel_date`.

## Expected result

`cancel_date` keeps its original value.

## Edge cases

- None.
