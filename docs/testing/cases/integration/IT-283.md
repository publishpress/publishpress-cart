# First-party emitters and detectors use canonical shortcode tags

## Scenario

Confirmation expands `[ppcart_receipt]`. Asset enqueue treats a stored
canonical form tag as a hit. Leftover tag enqueue and leftover email replace
live in `publishpress-cart-compat`.

## Steps

1. Expand `[ppcart_receipt]` and confirm the raw tag is consumed.
2. Put a canonical form tag in a page and check frontend-asset detection.

## Expected result

The receipt shortcode does not leak. Enqueue hits the canonical form tag.

## Edge cases

- Leftover email replace is not an `add_shortcode()` shim.
