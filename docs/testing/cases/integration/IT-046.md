# Incomplete-expired preserves the raw Stripe status in `sub_status`

## Scenario

When a Stripe subscription has the status incomplete_expired, the mapping normalizes the local status to canceled (see IT-045) but still keeps the original raw Stripe status in a separate field. This preserves the precise reason the subscription ended for reporting and debugging.

## Steps

1. Start with a Stripe subscription whose status is incomplete_expired.
2. Map the subscription.
3. Check the separate raw-status field on the result.

## Expected result

The raw-status field keeps the original incomplete_expired value, even though the normalized local status is canceled.

## Edge cases

- The local status (canceled) and the raw status (incomplete_expired) intentionally differ; the raw value is not overwritten by normalization.
