# Sync reuses an old order without a charge ID for the same payment

## Scenario

Orders migrated from old StudioCart versions have no charge ID. Sync with Stripe couldn't find them by charge, so it created a second order for each payment.

## Steps

1. Create a subscription with a paid $39 order that has no charge ID, dated 2021-07-19 17:54:18 UTC.
2. Sync a paid $39 invoice of that subscription, paid at 2021-07-19 17:54:06 UTC.
3. List the subscription's orders.

## Expected result

The subscription still has one order, and that order now has the invoice's charge ID.

## Edge cases

- A different amount, or a payment more than a day away, creates a new order.
