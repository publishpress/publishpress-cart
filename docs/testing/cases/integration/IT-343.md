# Leftover form tags do not trip first-party frontend asset detection

## Scenario

Cart first-party must not recognize leftover StudioCart shortcode tags. A page
whose content is only `[studiocart-form]` must not load heavy frontend assets
from Cart detectors. Leftover hits belong in Compatibility Mode.

## Steps

1. Ensure Compatibility Mode is off when the companion class exists.
2. Insert a page with `[studiocart-form id="1"]`.
3. Call `PPCart_Public_Asset_Controller::frontend_assets_needed()`.

## Expected result

Assets are not needed.

## Edge cases

- Canonical `[ppcart_form]` still hits (IT-283).
- Leftover hits while Compatibility Mode is on live in publishpress-cart-compat.
