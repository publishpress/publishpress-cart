# Account Login Block Renders Minimal Style Preset Class

## Scenario

Selecting the minimal style preset for the Account Login block must apply that styling while still rendering the login form.

## Steps

1. As a logged-in customer, render the Account Login block with the hide-when-logged-in option turned off and the minimal style preset selected.

## Expected result

- The Account Login block renders the login form styled with the minimal preset.

## Edge cases

- Skipped when a temporary account customer cannot be created.
