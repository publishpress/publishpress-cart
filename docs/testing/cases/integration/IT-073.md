# Account Component Blocks Add Account Page Body Class

## Scenario

Account-page detection must also trigger when the page uses an account component block such as Account Orders inside the page builder, not only the login block, so any account composition still receives the account-page body class.

## Steps

1. Create a published page whose content is an Account Page Builder containing an Account Orders block.
2. With that page as the current page, ask the plugin which body classes apply.

## Expected result

- The body classes include the account-page class.

## Edge cases

- Skipped when the temporary page cannot be created.
- Skipped when the plugin's body-class handling is unavailable.
