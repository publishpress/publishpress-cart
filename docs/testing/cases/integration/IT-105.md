# Removed Simple Account-Page Block Is Not Registered

## Scenario

The old single-purpose account-page block was replaced by the Account Page Builder and its component blocks, so it must no longer be registered. This prevents the deprecated block from reappearing in the inserter and colliding with the newer account blocks.

## Steps

1. Load the plugin so blocks register.
2. Check whether the removed standalone account-page block is registered.

## Expected result

The removed standalone account-page block is reported as not registered, confirming it was removed.

## Edge cases

- The replacement blocks (such as the Account Page Builder) remain registered; only the standalone account-page block must be absent.
