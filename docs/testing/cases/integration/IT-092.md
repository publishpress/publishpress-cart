# Account Login Block Is Hidden For Logged In Customers

## Scenario

By default the Account Login block hides itself for logged-in customers, since someone already signed in has no need for the login form.

## Steps

1. As a logged-in customer, render the Account Login block with default settings.

## Expected result

- The Account Login block renders nothing for a logged-in customer.

## Edge cases

- Skipped when a temporary account customer cannot be created.
