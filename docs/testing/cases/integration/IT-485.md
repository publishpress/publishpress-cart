# Syncing a refunded Cash order with a partial Stripe refund sets it paid without integrations

## Steps

1. A refunded one-time order and a refunded subscription order were migrated as "cod" with pi_ transaction IDs and no refund record.
2. Stripe partly refunded each $39 charge: one refund of $10.00.
3. Run order-level Sync with Stripe on the one-time order and sync the subscription invoice of the other order. Do both twice.

## Expected result

Both orders become paid, as Stripe shows them, with the Stripe refund in the refund log, a refund amount of 10.00 and the payment method "stripe". No integrations run on either sync.
