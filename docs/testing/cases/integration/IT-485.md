# Syncing a refunded Cash order with a partial Stripe refund keeps it refunded

## Steps

1. A refunded one-time order and a refunded subscription order were migrated as "cod" with pi_ transaction IDs and no refund record.
2. Stripe partly refunded each $39 charge: one refund of $10.00.
3. Run order-level Sync with Stripe on the one-time order and sync the subscription invoice of the other order. Do both twice.

## Expected result

Order-level sync returns "Order synced. The refund needs a check: see the order log." each time. Both orders stay refunded, because the rest may have been refunded outside Stripe. Each gets the Stripe refund in its refund log, a refund amount of 10.00 and the payment method "stripe". Each order log has "Stripe shows a partial refund of 10.00; the order stays refunded. Check the refunds in Stripe." once. No integrations run on either sync.
