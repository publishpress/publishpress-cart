# The first sync of a refunded Cash order with a partial Stripe refund keeps it refunded

## Steps

1. A refunded order migrated as "cod" has a pi_ transaction ID and no refund record.
2. Stripe partly refunded the $39 charge: one refund of $10.00.
3. Run order-level Sync with Stripe.

## Expected result

The order stays refunded. Its refund log has the Stripe refund, the refund amount is 10.00, and its payment method is "stripe". No integrations run.
