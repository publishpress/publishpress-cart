# Syncing a pending Cash order whose charge succeeded sets it paid without integrations

## Steps

1. A pending-payment one-time order migrated as "cod" and a pending-payment subscription order with no payment method have pi_ transaction IDs. Stripe shows both charges as succeeded.
2. Run order-level Sync with Stripe on the one-time order and sync the subscription invoice of the other order. Do both twice.

## Expected result

Both orders become paid with the charge ID as transaction ID and the payment method "stripe". No integrations run and no email is sent on either sync.
