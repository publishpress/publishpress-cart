# Importing a PaymentIntent uses its charge and refuses failed payments

## Scenario

The admin can enter a pi_ ID instead of a ch_ ID. Only successful payments can be imported.

## Steps

1. Create a Stripe subscription.
2. Stripe has a succeeded $25 PaymentIntent and a failed charge for the subscription's customer.
3. Import the PaymentIntent, then the failed charge.

## Expected result

The PaymentIntent becomes a $25 order that stores the charge ID. The failed charge is refused.
