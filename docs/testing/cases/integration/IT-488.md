# Failed and canceled refunds are left out

## Steps

1. A refunded order migrated as "cod" has a manual refund of $39.00.
2. The Stripe charge has a succeeded $39 refund, a failed refund and a canceled refund. Run order-level Sync with Stripe.

## Expected result

The manual refund matches the succeeded refund only. The refund log has only that refund, the refund amount is 39.00, and no integrations run.
