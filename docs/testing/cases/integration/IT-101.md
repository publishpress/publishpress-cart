# Account Subscriptions Block Denies Another Customer's Subscription Detail

## Scenario

A customer must never view another customer's subscription through the in-page detail view. When a request asks to view a subscription that belongs to a different customer, the Account Subscriptions block must refuse to show it. This is the access-control guard of the subscription detail feature.

## Steps

1. As a logged-in customer, request the detail view for a subscription owned by a different customer, from within the account page that contains the Account Navigation with a Subscriptions tab set to the slide-in detail presentation.

## Expected result

- A permission-denied message is shown instead of the subscription.
- The other customer's subscription details are not revealed.

## Edge cases

- Skipped when the temporary account customer or the second customer's subscription cannot be created.
