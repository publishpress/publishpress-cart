# Item building safely ignores a non-order post

## Scenario

An integration passes a non-order post ID into the order model and then asks
Free to build its item list. The rejected model has no normal order properties.

## Steps

1. Create a product post.
2. Pass its ID to the order model.
3. Build order items from the rejected model.

## Expected result

- The model identifies the post as invalid for an order.
- No undefined-property warning is emitted.
- The item builder returns an empty list.
