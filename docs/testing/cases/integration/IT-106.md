# Checkout Block Registers Both Frontend And Editor Stylesheets

## Scenario

The Checkout Form block ships separate stylesheets for the rendered front end and for the block editor, both of which must be registered so WordPress can load them on demand. This catches cases where one of the two stylesheets is dropped during asset registration.

## Steps

1. Load the plugin so assets register.
2. Check whether the checkout front-end stylesheet is registered.
3. Check whether the checkout editor stylesheet is registered.

## Expected result

Both the checkout front-end and editor stylesheets are reported as registered.

## Edge cases

- Being registered is distinct from being loaded on a page; this case only verifies registration, not that the styles are printed on a given request.
