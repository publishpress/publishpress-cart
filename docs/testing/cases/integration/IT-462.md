# Importing an invoice payment as a one-time order is refused

## Scenario

A payment that paid a Stripe invoice belongs to a subscription. Sync with Stripe imports it.

## Steps

1. Stripe has a succeeded charge that paid an invoice. The charge has no invoice field, as on the Stripe API version the SDK pins. Stripe's invoice payments for its PaymentIntent list the invoice.
2. Import it as a one-time order for a product.
3. Import another charge while Stripe's invoice payments lookup fails.
4. Import a charge that has no PaymentIntent.

## Expected result

Step 2 is refused as an invoice payment. Step 3 is refused because Cart can't check the invoice. Neither creates an order. Step 4 skips the lookup and imports.
