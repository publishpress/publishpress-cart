# Order sync fills in the missing refund record of a refunded one-time order

## Steps

1. A one-time order is refunded in Cart, has a pi_ transaction ID and no refund record. Run it once with the payment method "stripe" and once with "cod".
2. Stripe fully refunded the charge with one refund.
3. Run order-level Sync with Stripe twice.

## Expected result

The order screen shows "Sync with Stripe". After sync the refund log has one entry with the Stripe refund ID, amount and date, and the refund amount equals the Stripe refund. The second sync adds nothing. The order stays refunded, its transaction ID becomes the charge ID and its payment method is "stripe". No integrations run, no email is sent, and every Stripe request is a GET.
