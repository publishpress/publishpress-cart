# Order Customer Email Stays Locally Editable

## Scenario

The customer email on an order is store-owned data that a merchant may correct at any time, so it must not be governed by the Stripe data guard. The owned-field registry must report the email as not Stripe-owned for orders, ensuring local edits to it are never reverted. This case confirms the boundary between Stripe-owned and locally-editable fields on an order.

## Steps

1. Ask the registry whether the order customer email is Stripe-owned, in the context of an order.

## Expected result

The order customer email is reported as not Stripe-owned, so it remains locally editable and is excluded from data-guard preservation.

## Edge cases

- Contrasts with Stripe-owned fields like the status and payment status; the email must stay editable even on a Stripe-backed order.
