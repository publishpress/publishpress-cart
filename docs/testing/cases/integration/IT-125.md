# Checkout block renders its style customizations

## Scenario

The Checkout Form block lets editors customize its appearance (accent color, surface style, corner radius), and those choices must show up in the rendered form. This verifies the chosen accent color and rounded corners are reflected on the frontend.

## Steps

1. Add a Checkout Form block for a configured product and set a custom accent color, a card surface style, and rounded corners.
2. View the page on the frontend.

## Expected result

The rendered checkout form uses the chosen accent color and rounded corners.

## Edge cases

- Requires a configured product to be available.
