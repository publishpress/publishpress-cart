# Importing a payment needs exactly one of a subscription and a product

## Scenario

Import a payment adds the payment to a subscription or imports it as a one-time order. The server checks the choice, not only the form.

## Steps

1. Import a charge with both a subscription ID and a product.
2. Import it with neither.
3. Send the same two requests to the AJAX handler as a Cart manager.

## Expected result

All four are refused with a clear message. No order is created, and Stripe isn't called.
