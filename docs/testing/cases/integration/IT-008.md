# Subscription Sync Deletes Cancel-At Meta When Stripe Clears It

## Scenario

A scheduled cancellation can be cleared on Stripe's side. When the incoming subscription no longer carries a scheduled cancellation date, the local subscription's scheduled cancellation date must be removed so no stale value remains. This verifies the sync deletes the cleared scheduled cancellation date.

## Steps

1. Start with a subscription (and its first order) that has a stored next billing date and a scheduled cancellation date.
2. Run a Stripe subscription with no scheduled cancellation through the sync.
3. Check the subscription's scheduled cancellation date.

## Expected result

The scheduled cancellation date is empty — the previously stored value is removed because Stripe no longer reports a scheduled cancellation.

## Edge cases

- The absence of a scheduled cancellation is treated as "no scheduled cancellation" and triggers deletion rather than storing an empty placeholder.
