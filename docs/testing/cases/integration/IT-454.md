# Cart checkout form and confirmation

## Scenario

The checkout block with the source Cart and `[ppcart_cart_checkout]` render the
cart checkout form. After the payment, the same page shows the confirmation to
the buyer only. A payment that leaves the page must come back to this page
before the buyer goes to the confirmation.

## Steps

1. Render the checkout block with the source Cart on a product page. Render
   `[ppcart_cart_checkout]`. Render it with an empty cart.
2. Open the confirmation with the order ID and a wrong token, with the order
   token before the payment, and after the payment.
3. Set the confirmation to a redirect URL and start a card payment. Open the
   return address of the payment before the payment is complete, with a wrong
   token, without the payment reference, and after the payment is complete.
   Change the confirmation to a message and open the return address again.
4. Request the editor preview of the source Cart with and without the product
   capability.

## Expected result

The block shows the cart form with the fields from the Cart settings, the cart
revision, the items, and the total. It shows no product, plan, bump, or coupon
field of the product. The shortcode renders the same form, and the page is not
cached. With the token and before the payment, the page waits for the payment.
After the payment it shows the Cart settings message and every item. The card
payment gets a return address on the checkout page, not the redirect URL. After
the payment is complete, the return request pays the order one time and sends
the buyer to the redirect URL. With a message confirmation it sends the buyer
to the confirmation on the checkout page. The preview returns the form with a
disabled Pay button and the block style tokens.

## Edge cases

- An empty cart shows the empty state and no form.
- Without the order token the visitor sees no order.
- Before the payment is complete, with a wrong token, or without the payment
  reference, the return request sends the buyer nowhere and the order stays
  pending.
- The editor preview needs the product capability.
