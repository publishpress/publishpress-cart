# Paid Charge Sync Migrates Payment-Intent Id To Charge Id

## Scenario

After a successful charge, an order initially keyed by the Stripe payment intent should be upgraded to reference the concrete charge. This verifies the sync rewrites the recorded transaction from the payment intent to the charge so later lookups (refunds, reconciliation) resolve against the real charge.

## Steps

1. Start with an order whose recorded transaction is the Stripe payment intent.
2. Run the matching Stripe charge through the sync.
3. Check the order's recorded transaction.

## Expected result

The recorded transaction changes from the payment intent to the charge, demonstrating the sync stores the charge as the canonical transaction reference.

## Edge cases

- The incoming charge must belong to the previously recorded payment intent for the sync to recognize it as the same order and payment.
