# Order Payment Status Is Recognized As Stripe-Owned

## Scenario

An order's payment status reflects the real payment outcome held by Stripe (such as paid or refunded). Because the gateway is the source of truth for this value, the owned-field registry must flag it as Stripe-owned for orders so the data guard blocks local overwrites. This case checks the registry in the context of an order.

## Steps

1. Ask the registry whether the order payment status is Stripe-owned, in the context of an order.

## Expected result

The order payment status is reported as Stripe-owned.

## Edge cases

- The check is scoped to an order; the payment status is evaluated as owned in the order context specifically.
