# Product metabox shows help text, empty states, sections and grouped tabs

## Scenario

The product settings metabox renders field help as visible text, uses real labels,
shows an empty state for repeaters with no rows, splits plan fields into sections,
and sorts the tabs into groups.

## Steps

1. Render a checkbox and a text field that have a description.
2. Render a repeater with no saved rows and an `empty_state`, and one without it.
3. Render a repeater with a `sections` map that has a collapsed "Advanced" section.
4. Render the General tab with one field in "Product details" and two in "Page header".
5. Render the Confirmation tab fields.
6. Sort a tab list that includes a tab with no group, then move it with `ppcart_product_setting_tab_groups`.

## Expected result

1. The description is a visible paragraph linked by `aria-describedby`. The checkbox text is a `<label for>`. No tooltip is rendered.
2. With `empty_state`: the empty card and only the template row. Without it: a starter row.
3. Advanced fields are inside a closed `<details>`. Fields render in section order.
4. "Product details" renders without a card or title. "Page header" renders as a card with its title. Each row has a field-type class.
5. The fields render in one card with no title, in their original order.
6. The tab without a group joins the group of the tab before it. The filter can move it to another group.
