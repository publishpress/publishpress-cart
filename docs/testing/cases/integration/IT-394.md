# The embed shell template serves only embed requests on singular posts

## Scenario

An embed request is a singular front-end request with a non-empty
`ppcart-embed` query arg. Only those requests get the bare shell
`public/templates/embed/checkout.php` through `template_include`.

## Steps

1. Load the product permalink without the arg and ask the controller for the
   template.
2. Load it with `ppcart-embed=1`, then with `ppcart-embed=popup`.
3. Load it with an empty `ppcart-embed=`.
4. Load the home page with `ppcart-embed=1`.

## Expected result

1. The theme template comes back unchanged.
2. The shell template path comes back both times.
3. The theme template comes back unchanged.
4. The theme template comes back unchanged, because the request is not singular.

## Edge cases

- The shell wins over the product's own full-page template and over block
  themes, because it runs late on `template_include`.
