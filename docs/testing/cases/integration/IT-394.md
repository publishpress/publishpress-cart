# Product metabox shows help text, empty states, sections and grouped tabs

## Scenario

The product settings metabox renders field help as visible text, puts longer details
in a "?" tooltip, uses real labels, shows an empty state for repeaters with no rows,
splits plan fields into sections, and sorts the tabs into groups.

## Steps

1. Render a checkbox and a text field that have a description. Then render a text field and a checkbox that also have a `tooltip`.
2. Render a repeater with no saved rows and an `empty_state`, and one without it. Render a repeater with a titled row, then an untitled row. Render a repeater with a checkbox that has `new_row_value`, and one saved row without that key.
3. Render a repeater with a `sections` map that has a collapsed "Advanced" section.
4. Render the General tab with one field in "Product details" and two in "Page header".
5. Render the Confirmation tab fields, once with a `class_size` of `hide` on the second field. Render the Availability tab fields.
6. Render the Pricing tab fields, sale fields first.
7. Sort a tab list that includes a tab with no group, then move it with `ppcart_product_setting_tab_groups`.

## Expected result

1. The description is a visible paragraph linked by `aria-describedby`. The checkbox text is a `<label for>`. No tooltip is rendered without a `tooltip`. With a `tooltip`, a focusable "?" with the escaped text in `aria-label` is inside the label.
2. With `empty_state`: the empty card and only the template row. Without it: a starter row. The untitled row and the template row show the default title, not the title of the row before them. The saved row's checkbox is off; the template row's checkbox is on.
3. Advanced fields are inside a closed `<details>`. Fields render in section order.
4. "Product details" renders without a card or title. "Page header" renders as a card with its title. Each row has a field-type class.
5. The fields render in one card with no title, in their original order. With the hidden field, the section renders plain. Availability shows "Sales limits", "Checkout window" and "When checkout is closed", in that order, with the stock and customer fields in the first card.
6. The "Payment plans" card comes before the "Sale" card.
7. The tab without a group joins the group of the tab before it. The filter can move it to another group.
