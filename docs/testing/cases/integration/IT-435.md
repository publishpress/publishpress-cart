# The embed shell renders the product form

## Scenario

A product embedded through `?ppcart-embed=1` renders its checkout form inside
the shell, with the embed stylesheet and frame bridge enqueued, and no admin bar.

## Steps

1. Load the product with `ppcart-embed=1` and render the shell template.

## Expected result

The output contains the submit button (`#ppcart_card_button`, testid
`ppcart-order-submit`), a body with the class `ppcart-embed`, the
`ppcart-embed__main` landmark, links to `ppcart-embed.css` and
`ppcart-embed-frame.js`, and the `show_admin_bar` filter returns false.

## Edge cases

- None.
