# Importing a Stripe payment adds a paid order to the subscription

## Scenario

A Stripe charge has no invoice, for example one made by hand in the Stripe Dashboard. Sync with Stripe can't find it. The admin imports it from Cart > Settings > Maintenance > Import from Stripe > Import a payment.

## Steps

1. Create a Stripe subscription with a first order and a Stripe customer.
2. Stripe has a succeeded $39 charge for that customer, with no invoice.
3. Import the charge by its ch_ ID onto the subscription.
4. Import the same charge again.

## Expected result

Cart creates a paid $39 order on the subscription with the charge ID, the customer's details and the charge date. Order integrations don't run, and nothing is written to Stripe. The second import is refused and names the existing order.
