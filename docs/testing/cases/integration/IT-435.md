# Shop visibility and offers

Save a product with Show in Shop Page unchecked, then render the Shop and the
product's Buy now checkout. The setting remains `no`, the Shop omits the product,
and Buy now still renders. Checking the field stores `yes`. A save without the
General submission marker preserves the value.

Render mixed one-time and subscription plans. Only eligible one-time and free
plans appear in the selector, and text plan IDs retain colons. Subscription-only
cards link to Buy now with Subscribe. Disabled shopping carts show View.

Query filters cannot bypass published status, product types, or visibility.
Closed sales windows and exhausted stock prevent cart eligibility. Plan aliases
are rejected. Price ordering uses current plan prices before pagination.

The block and shortcode render the same catalog. The removed store shortcode
stays literal. Shared styles preserve the base look and native preset values.
