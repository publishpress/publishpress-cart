# The embed layout picks the checkout skin

## Scenario

The saved `_ppcart_embed_layout` becomes the `skin` of the `[ppcart_form]`
shortcode the shell renders (`2-step` or `normal`), which reaches the
`ppcart_checkout_template_path` filter. The 2-step template itself is Pro, so
Free proves the skin and the body class, not the tabs markup.

## Steps

1. Save the 2-step layout, capture the template argument of
   `ppcart_checkout_template_path`, and render the shell.

## Expected result

The filter received `2-step`, the body has `ppcart-embed--layout-2-step`, and
the form submit button is present.

## Edge cases

- An empty layout passes no `skin`, so the product's own display setting applies.
