# Charge Sync Does Not Flip A Fully Refunded Order Back To Paid

## Scenario

A charge can arrive marked as fully refunded. When the sync processes such a charge for an order that is already refunded, it must not regress the order back to paid. This protects refunded orders from being incorrectly reactivated by a charge.

## Steps

1. Start with a refunded order with no refunds recorded yet.
2. Run a fully refunded Stripe charge (its entire amount returned) through the sync.
3. Check the order's status.

## Expected result

The order stays refunded after the sync — the sync recognizes the fully refunded charge and does not set the order back to a paid status.

## Edge cases

- A charge whose refunded amount equals the full charge amount represents a full refund; partial refunds would follow a different path.
