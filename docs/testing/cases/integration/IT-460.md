# Importing a Stripe payment as a one-time order of a product

## Scenario

A store moved to Cart from another plugin. Stripe has a one-time purchase with no invoice and no subscription. The admin imports it from Cart > Settings > Maintenance > Import a Stripe payment, as a one-time order of a product.

## Steps

1. Create a product with a recurring plan and a one-time plan that costs $39.
2. Create a WordPress user with the email buyer@example.test.
3. Stripe has a succeeded $39 charge with no invoice. Its billing details have the buyer's email, name, phone and address. Its Stripe customer has a different email.
4. Import the charge by its pi_ ID for the product.

## Expected result

Cart creates a paid $39 one-time order for the product, with no subscription. It has the charge ID, the charge date, the one-time plan, one main order item, and the email, name, phone and address from the billing details. The order is linked to the existing user. Order integrations don't run, no user is created, and Cart only reads from Stripe.
