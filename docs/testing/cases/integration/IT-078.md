# Account Page Builder Honors Navigation Included Tabs Filter

## Scenario

When an Account Navigation block explicitly configures which tabs to include, the page builder must drop component blocks whose tabs were not included, so authors can curate which account sections appear.

## Steps

1. As a logged-in customer, render an Account Page Builder containing an Account Navigation block that is configured to include only the Orders tab, followed by an Account Orders block and an Account Subscriptions block.

## Expected result

- The Orders section content is present.
- The Subscriptions section is excluded.

## Edge cases

- Skipped when a temporary account customer cannot be created.
