# Extension repeater fields without CSS classes remain saveable

## Scenario

An extension adds an optional subfield to a product repeater without a CSS
`class` attribute. The product save schema must accept the field because the
render schema also treats `class` as optional.

## Steps

1. Add a repeater field through the product pricing-fields filter.
2. Omit the optional `class` attribute from its subfield.
3. Build the product metabox save schema.

## Expected result

- The schema is built without PHP warnings or deprecation notices.
- The extension field is included with its declared field type.
- The optional field is not marked as required.
