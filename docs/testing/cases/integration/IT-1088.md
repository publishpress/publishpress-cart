# Categories and Tags submenus list products and stay highlighted

## Steps

1. Register the Cart menu as an administrator.
2. Open the Categories and the Tags submenu links.
3. Render the count of a term that one product has.

## Expected result

Each submenu link names the taxonomy and the product post type. The link equals the submenu file WordPress sets on that screen, so the item stays highlighted, and the Cart menu stays open. The term count links to edit.php with the term and post_type set to the product post type. Categories and Tags stay before Settings in the menu.
