# Backed-Post Helper Detects A Stripe Pay-Method Order

## Scenario

The data guard needs a reliable way to decide whether a given record represents a Stripe transaction. The primary signal for an order is that its payment method is Stripe. This case verifies the detection recognizes an order whose payment method is explicitly Stripe.

## Steps

1. Start with an order whose payment method is Stripe.
2. Check whether the order is detected as Stripe-backed.

## Expected result

The order is detected as Stripe-backed because its payment method is Stripe.

## Edge cases

- Detection is driven by the payment method; a non-Stripe method (such as Cash on Delivery) would not mark the order as Stripe-backed (cf. IT-021).
