# Importing refuses an uncaptured payment and uses the captured amount

## Steps

1. Stripe has an uncaptured charge for the subscription's customer, and a $50 charge of which $30 was captured.
2. Import both onto the subscription.

## Expected result

The uncaptured charge is refused and creates no order. The other becomes a paid $30 order.
