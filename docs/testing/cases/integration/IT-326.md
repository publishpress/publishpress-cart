# Parent Order access token does not unlock a child order ID

## Scenario

Proof on the requested order covers bump/upsell children when listing files (`full=true`). A child ID plus a parent token is not enough.

## Steps

1. Create two guest orders with different Order access tokens.
2. Present the parent token.
3. Request the child order id.

## Expected result

Parent id is viewable. Child id is not. Downloads shortcode for the child id is empty.
