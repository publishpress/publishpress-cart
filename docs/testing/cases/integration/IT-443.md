# Order built from a shopping cart

Build an order from a cart with two products. The order has one main item for
each line with the server price, a total that is the sum of the items, the
customer fields, and the name "{first product} + 1 more". It has no bumps, no
coupon, and no custom fields. A one-line cart gives the product name alone.

Store the order and load it again. The checkout type is `cart` and no product
ID is stored. Both items and the paid cart lines come back. `ppcart_setup_order()`
gives a one-time plan with option `cart` and the order total. A Buy now order
is not a cart order.

Each main item gives one context with its own product, plan, amount, and
quantity, and with the ID of the parent order. A free item is included.

The `ppcart_shopping_cart_order_loaded` filter changes item amounts before the
totals are computed. A filter that returns another object is reported and
ignored. `ppcart_charge_amount` receives no product. A cart order whose item
rows are missing shows no item.
