# Preview REST route rejects users without product access

## Scenario

The checkout preview endpoint renders a product's checkout, so it must only serve users who can edit products. This access-control case verifies that an authenticated author, who cannot edit cart products, is denied even when a valid product is supplied.

## Steps

1. Sign in as a user with only the author role.
2. Request a checkout preview for a configured product as that user.

## Expected result

The request is rejected and no preview is rendered for the author.

## Edge cases

- Skipped if a configured product cannot be created.
- Skipped if the temporary author user cannot be created.
