# Terms checkbox is required

## Scenario

Automated by `tests/playwright/smoke/st009-terms-checkbox-is-required.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `checkout_terms_url` is configured for the target site.

## Steps

1. Open the checkout page configured as `checkout_terms_url`.
2. Wait for `#ppcart_accept_terms` to appear.
3. Force-submit the checkout form to trigger client-side validation.
4. Tick the terms and conditions checkbox.

## Expected result

1. The page contains "terms".
2. `#ppcart_accept_terms` is checked.

## Edge cases

- None.
