# 100 percent coupon zero total checkout

## Scenario

Automated by `tests/playwright/smoke/st036-100-percent-coupon-zero-total-checkout.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `checkout_coupon_url` is configured for the target site.

## Steps

1. Open the checkout page configured as `checkout_coupon_url`.
2. Fill `#first_name` with the configured `first_name`.
3. Fill `#last_name` with the configured `last_name`.
4. Fill `#email` with a unique test email address.
5. Fill `#phone` with the configured `phone`.
6. Click Order Now.

## Expected result

1. The page contains "Free access".
2. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.

- None.
