# Duplicate submit is prevented

## Scenario

Automated by `tests/playwright/smoke/st004-duplicate-submit-is-prevented.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `checkout_stripe_url` is configured for the target site.

## Steps

1. Open the checkout page configured as `checkout_stripe_url`.
2. Enter the Stripe test card details.
3. Fill `#first_name` with the configured `first_name`.
4. Fill `#last_name` with the configured `last_name`.
5. Fill `#email` with a unique test email address.
6. Fill `#phone` with the configured `phone`.
7. Click Order Now 2 times in quick succession.

## Expected result

1. Order Now switches to its running state and is disabled, so a second submit cannot be sent.

## Edge cases

- None.
