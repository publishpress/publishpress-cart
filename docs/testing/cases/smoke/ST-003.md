# Required checkout fields validate

## Scenario

Automated by `tests/playwright/smoke/st003-required-checkout-fields-validate.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `checkout_stripe_url` is configured for the target site.

## Steps

1. Open the checkout page configured as `checkout_stripe_url`.
2. Wait for `#email` to appear.
3. Force-submit the checkout form to trigger client-side validation.
4. Fill `#email` with "not-an-email".
5. Force-submit the checkout form to trigger client-side validation.

## Expected result

1. The page contains "required".
2. The page contains "email".

## Edge cases

- None.
