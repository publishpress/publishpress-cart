# Save Branding Settings

## Scenario

Automated by `tests/playwright/admin/ad208-save-branding-settings.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

## Steps

1. Sign in to WP Admin and open `<site>/wp-admin/admin.php?page=ppcart-settings`.
2. Click `[data-testid="ppcart-admin-settings-tab-branding"]`.
3. Click `[data-testid="ppcart-admin-field-ppcart-company-name"]`.
4. Set `[data-testid="ppcart-admin-field-ppcart-company-name"]` to "{{admin_workflow_company_name}}".
5. Click `[data-testid="ppcart-admin-field-ppcart-company-address"]`.
6. Set `[data-testid="ppcart-admin-field-ppcart-company-address"]` to "{{admin_workflow_company_address}}".
7. Click `[data-testid="ppcart-admin-settings-save-bottom"]`.

## Expected result

1. `[data-testid="ppcart-admin-settings-search"]` is present on the page.
2. `#content_tab_branding` is present on the page.
3. `body` contains "Settings saved".
4. `[data-testid="ppcart-admin-field-ppcart-company-name"]` is present on the page.
5. `[data-testid="ppcart-admin-field-ppcart-company-address"]` contains "{{admin_workflow_company_address}}".

- None.
