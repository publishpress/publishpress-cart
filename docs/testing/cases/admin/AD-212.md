# Product Embed Tab Shows And Copies The Embed Code

## Scenario

Automated by `tests/playwright/admin/ad212-product-embed-tab-shows-and-copies-embed-code.spec.ts`. The declarative steps live in `tests/playwright/support/admin-cases.ts`; the spec adds the type choice and copy checks after them. The admin fixtures are read-only, so the test creates its own product and moves it to the trash at the end.

## Steps

1. Sign in to WP Admin and open `<site>/wp-admin/post-new.php?post_type=ppcart_product`.
2. Set the title, then open the Embed tab.
3. Publish the product, reload the edit screen, and open the Embed tab again.
4. Click the Popup button card, then the Inline checkout card.
5. Click Copy on the Inline checkout code.

## Expected result

1. Before publishing, the tab shows "Publish this product to get the embed code."
2. After publishing, the tab shows the three type cards and the Inline checkout code with `data-ppcart-checkout="<permalink>"`. The other two codes are hidden.
3. The Popup button card shows the code with `data-ppcart-popup="<permalink>"` and hides the inline code.
4. Copy shows "Copied", and the clipboard holds the inline code.

## Edge cases

- Without the script, the cards are hidden and all three codes show.
