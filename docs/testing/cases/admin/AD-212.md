# Product Embed Tab Previews And Saves The Accent Color

## Scenario

Automated by `tests/playwright/admin/ad212-product-embed-tab-previews-and-saves-accent.spec.ts`. The declarative steps live in `tests/playwright/support/admin-cases.ts`; the spec adds the preview, save, and copy checks after them. The admin fixtures are read-only, so the test creates its own product and moves it to the trash at the end.

## Steps

1. Sign in to WP Admin and open `<site>/wp-admin/post-new.php?post_type=ppcart_product`.
2. Set the title, then open the Embed tab.
3. Publish the product and open the Embed tab again.
4. Click the Accent color picker and set it to `#ff5a1f`.
5. Click Update, reload the edit screen, and open the Embed tab.
6. Click Copy on the Inline checkout code.

## Expected result

1. Before publishing, the tab shows "Publish this product to get the embed code."
2. After publishing, the preview frame and the three code boxes show: the inline code has `data-ppcart-checkout=`, the popup code has `data-ppcart-popup=`, and the link has `ppcart-embed=popup`.
3. Before saving, the popup button code has `background:#ff5a1f` and the preview submit button (`#ppcart_card_button`) has background `rgb(255, 90, 31)`.
4. After update and reload, the accent field still has `#ff5a1f` and the inline code has `data-ppcart-checkout="<permalink>"`.
5. Copy shows "Copied", and the clipboard holds the inline code.

## Edge cases

- The color picker input is hidden until the picker opens, so the test clicks the picker before it types.
