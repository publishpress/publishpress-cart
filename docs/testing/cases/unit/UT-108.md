# Product Parent Relationship Is Copied

## Scenario

`ppcart_product` is hierarchical, so a child product should stay under the same parent when duplicated. This verifies `post_parent` is carried over so the copy keeps its place in the product tree.

## Steps

1. Seed the source product with `post_parent` `88`.
2. Duplicate it and read the duplicate post object.
3. Inspect its `post_parent`.

## Expected result

`post_parent` equals `88`, copied from the source so the duplicate shares the same parent product.

## Edge cases

- Intentional for hierarchical products: the copy is a sibling of the source, not re-parented to the source itself.
