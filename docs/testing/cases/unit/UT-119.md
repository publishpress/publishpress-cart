# Custom Fields Meta Is Copied

## Scenario

Admin-defined custom checkout fields live under `_sc_custom_fields`. The duplicate must inherit them so its checkout form matches the source. This verifies the `_sc_custom_fields` meta key is present on the copy.

## Steps

1. Seed the source with a `_sc_custom_fields` entry (e.g. a VAT text field).
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_custom_fields` key.

## Expected result

The duplicate's meta contains the `_sc_custom_fields` key; custom-field definitions are carried over.

## Edge cases

- Copied alongside `_sc_default_fields` (UT-118) so both built-in and custom checkout fields survive duplication.
