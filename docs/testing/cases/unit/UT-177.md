# Plain cancellation success response stays "OK"

## Scenario

When a subscription is cancelled and no refund error needs to be reported, the AJAX/redirect success response must remain the literal token `OK` that the frontend expects. This test confirms `ppcart_get_subscription_cancel_success_response()` called with no argument returns exactly that.

## Steps

1. Call `ppcart_get_subscription_cancel_success_response()` with no arguments.
2. Compare the return value to the string `OK`.

## Expected result

The function returns the exact string `OK`.

## Edge cases

- With no refund-failure message supplied, the response carries no `OK_REFUND_FAILED|...` suffix — it is just `OK`.
