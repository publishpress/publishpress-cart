# Email Body Settings Register The Canonical Kses Callback

## Scenario

Saving Settings → Email template bodies goes through `register_setting()` and WordPress `sanitize_option()`. Email HTML must use `ppcart_kses_email_html` as the sanitize callback. A leftover `sc_kses_email_html` string fatals when Compatibility Mode is off because that function is not loaded.

## Steps

1. Register one email-template `body` field and one `subject` field through the settings field registrar.
2. Capture each `register_setting()` sanitize callback.

## Expected result

- The body option's sanitize callback is the callable string `ppcart_kses_email_html`.
- The subject option still uses `sanitize_text_field`.
- The leftover name `sc_kses_email_html` is not registered.

## Edge cases

- Compatibility Mode wrappers may still define `sc_kses_email_html`; first-party `register_setting()` must not depend on that shim.
