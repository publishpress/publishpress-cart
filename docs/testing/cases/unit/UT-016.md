# Single Order Editor Remains Eligible For Version Notices

## Scenario

The version-notice carve-out applies only to the single product editor, not the order editor. Editing a single order (`post` base, `ppcart_order` post type) is a plugin screen that should still surface version/upgrade notices, so `PPCart_Admin_Screens::is_version_notice_screen()` must return `true` here.

## Steps

1. Reset the admin screen context with a screen object `{ id: 'ppcart_order', base: 'post', post_type: 'ppcart_order' }`.
2. Call `PPCart_Admin_Screens::is_version_notice_screen()`.

## Expected result

`is_version_notice_screen()` returns `true`: the `ppcart_order` post type does not match the product exclusion guard, so the method falls through to `is_plugin_screen()`, which recognizes the order editor as a plugin screen.

## Edge cases

- Sibling boundary to UT-015: identical structure but `ppcart_order` instead of `ppcart_product`, proving only the product editor is suppressed.
