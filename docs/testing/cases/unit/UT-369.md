# Upsell charges only the payment method that paid the parent order

## Scenario

Off-session upsell and downsell charges use the payment method from the parent
order's own Stripe payment. They never use the customer's default method or another
saved card.

## Steps

1. Parent order paid by `pi_parent` for `cus_guest` with `pm_parent`.
2. Look up the method again after the PaymentIntent is gone.
3. Parent payment for another customer, parent payment not paid, and no parent payment.

## Expected result

1. `pm_parent` is returned and stored on the parent order. The customer and saved cards are never read.
2. The stored method is returned.
3. No method is returned and nothing is stored.

## Edge cases

- Pro child orders copy the parent customer; the parent payment must match it.
