# Footer tracking script emits structured lead events only

## Scenario

The purchase-view footer tracker must not execute merchant-pasted `_ppcart_tracking_main` or `_ppcart_tracking_lead` snippets. Structured Meta Lead and GA `generate_lead` events print only when their options are on, and must not read product properties when no product is in scope.

## Steps

1. Render the footer tracking script with legacy snippet meta set on the product.
2. Render again with `_ppcart_fb_lead` / `_ppcart_ga_lead` on, then off.
3. Render with no product object.

## Expected result

The stored snippet never appears in the inline script. Lead events appear only when the matching option is enabled. A missing product does not emit Lead or `generate_lead` and does not read product properties.

## Edge cases

- GA type `datalayer_ga4` still uses `generate_lead`.
- Purchase `fbq('track', 'Purchase')` stays gated on an order id.
