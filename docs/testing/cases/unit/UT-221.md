# Default Debug Log Directory Stays Publishpress-Cart Logs

## Scenario

Prefix slice 17 keeps the on-disk debug log directory slug `publishpress-cart/logs` (not `ncs-cart/logs` or `studiocart/logs`). WordPress.org review stores that folder under `wp_upload_dir()['basedir']`, so the default is `wp-content/uploads/publishpress-cart/logs`. This case locks the default returned by `PPCart_Debug_Logger::resolve_log_dir()` and the debug log viewer folder path when `PPCART_DEBUG_LOG_DIR` is undefined.

## Steps

1. Invoke `PPCart_Debug_Logger::resolve_log_dir()` and `PPCart_Debug_Log_Viewer::get_log_folder_path()` while `PPCART_DEBUG_LOG_DIR` is undefined.
2. Stub `wp_upload_dir()` and assert both return `{uploads basedir}/publishpress-cart/logs`.

## Expected result

Both resolved paths equal `{uploads basedir}/publishpress-cart/logs` and do not
contain `ncs-cart` or `studiocart`.

## Edge cases

- A wp-config override (`PPCART_DEBUG_LOG_DIR`) may still point elsewhere; this case only locks the default when that constant is undefined. Compatibility Mode leftover `NCS_CART_DEBUG_LOG_DIR` is Compat-owned and is not a Cart skip gate.
- Settings-page preview is UT-356 (`PPCart_Debug_Logger::get_admin_log_data()`).
