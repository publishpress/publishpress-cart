# Debug Log Reset Clears Rotated Files

## Scenario

Resetting the debug log must wipe not only the active file but also any rotated archives, so no stale history lingers. This case first forces a rotation, then resets and verifies the `.1` archive is deleted.

## Steps

1. Instantiate `PPCart_Debug_Logger` and write 8 padded rows to force creation of a `<log_file>.1` rotation file.
2. Call `reset_log_file()` on the logger.
3. Check the filesystem for the `<log_file>.1` archive.

## Expected result

- After reset, the rotated file `<log_file>.1` no longer exists.

## Edge cases

- Multiple rotation archives (`.1`, `.2`, ...) should all be removed by a single reset.
