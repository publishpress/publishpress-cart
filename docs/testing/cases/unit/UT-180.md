# OAuth Key Source Does Not Send Destination Transfer Args

## Scenario

When the platform charges through an OAuth access token it acts on the
connected account directly, so sending `transfer_data` would make Stripe reject
the request as a destination charge. The application fee must still be applied.

## Steps

1. Leave the configured key source at its default (OAuth access token).
2. Build the payment intent args, the checkout payment intent args, and the subscription args.

## Expected result

1. None of the three argument sets contains `transfer_data`.
2. The payment and checkout intents carry an `application_fee_amount` of 20.
3. The subscription carries an `application_fee_percent` of 2.0.

## Edge cases

- A zero application fee should still omit `transfer_data`.
