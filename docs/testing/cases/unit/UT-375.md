# Only a redirect to another origin counts as leaving the site

## Scenario

An embed request answers a redirect to another site with a bounce page instead
of a 302. The check compares scheme, host and port with the site URL.

## Steps

1. Compare several targets with `https://shop.example`.

## Expected result

Another host, `http:` instead of `https:`, and another port leave the site. The
same host in another letter case, the default port written out, and a relative
path do not.

## Edge cases

- A relative URL never leaves the site.
