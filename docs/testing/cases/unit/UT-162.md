# Secret redaction strips credential patterns from free text

## Scenario

Security case. Secrets can leak into logs, error messages, and diagnostics. `ppcart_redact_secrets_from_text()` must scan arbitrary text for credential patterns (such as Stripe `sk_` keys) and replace the secret portion with a redaction marker, so the raw credential is never persisted or displayed even when it appears embedded in a larger string.

## Steps

1. Call `ppcart_redact_secrets_from_text('Stripe key sk_test_abc123xyz in log line')`.
2. Inspect the returned string for the redaction marker and for the original secret.

## Expected result

- The result contains the marker `sk_[redacted]` in place of the credential.
- The result does not contain the original secret `sk_test_abc123xyz` anywhere.

## Edge cases

- Surrounding non-secret words (`Stripe key`, `in log line`) are preserved; only the matched credential token is redacted so the message stays readable.
