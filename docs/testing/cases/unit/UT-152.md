# Empty secret-field submission preserves the stored credential

## Scenario

Security case. Secret fields are rendered as masked password inputs that submit blank when the admin does not retype the credential. `sanitize_secret_field()` must treat an empty submission as "leave unchanged" and keep the previously stored secret, rather than wiping a live credential and breaking the integration.

## Steps

1. Seed the existing option `_sc_paypal_secret` with the value `existing-secret`.
2. Call `PPCart_Secrets::sanitize_secret_field('', '_sc_paypal_secret')` (empty submitted value, option key).
3. Compare the returned value to the seeded secret.

## Expected result

- The returned value is `existing-secret`: the empty submission is ignored and the stored PayPal secret is preserved intact.

## Edge cases

- A non-empty submission would replace the stored value (and be subject to encrypt-on-write when the flag is on); only a blank submission triggers the preserve-existing path.
