# Debug Log Viewer Groups Events By Flow Id

## Scenario

The viewer's `group_entries()` collapses related entries into flow groups keyed by `flow:<flow_id>`. This case logs two events under `flow_id` `unit-checkout-1` plus one under another flow, then verifies a group exists for the first flow key.

## Steps

1. Log three events: two with `flow_id` `unit-checkout-1` (a validation-started and an order-saved) and one with `flow_id` `unit-checkout-2`.
2. Read entries and pass them to `PPCart_Debug_Log_Viewer::group_entries()`.
3. Locate the group whose `key` is `flow:unit-checkout-1`.

## Expected result

- A group keyed `flow:unit-checkout-1` is present and is returned as an array.

## Edge cases

- Entries lacking a flow id should still be grouped deterministically rather than discarded.
