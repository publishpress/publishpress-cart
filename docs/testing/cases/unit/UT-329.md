# Pro-gate filter skips Free version-notice registration

## Scenario

Free registers wordpress-version-notices settings unless `ppcart_show_version_notices` returns false. Pro adds that filter before requiring Free so the upgrade nag stays off.

## Steps

1. Stub `ppcart_show_version_notices` to false and call `PPCart_Version_Notices::register_notice_settings()`.
2. Call `register_notice_settings()` with the default true and a user who can `install_plugins`.

## Expected result

Filter false registers no notice hooks. Default registers `pp_version_notice_top_notice_settings` and `pp_version_notice_menu_link_settings`.

## Edge cases

- Files bootstrap (`ppcart_register_file_handler`) is include-time in the admin registrar template. Unit suite cannot construct that registrar without the rest of admin boot; no Files test.
