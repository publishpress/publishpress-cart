# Debug Log Download Is Denied Without The manage_options Capability

## Scenario

Security/access-control case. Downloading the debug log file is an administrator-only action. When a user without the `manage_options` capability requests a log download on the settings page, the handler must hard-deny via `wp_die()` and must not proceed to nonce verification or stream the file. This prevents non-administrators from exfiltrating log contents through the download path.

## Steps

1. Simulate a request where `$_REQUEST['page']` is `ppcart-settings` and `$_REQUEST['ppcart_download_log']` is `1`.
2. Simulate the current user lacking the `manage_options` capability.
3. Call `PPCart_Debug_Logger::view_log_request()`.

## Expected result

The handler denies the request: `wp_die()` is called (raising the simulated termination) and the nonce check (`check_admin_referer`) is never reached. The `manage_options` capability check fails closed, blocking the download before any nonce logic or file output.

## Edge cases

- The capability denial precedes nonce verification, so a valid download nonce cannot grant file access to a user lacking `manage_options`.
