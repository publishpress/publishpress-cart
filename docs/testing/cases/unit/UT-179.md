# OAuth Key Source Is Authoritative For Every Checkout Path

## Scenario

Stripe credentials can come from a Connect OAuth access token or from directly
entered keys, and that choice changes how charges are routed. Every checkout
path must read the same answer, otherwise one path could charge through Connect
while another charges directly.

## Steps

1. Leave the configured key source at its default (OAuth access token).
2. Read the Stripe Connect config from the payment, checkout, subscription, and hosted checkout paths.

## Expected result

1. All four paths report `is_oauth_access_token_key` as true.

## Edge cases

- A path that resolves credentials independently would drift from the others.
