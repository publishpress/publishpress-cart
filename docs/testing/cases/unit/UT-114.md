# Sale Stripe Price ID Is Cleared On Duplicate

## Scenario

A plan's sale price also has its own Stripe price ID (`sale_stripe_plan_id`), which is an external identity. The duplicate must not reuse the source's sale price object. This verifies the recurring plan's `sale_stripe_plan_id` is emptied on the copy.

## Steps

1. Seed the source recurring plan with `sale_stripe_plan_id` `'price_source_recurring_sale'`.
2. Duplicate it.
3. Read `_sc_pay_options[1]['sale_stripe_plan_id']` from the duplicate.

## Expected result

`_sc_pay_options[1]['sale_stripe_plan_id']` is an empty string `''`; the source's sale price id is discarded on the copy.

## Edge cases

- Both Stripe price fields on a plan row are cleared independently: regular (`stripe_plan_id`, UT-113) and sale (`sale_stripe_plan_id`, this case).
