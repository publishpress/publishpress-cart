# Product Duplicate Setting Can Re-Enable Duplicate Action

## Scenario

After duplication has been turned off, an admin can turn it back on. This verifies that storing the enable value in `_ppcart_product_duplicate_enable` returns the feature to its available state.

## Steps

1. Set the `_ppcart_product_duplicate_enable` option (`PPCart_Product_Duplicator::OPTION_NAME`) to the string `'1'`.
2. Call `PPCart_Product_Duplicator::is_enabled()`.

## Expected result

`is_enabled()` returns `true`. The stored value `'1'` is not equal to `'0'`, so the feature is enabled.

## Edge cases

- Confirms the toggle is reversible: `'0'` disables (UT-099) and `'1'` re-enables, matching the default-on behavior (UT-098).
