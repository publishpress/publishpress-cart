# Source Product Meta Is Not Mutated

## Scenario

Duplication is a read-only operation against the source: it should produce a copy without altering the original's stored meta in any way. This is the holistic guard that none of the copy/clear logic leaks back into the source's full meta array.

## Steps

1. Seed the source product and snapshot its complete meta array before duplicating.
2. Run the duplication (which clears Stripe ids and drops excluded keys on the copy).
3. Re-read the source's full meta array and compare it to the pre-duplication snapshot.

## Expected result

The source's entire meta array is identical to the snapshot taken before duplication; no key was cleared, added, or removed on the original.

## Edge cases

- Broader than UT-115/UT-124 (which check single Stripe ids): this asserts whole-array equality, proving the duplicator never mutates the source even while clearing/excluding fields on the copy.
