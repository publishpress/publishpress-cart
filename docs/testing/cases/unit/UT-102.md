# Duplicate Is A Distinct Post From The Source

## Scenario

A duplication must produce a brand-new post, never edit or alias the original. This verifies that the returned ID differs from the source ID so the original product is left untouched.

## Steps

1. Seed the source product (ID 101).
2. Call `PPCart_Product_Duplicator::duplicate($sourceId)`.
3. Compare the returned ID against the source ID.

## Expected result

The returned `$duplicate_id` is not equal to the source ID (101); `wp_insert_post` allocates a fresh post (the fixture assigns IDs starting at 2001).

## Edge cases

- Guarantees duplication creates a new record rather than reusing/overwriting the source post.
