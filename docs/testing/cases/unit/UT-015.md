# Single Product Editor Is Excluded From Version Notices

## Scenario

Although the single product editor is a plugin screen (UT-014), version/upgrade notices are deliberately suppressed there to keep the product editing surface clean. `PPCart_Admin_Screens::is_version_notice_screen()` carves out the `post` base plus canonical `ppcart_product`.

## Steps

1. Reset the admin screen context with a screen object `{ id: 'ppcart_product', base: 'post', post_type: 'ppcart_product' }`.
2. Call `PPCart_Admin_Screens::is_version_notice_screen()`.

## Expected result

`is_version_notice_screen()` returns `false` for the canonical product editor.

## Edge cases

- Contrast with UT-016: the single ORDER editor (`ppcart_order`) is NOT excluded — the carve-out is specific to the product post type.
