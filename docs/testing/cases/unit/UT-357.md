# Mailchimp helper is true only for a valid API key

## Scenario

`ppcart_has_mailchimp_api()` is the public boolean check after Free dropped
`\MailchimpMarketing\ApiClient`. It must be false without a datacenter-suffixed
key and true when `_ppcart_mailchimp_api` is a valid `key-dc` string.

## Steps

1. Stub `_ppcart_mailchimp_api` empty and call `ppcart_has_mailchimp_api()`.
2. Stub `_ppcart_mailchimp_api` to `abc123-us1` and call it again.

## Expected result

1. Returns false.
2. Returns true.

## Edge cases

- A key with no `-datacenter` suffix (`nodatacenter`) is invalid (same as empty).
