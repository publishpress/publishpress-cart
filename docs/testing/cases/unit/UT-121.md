# Coupon Repeater Meta Is Copied

## Scenario

Product-level coupons are stored in the `_sc_coupons` repeater. The duplicate must inherit the coupon configuration. This verifies the `_sc_coupons` meta key is present on the copy.

## Steps

1. Seed the source with a `_sc_coupons` entry (e.g. code `SAVE10`).
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_coupons` key.

## Expected result

The duplicate's meta contains the `_sc_coupons` key; coupon rows are carried over.

## Edge cases

- The repeater is copied (this case) but each coupon's `stripe_id` is cleared inside it (UT-123).
