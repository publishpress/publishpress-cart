# Standard Debug Log Line Detects Order Id

## Scenario

The viewer extracts the numeric order id from the message so entries can be searched and grouped per order. The id is written as `#627` in the message and must be parsed into an integer. This case verifies that extraction.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with `[05/12/2026 6:31 AM] - SUCCESS : Order #627 saved successfully with status paid.`.
2. Inspect the `order_id` field of the returned parsed array.

## Expected result

- The parsed entry's `order_id` is the integer `627` (not the string `"627"` or `"#627"`).

## Edge cases

- A message with no `#<number>` token should yield a neutral order id (e.g. `0`) rather than a partial or wrong number.
