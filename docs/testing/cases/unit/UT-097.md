# Formatted Amount Strings Parse As Decimals

## Scenario

`PPCart_Order_Refunds::parse_amount()` normalizes human-formatted money strings into plain float decimals so refund math is reliable. A value like `"$1,234.56"` carries a currency symbol and thousands separator that must be stripped, leaving the numeric decimal `1234.56`.

## Steps

1. Call `PPCart_Order_Refunds::parse_amount('$1,234.56')`.
2. The method removes commas, strips any character that is not a digit, dot, or minus sign, and casts the remaining `"1234.56"` to a float.

## Expected result

The parsed value is exactly `1234.56` (float), with the `$` and `,` removed.

## Edge cases

- Empty strings, or residue like `"-"`, `"."`, or `"-."` after stripping, parse to `0`.
- Non-scalar inputs (e.g. arrays) return `0`; numeric int/float inputs are returned cast to float unchanged.
