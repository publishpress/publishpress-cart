# Static Debug Logger Writes When Debug Logging Is Enabled

## Scenario

The logger exposes a static convenience method `log_debug_st()` for callers without an instance. When the `_sc_enable_debug` option is on, that static call must persist a readable entry. This case verifies a statically logged message is found by the viewer.

## Steps

1. With debug logging enabled (`_sc_enable_debug` = 1), call `PPCart_Debug_Logger::log_debug_st('Static logger writes when debug is enabled.', 1)`.
2. Call `PPCart_Debug_Log_Viewer::read_entries(['limit' => 10, 'search' => 'Static logger writes'])`.
3. Confirm a matching entry exists.

## Expected result

- `read_entries()` returns at least one entry for the searched text, proving the static logger wrote the line.

## Edge cases

- When debug logging is disabled, the static logger should write nothing.
