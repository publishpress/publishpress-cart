# Core WP-Admin Dashboard Screen Is Not A Plugin Screen

## Scenario

The WordPress dashboard (`index.php`) has a screen whose `id`/`base` is `dashboard`. The Cart detector must explicitly exclude core dashboard screens so plugin assets and notices never render on the main WP dashboard. `PPCart_Admin_Screens::is_plugin_screen()` short-circuits to `false` for excluded core bases regardless of other signals.

## Steps

1. Reset the admin screen context with a screen object `{ id: 'dashboard', base: 'dashboard' }`, empty query and request.
2. Call `PPCart_Admin_Screens::is_plugin_screen()`.

## Expected result

`is_plugin_screen()` returns `false`: `dashboard` is in the excluded core admin bases, so the early exclusion check rejects the request before any positive detection runs.

## Edge cases

- Establishes the core-screen exclusion; UT-008 proves this exclusion wins even when a Cart menu parent is also present.
