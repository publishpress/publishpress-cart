# Product Categories Are Copied

## Scenario

Products are organized via the `ppcart_product_cat` taxonomy. The duplicate must keep the same category assignments. This verifies the source's category term IDs are reassigned to the copy.

## Steps

1. Seed the source with `ppcart_product_cat` terms `[11, 12]`.
2. Duplicate it (`copy_taxonomies` re-applies term ids via `wp_set_object_terms`).
3. Read the duplicate's `ppcart_product_cat` terms.

## Expected result

The duplicate's `ppcart_product_cat` terms equal `[11, 12]`, copied from the source.

## Edge cases

- Term ids are reused (the copy shares the same category terms), preserving order; one of three product taxonomies copied (with tags UT-141 and the custom taxonomy UT-142).
