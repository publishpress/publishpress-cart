# Debug Log View Is Denied Without The manage_options Capability

## Scenario

Security/access-control case. Viewing the debug log is an administrator-only action. When a user without the `manage_options` capability requests to view the log on the settings page, the handler must hard-deny via `wp_die()` and must not proceed to nonce verification or emit any log content. This enforces the capability gate as the primary authorization barrier for reading log data.

## Steps

1. Simulate a request where `$_REQUEST['page']` is `ppcart-settings` and `$_REQUEST['ppcart_view_log']` is `1`.
2. Simulate the current user lacking the `manage_options` capability.
3. Call `PPCart_Debug_Logger::view_log_request()`.

## Expected result

The handler denies the request: `wp_die()` is called (raising the simulated termination) and the nonce check (`check_admin_referer`) is never reached. The `manage_options` capability check fails closed, blocking the view before any nonce logic or output.

## Edge cases

- The capability denial occurs before nonce verification, so an attacker cannot bypass authorization by supplying a valid nonce without the required capability.
