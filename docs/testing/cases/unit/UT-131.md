# Shipping Amount Meta Is Copied

## Scenario

The flat shipping charge for a product is stored under `_sc_shipping_single`. The duplicate must inherit this value. This verifies the `_sc_shipping_single` meta key is present on the copy.

## Steps

1. Seed the source with `_sc_shipping_single` set to `'9.99'`.
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_shipping_single` key.

## Expected result

The duplicate's meta contains the `_sc_shipping_single` key; the shipping amount is carried over.

## Edge cases

- Paired with the enable toggle (UT-130): both the on/off flag and the price are copied.
