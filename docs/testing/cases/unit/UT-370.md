# Admin field sections sort fields without changing the field arrays

## Scenario

The product metabox shows fields in titled sections. A render-time map, keyed by
field ID, puts each field in a section. Code in Free and Pro splices the field
arrays by position, so the arrays themselves never change.

## Steps

1. Group fields that the map lists, in an order different from the array.
2. Group a field that the map does not list, after a listed field.
3. Group an unlisted field that comes after a field in a collapsed ("details") section.
4. Group fields with string keys, and a map with a section that gets no fields.

## Expected result

1. Each field is in its section, in the order of the section list.
2. The unlisted field stays right after the field before it.
3. The unlisted field goes to the first open section, so add-on fields are never hidden.
4. The original field keys are kept, and the empty section is left out.
