# Embed appearance sanitize keeps valid values and empties invalid ones

## Scenario

`PPCart_Embed_Appearance::sanitize()` is the one place that validates the eight
`_ppcart_embed_*` product values before the embed shell and the admin preview use
them.

## Steps

1. Sanitize a full set of valid values with an unknown extra key.
2. Sanitize a set where every value is invalid (bad layout, bad colors, a font
   family with a tag, an `http:` font URL, a radius above 24, a 61-character
   button text).
3. Sanitize a font URL with a quote and one with a space, a negative radius, and
   a zero radius.
4. Sanitize a non-array and a value that is an array.

## Expected result

1. All eight keys come back, colors lowercased, the radius as the integer 12,
   the button text without tags, and the unknown key dropped.
2. Every key is `''`.
3. Both font URLs and the negative radius are `''`; the zero radius stays `0`.
4. All eight keys are `''` and nothing throws.

## Edge cases

- Whitespace around a value is trimmed before validation.
