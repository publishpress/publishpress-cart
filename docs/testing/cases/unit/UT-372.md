# Embed CSS variables declare only the set appearance values

## Scenario

The embed shell prints `:root{...}` with one custom property per set value. The
admin live preview sets the same properties, so both must agree on names and
units.

## Steps

1. Build the declarations for accent, text, background, font family, and a
   radius of 12.
2. Build the declarations for an empty appearance and for a radius of 0.

## Expected result

1. `--ppcart-embed-accent:#ff5a1f;--ppcart-embed-text:#222222;--ppcart-embed-bg:#ffffff;--ppcart-embed-font:'Inter', sans-serif;--ppcart-embed-radius:12px;`
2. An empty string, then `--ppcart-embed-radius:0px;`.

## Edge cases

- The font URL and button text never become a variable.
