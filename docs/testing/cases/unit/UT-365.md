# Logged-in checkout reuses only the user's own stored customer

## Scenario

A logged-in user gets the same Stripe customer on later checkouts, but only the
customer that a checkout created for that user account.

## Steps

1. As user 7, create a customer.
2. Read the stored customer for user 7 in `test` and `live` mode, and for user 8.
3. Mark the customer as deleted in Stripe and read it again.

## Expected result

1. The new customer is stored on user 7.
2. User 7 gets it in `test` mode only. User 8 gets nothing.
3. A deleted customer is not reused.

## Edge cases

- A customer found by the account email is not trusted; only the stored ID counts.
