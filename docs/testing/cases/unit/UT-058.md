# Flow Group Title Explains Checkout Save Phase

## Scenario

Each flow group gets a human-readable title summarizing what happened. For a checkout flow that ends in an order save, the title should name the phase and the order. This case verifies the generated title for the `unit-checkout-1` flow that saved order 702.

## Steps

1. Log a validation-started event and an order-saved event (Order #702) under `flow_id` `unit-checkout-1`.
2. Build groups via `group_entries()` and select the `flow:unit-checkout-1` group.
3. Inspect the group's `title` field.

## Expected result

- The group's `title` is exactly `Checkout saved Order #702`.

## Edge cases

- A checkout flow that did not reach the save phase should yield a different, phase-appropriate title rather than this one.
