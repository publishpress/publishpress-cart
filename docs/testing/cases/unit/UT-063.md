# Payment Confirmation Group Title Explains Paid Transition

## Scenario

When a flow moves an order from an unpaid status into `paid`, the group title should communicate that payment was confirmed. This case verifies the title for a flow whose order 705 transitions from `pending-payment` to `paid`.

## Steps

1. Parse two lines under `flow_id` `unit-payment-confirmed`: an `order.save.started` event (status `paid`) and an `order.save.updated` event with `previous_status` `pending-payment` and `status` `paid`, both for order 705.
2. Assign sequences and pass both entries to `group_entries()`.
3. Inspect the resulting group's `title`.

## Expected result

- The group's `title` is exactly `Payment confirmed for Order #705`, reflecting the unpaid-to-paid transition.

## Edge cases

- A flow that stays in an unpaid status throughout should not be titled as a payment confirmation.
