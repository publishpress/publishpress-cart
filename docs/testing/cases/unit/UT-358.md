# Plan without a price resolves to zero

## Scenario

A payment plan can be saved with no price. `ppcart_plan()` must still return
that plan, with an empty price and a zero initial payment, and must not emit
an undefined-index warning.

## Steps

1. Resolve a plan whose pay option has an option id and name, and no price.
2. Resolve the same plan after a price of `19.00` is stored.

## Expected result

1. Price is an empty string, initial payment is `0.0`, and PHP emits no warning.
2. Price stays `19.00` and initial payment is `19.0`.

## Edge cases

- A free plan still returns the price string `free`.
