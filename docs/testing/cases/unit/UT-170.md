# Credit note refund amount equals the credited amount

## Scenario

When the credit note is created with a refund, Stripe expects both the credit-note `amount` and the `refund_amount` to match so the full remaining balance is returned to the customer. This test confirms the `refund_amount` sent to Stripe equals the computed refundable amount.

## Steps

1. Build a Stripe client stub whose latest invoice `in_test` has `amount_paid = 2000` and `post_payment_credit_notes_amount = 500`.
2. Call `ppcart_issue_stripe_subscription_cancellation_refund()` with order `{ id: 321, subscription_id: 'sub_test' }` and subscription `{ id: 'sub_test', latest_invoice: 'in_test' }`.
3. Read `creditNotes->last_args['refund_amount']` captured by the stub.

## Expected result

The credit note is requested with `refund_amount = 1500`, matching the credited `amount` of `1500` (`2000 - 500`).

## Edge cases

- `refund_amount` and `amount` are kept identical; a mismatch would leave part of the invoice credited but not refunded.
