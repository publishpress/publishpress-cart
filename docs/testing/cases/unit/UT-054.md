# Log Event Redacts Sensitive Structured Context Before Writing

## Scenario

SECURITY/PRIVACY. When `log_event()` receives a sensitive value such as `client_secret` in its context, the secret must be masked at write time so it is never persisted to disk in clear text. This case verifies the stored entry reads back the secret as redacted.

## Steps

1. Instantiate `PPCart_Debug_Logger` and call `log_event('checkout.order.saved', 'Order saved successfully.', ['order_id' => 701, 'status' => 'paid', 'client_secret' => 'secret_value'], 0)`.
2. Call `PPCart_Debug_Log_Viewer::read_entries(['limit' => 10, 'search' => '701'])`.
3. Inspect `context['client_secret']` of the first entry.

## Expected result

- `entries[0]['context']['client_secret']` equals `[redacted]`; the real value `secret_value` is never written to the log file.

## Edge cases

- Redaction occurs before persistence, so even direct inspection of the on-disk log must not reveal the secret.
