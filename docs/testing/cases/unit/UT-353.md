# Review banner only on Cart dashboard and settings for managers

## Scenario

`PPCart_Reviews` boots wordpress-reviews on `admin_init` (user is authenticated
by then). `should_display_banner()` is the screen gate: managers on Cart
dashboard (`ppcart`) or settings (`ppcart-settings`) only. Pro can skip with
`ppcart_show_reviews`.

## Steps

1. Call `init()` as admin and record `add_action` hooks.
2. Stub `ppcart_show_reviews` false and call `register_reviews()`.
3. Call `should_display_banner(true)` with `is_admin` false and `page=ppcart`.
4. Call it as admin without `manage_options` on `page=ppcart`.
5. Call it as a manager on `page=plugins`.
6. Call it as a manager on `page=ppcart`.
7. Call it as a manager on `page=ppcart-settings`.

## Expected result

1. Registers `admin_init`, not `plugins_loaded`.
2. Registers no filters.
3–5 return false. 6–7 return true.

## Edge cases

- Library still requires the current user to have the administrator role.
- `PUBLISHPRESS_CART_SKIP_REVIEWS` skips `init()` entirely.
