# Structured Context Redacts Client Secrets

## Scenario

SECURITY/PRIVACY. Structured context can include sensitive Stripe values such as `client_secret`, which must never be displayed in the admin log viewer. The parser must mask such fields when reading a stored line. This case verifies the `client_secret` value is redacted on parse.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with `[05/12/2026 6:32 AM] - STATUS : Stripe PaymentIntent created successfully. context={"event":"checkout.payment_intent.created","order_id":627,"client_secret":"pi_secret","charge_id":"ch_123"}`.
2. Inspect `context['client_secret']` in the returned parsed array.

## Expected result

- `context['client_secret']` equals `[redacted]`; the real value `pi_secret` never appears in the parsed entry.

## Edge cases

- Other secret-bearing keys carried in context must be redacted with the same masking, not just `client_secret`.
