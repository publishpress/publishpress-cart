# Embedded Json Redacts Nonce Values

## Scenario

SECURITY/PRIVACY. Embedded JSON payloads can include a `nonce`, which is a security token that must never be rendered in the log viewer. The parser must mask it just like other secrets. This case verifies the `nonce` from inline JSON is redacted.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with `[05/12/2026 6:33 AM] - WARNING : Checkout form validation failed. {"product_id":45,"nonce":"abc"}`.
2. Inspect `context['nonce']` in the returned parsed entry.

## Expected result

- `context['nonce']` equals `[redacted]`; the real value `abc` never appears in the parsed entry.

## Edge cases

- Redaction must apply to nonce values regardless of whether they arrive via embedded JSON or the `context=` payload.
