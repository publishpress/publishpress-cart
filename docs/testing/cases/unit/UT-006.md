# `publishpress-cart` Slug Is Not Recognized As The Dashboard

## Scenario

The public plugin slug is `publishpress-cart`, while the canonical dashboard page slug is `ppcart`. A request at `?page=publishpress-cart` must not be treated as the dashboard by `PPCart_Admin_Screens::is_dashboard_screen()`, otherwise dashboard logic would fire on the wrong slug.

## Steps

1. Reset the admin screen context with `$_GET['page'] = 'publishpress-cart'` and no screen object.
2. Call `PPCart_Admin_Screens::is_dashboard_screen()`.

## Expected result

`is_dashboard_screen()` returns `false`: `publishpress-cart` does not equal the dashboard slug `ppcart` nor the dashboard hook, so it is not the dashboard screen.

## Edge cases

- Direct counterpart to UT-005: same method, different slug, opposite result.
