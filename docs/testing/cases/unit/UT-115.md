# Source Payment Plan Stripe ID Is Not Mutated

## Scenario

Clearing Stripe ids on the copy must never leak back onto the original. The source product still needs its real `stripe_plan_id` to keep billing working. This verifies that duplication leaves the source plan's Stripe id intact.

## Steps

1. Seed the source recurring plan with `stripe_plan_id` `'price_source_recurring'`.
2. Run the duplication.
3. Re-read the source's stored `_sc_pay_options` and unserialize it; inspect row 1's `stripe_plan_id`.

## Expected result

The source's `_sc_pay_options[1]['stripe_plan_id']` is still `'price_source_recurring'`; only the copy's value was cleared.

## Edge cases

- Verifies the clear operates on the duplicate's copy of the meta, not the source array (no by-reference mutation).
