# Old Slug Meta Is Not Copied

## Scenario

`_wp_old_slug` stores the source post's previous permalink slugs for redirect handling. It belongs only to the original URL history and must not be inherited by a new draft. This verifies `_wp_old_slug` is excluded and absent from the duplicate.

## Steps

1. Seed the source with `_wp_old_slug` (e.g. `'configured-product'`).
2. Duplicate it and read the duplicate's full meta array.
3. Assert the `_wp_old_slug` key is missing.

## Expected result

The duplicate's meta does not contain `_wp_old_slug`; it is filtered out by `get_excluded_meta_keys()`.

## Edge cases

- "Not copied" WP-internal meta; prevents the copy from hijacking the source's old-permalink redirects.
