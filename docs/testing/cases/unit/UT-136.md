# Edit Lock Meta Is Not Copied

## Scenario

`_edit_lock` is WordPress's transient "who is editing this post" marker, meaningful only to the original post. Copying it would carry a stale lock onto a brand-new draft. This verifies `_edit_lock` is in the excluded list and absent from the duplicate.

## Steps

1. Seed the source with `_edit_lock` (e.g. `'123:1'`).
2. Duplicate it and read the duplicate's full meta array.
3. Assert the `_edit_lock` key is missing.

## Expected result

The duplicate's meta does not contain `_edit_lock`; it is filtered out by `get_excluded_meta_keys()`.

## Edge cases

- A "not copied" case (key absent), the opposite of copied configuration meta; grouped with `_edit_last` (UT-137) and `_wp_old_slug` (UT-138) as WP-internal cruft.
