# Subscription create args keep the first invoice on-session for 3DS

## Scenario

Stripe Basil removed `Invoice.payment_intent`. Checkout confirms the first
invoice with `latest_invoice.confirmation_secret.client_secret`. Create args
must stay `default_incomplete`, save the card on the subscription, and expand
that secret even after `ppcart_checkout_stripe_subscription_args` rewrites them.

## Steps

1. Call `ppcart_stripe_subscription_on_session_args()` with empty args.
2. Call it with args that dropped `payment_behavior`, `payment_settings`, and `expand`.
3. Call it with extra `expand` entries and an existing `payment_settings` key.

## Expected result

1. Empty and stripped args return `payment_behavior=default_incomplete`,
   `save_default_payment_method=on_subscription`, and
   `expand` containing `latest_invoice.confirmation_secret`.
2. `allow_incomplete` is overwritten to `default_incomplete`.
3. Extra expand entries and other payment_settings keys are kept.
4. `latest_invoice.payment_intent` (and nested) expands are removed.
5. `latest_invoice.confirmation_secret` is not duplicated.

## Edge cases

- Non-array input is treated as an empty args array.
