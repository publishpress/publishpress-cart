# Shipping Enable Meta Is Copied

## Scenario

Whether shipping is enabled for a product is stored under `_sc_enable_shipping`. The duplicate must inherit this toggle. This verifies the `_sc_enable_shipping` meta key is present on the copy.

## Steps

1. Seed the source with `_sc_enable_shipping` set to `'1'`.
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_enable_shipping` key.

## Expected result

The duplicate's meta contains the `_sc_enable_shipping` key; the shipping toggle is carried over.

## Edge cases

- Copied alongside the shipping amount (UT-131) so the full shipping configuration survives.
