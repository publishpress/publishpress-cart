# Encrypt/decrypt round-trip restores the exact secret value

## Scenario

Security case. The core guarantee of at-rest encryption is reversibility without data loss: a credential encrypted with `encrypt_value()` must decrypt back to the identical plaintext via `decrypt_value()`, and the encrypted blob must be self-identifying so the system can tell ciphertext from plaintext. This case round-trips a Stripe-style secret key.

## Steps

1. Skip if the OpenSSL extension is unavailable (`requireOpenSsl`).
2. Encrypt the plaintext `sk_test_unit_secret_value_12345` with `PPCart_Secrets::encrypt_value()`.
3. Check `PPCart_Secrets::is_encrypted_value()` on the result.
4. Decrypt the blob with `PPCart_Secrets::decrypt_value()` and compare to the original.

## Expected result

- `encrypt_value()` returns a string (the ciphertext blob), not the original plaintext.
- `is_encrypted_value()` returns `true` for the blob, so it is recognizable as encrypted.
- `decrypt_value()` returns exactly `sk_test_unit_secret_value_12345`, proving a lossless round-trip.

## Edge cases

- Without the OpenSSL extension the cipher cannot run, so the test is skipped rather than producing a false failure.
