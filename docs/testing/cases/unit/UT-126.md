# Notification Repeater Meta Is Copied

## Scenario

Admin email notifications are stored in the `_sc_notifications` repeater. The duplicate must inherit them so it triggers the same alerts. This verifies the `_sc_notifications` meta key is present on the copy.

## Steps

1. Seed the source with an `_sc_notifications` entry.
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_notifications` key.

## Expected result

The duplicate's meta contains the `_sc_notifications` key; notification configuration is carried over.

## Edge cases

- Copied as-is, including recipient addresses, with no clearing applied.
