# Malformed Debug Log Line Becomes Unknown

## Scenario

Older or third-party log lines may not follow the timestamp/level/message format. Rather than dropping such lines, the viewer still renders them with a safe placeholder severity. This case verifies a line without any recognizable level is classified as `UNKNOWN`.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with the free-form line `A malformed raw debug message.`.
2. Inspect the `level` field of the returned parsed array.

## Expected result

- The parsed entry's `level` is `UNKNOWN`, so the line is preserved but flagged as unclassified.

## Edge cases

- A line containing a level-like word in the middle of prose should still resolve to `UNKNOWN` unless it matches the expected leading format.
