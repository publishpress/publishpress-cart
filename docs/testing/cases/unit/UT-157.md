# maybe_decrypt_option_value decrypts ciphertext and passes plaintext through

## Scenario

Security case. The read-side helper `maybe_decrypt_option_value()` must be safe to call on any stored value: if the value is an encrypted blob it returns the decrypted plaintext, and if the value is already plaintext it returns it unchanged. This lets callers transparently read credentials regardless of whether they were stored encrypted.

## Steps

1. Skip if OpenSSL is unavailable.
2. Encrypt the plaintext `ac-secret-key-value` with `encrypt_value()`.
3. Call `PPCart_Secrets::maybe_decrypt_option_value()` on the encrypted blob.
4. Call `maybe_decrypt_option_value()` on the literal plaintext `still-plain`.

## Expected result

- The encrypted blob decrypts back to `ac-secret-key-value`.
- The plaintext `still-plain` is returned unchanged (no double-processing of a non-encrypted value).

## Edge cases

- A value that merely resembles a secret but is not in the encrypted format is treated as plaintext and returned as-is, avoiding spurious decryption attempts.
