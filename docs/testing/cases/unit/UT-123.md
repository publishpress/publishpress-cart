# Coupon Stripe ID Is Cleared On Duplicate

## Scenario

A coupon's `stripe_id` points at a specific Stripe coupon object and is an external identity, not local config. Reusing it on the copy would tie the duplicate's coupon to the source's Stripe object. This verifies the coupon's `stripe_id` is emptied on the duplicate.

## Steps

1. Seed the source coupon with `stripe_id` `'coupon_source'`.
2. Duplicate it (`prepare_meta_value_for_duplicate` clears `stripe_id` on `_sc_coupons`).
3. Read `_sc_coupons[0]['stripe_id']` from the duplicate.

## Expected result

`_sc_coupons[0]['stripe_id']` is an empty string `''`; the source's Stripe coupon id is discarded so the copy can create its own.

## Edge cases

- Cleared (blank), not removed: the coupon row and its `code` remain (UT-122); only the external Stripe identity is wiped.
