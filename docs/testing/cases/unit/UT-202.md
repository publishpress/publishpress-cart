# Edit post URL never returns null

## Scenario

`ppcart_get_edit_post_url()` must return a string, never `null`. Invalid or empty WordPress edit links collapse to `''` so callers can concatenate or echo the result without a type check.

## Steps

1. Stub `get_edit_post_link()` so post 99 returns a URL, post 7 returns `''`, and any other id returns `null`.
2. Call `ppcart_get_edit_post_url()` with `null`, `0`, `42`, `7`, and `99`.

## Expected result

`null` and `0` skip `get_edit_post_link()` and return `''`. Post 42 (`null` link) and post 7 (`''` link) return `''`. Post 99 returns the stubbed admin edit URL.

## Edge cases

- Non-positive ids must not call `get_edit_post_link()`.
- A `null` WordPress return is normalized to `''`, not passed through.
