# Dashboard Page Query Uses The Canonical `ppcart` Slug

## Scenario

The Cart top-level dashboard lives at `?page=ppcart`. This case verifies the canonical query is simultaneously a plugin screen and the dashboard screen, and that the menu helper reports the exact same slug.

## Steps

1. Reset the admin screen context with `$_GET['page'] = 'ppcart'` and no screen object.
2. Call `PPCart_Admin_Screens::is_plugin_screen()`.
3. Call `PPCart_Admin_Screens::is_dashboard_screen()`.
4. Call `PPCart_Admin_Screens::menu_slug()`.

## Expected result

`is_plugin_screen()` returns `true`, `is_dashboard_screen()` returns `true` (page equals `PAGE_DASHBOARD`), and `menu_slug()` returns the exact string `ppcart`.

## Edge cases

- UT-006 proves the public plugin slug `publishpress-cart` is not accepted as the dashboard page identifier.
