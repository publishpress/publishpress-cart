# Legacy Log Debug Writes Parseable Raw Lines

## Scenario

The legacy `log_debug()` API writes plain message lines to the debug file. Those lines must remain readable by the viewer's `read_entries()` so historical logging keeps working. This case verifies a legacy message round-trips back through the viewer unchanged.

## Steps

1. Instantiate `PPCart_Debug_Logger` and call `log_debug('Saving order after checkout validation.', 1)`.
2. Call `PPCart_Debug_Log_Viewer::read_entries(['limit' => 10])`.
3. Inspect the first entry's `message` field.

## Expected result

- `read_entries()` returns at least one entry, and `entries[0]['message']` is exactly `Saving order after checkout validation.`.

## Edge cases

- A legacy message containing JSON-like punctuation should still be stored and read back without being mangled by the parser.
