# Menu Order Is Copied

## Scenario

A product's manual sort position should be preserved on the duplicate. This verifies `menu_order` is carried over so the copy keeps the source's ordering value.

## Steps

1. Seed the source product with `menu_order` `7`.
2. Duplicate it and read the duplicate post object.
3. Inspect its `menu_order`.

## Expected result

`menu_order` equals `7`, copied from the source rather than resetting to the stub default of `0`.

## Edge cases

- Confirms ordering is explicitly copied, not left at the insert default.
