# Duplicate Is Created As A ppcart_product

## Scenario

The copy must remain a Cart product, not a plain post. This verifies the new post is inserted with the `ppcart_product` post type so it behaves as a product everywhere in the plugin.

## Steps

1. Seed and duplicate the configured source product.
2. Read the duplicate post object via `get_post()`.
3. Inspect its `post_type`.

## Expected result

`post_type` is `'ppcart_product'` (the value of `PPCart_Product_Duplicator::PRODUCT_POST_TYPE`), even though the stub's `wp_insert_post` default would otherwise be `'post'`.

## Edge cases

- Confirms `duplicate()` explicitly sets the product post type rather than inheriting the generic default.
