# Canonical admin page and hook identifiers replace legacy slugs

## Scenario

The centralized admin screen contract exposes only the canonical `ppcart`
menu, submenu, and hook identifiers after the hard cutover.

## Steps

1. Assert the complete page-slug and hook-suffix lists and canonical prefixes.
2. Verify every canonical page and hook is recognized.
3. Verify every replaced StudioCart, `sc`, and `ncs-cart` page or hook is rejected.

## Expected result

All eight canonical page slugs and hook suffixes match the approved mapping.
Old page and hook identifiers, including unknown old-prefixed IDs, are not
recognized.

## Edge cases

- No redirect, dual registration, or legacy slug recognition is provided.
