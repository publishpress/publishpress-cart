# Checkout completion authorization requires order access proof

## Scenario

Checkout completion must not run from anonymous replay unless the request
carries a valid purchase nonce plus order access token, PayPal PDT success when
configured, or an owner/admin bypass.

## Steps

1. Exercise `ppcart_checkout_completion_allowed()` for post, step, and PayPal contexts.
2. Exercise `PPCart_Order::token_matches()` and `access_arg()`.

## Expected result

Unauthorized combinations return false; valid proof returns true.
