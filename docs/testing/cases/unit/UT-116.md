# Integration Service Is Copied

## Scenario

Third-party integrations are stored in the `_sc_integrations` repeater. The duplicate must inherit the configured integrations so it behaves like the source. This verifies the integration's `service` value is copied.

## Steps

1. Seed the source with one `_sc_integrations` row whose `service` is `'mailchimp'`.
2. Duplicate it.
3. Read `_sc_integrations[0]['service']` from the duplicate.

## Expected result

`_sc_integrations[0]['service']` equals `'mailchimp'`, copied unchanged onto the duplicate.

## Edge cases

- Integration rows are copied as-is (no Stripe-style clearing); only plan references depend on the preserved `option_id` (UT-117).
