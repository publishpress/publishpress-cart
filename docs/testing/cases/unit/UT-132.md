# File Download Meta Is Copied

## Scenario

Digital downloadable files attached to a product are stored in the `_sc_files` repeater. The duplicate must inherit them so it delivers the same downloads. This verifies the `_sc_files` meta key is present on the copy.

## Steps

1. Seed the source with an `_sc_files` entry (file id and URL).
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_files` key.

## Expected result

The duplicate's meta contains the `_sc_files` key; downloadable file configuration is carried over.

## Edge cases

- File rows are copied as-is, including their URLs, with no clearing applied.
