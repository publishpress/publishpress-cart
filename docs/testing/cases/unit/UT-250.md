# Cart soft-stops beside Studiocart with an admin notice

## Scenario

Activating PublishPress Cart while leftover Studiocart is active must not `wp_die` or deactivate Cart. Cart stays listed as active, skips the rest of bootstrap, and shows an error notice only to users who can activate plugins and only on the Plugins screens. First-time setup is deferred until Studiocart is gone.

## Steps

1. Stub `active_plugins` to include Studiocart and call `on_activate()`.
2. Call `render_notice()` with and without the `activate_plugins` capability on the Plugins screen.
3. Set `_ppcart_pending_activation` and call `consume_pending_activation()` twice.

## Expected result

`on_activate()` does not call `wp_die` or `deactivate_plugins`, and writes `_ppcart_pending_activation`. The notice prints only for `activate_plugins` on Plugins screens. Consume returns true once, then false.
