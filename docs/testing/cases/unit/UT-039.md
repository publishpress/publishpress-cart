# Standard Debug Log Line Parses Level

## Scenario

The debug log viewer turns each stored raw log line into a structured entry the admin UI can render. A well-formed line carries a timestamp, a severity level, and a human message. This case verifies the parser extracts the severity `level` token from a standard line.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with the raw line `[05/12/2026 6:31 AM] - SUCCESS : Order #627 saved successfully with status paid.`.
2. Inspect the `level` field of the returned parsed array.

## Expected result

- `parse_line()` returns an array whose `level` is exactly `SUCCESS`, taken from the token between the dash and the colon.

## Edge cases

- A line using a different severity word (e.g. `WARNING`, `ERROR`) should surface that exact token rather than defaulting to `SUCCESS`.
