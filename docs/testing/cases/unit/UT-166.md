# Unknown Statuses Are Converted Into Readable Fallback Labels

## Scenario

For a status key that is neither registered in WordPress nor present in the internal fallback table, `PPCart_Status_Labels::get()` derives a readable label by humanizing the raw key. Hyphens and underscores become spaces and each word is capitalized, so arbitrary or third-party statuses still display cleanly.

## Steps

1. Leave the stubbed `get_post_status_object()` returning `null` for every key (no statuses registered).
2. Call `PPCart_Status_Labels::get('custom-status_value')`, a key absent from the fallback table.

## Expected result

The method returns `Custom Status Value` — both the hyphen and underscore are replaced with spaces and each word is title-cased.

## Edge cases

- Mixed delimiters in a single key are normalized together, so `custom-status_value` yields one clean phrase rather than partially converted text.
