# `ppcart_page_` Child Screen Prefix Is Recognized

## Scenario

Cart submenu pages use hook ids prefixed with `ppcart_page_`. To recognize submenu pages added later, any screen id starting with that canonical prefix should be accepted — even an unknown suffix like `ppcart-future`. `PPCart_Admin_Screens::is_plugin_screen()` matches via the `ppcart_page_` prefix.

## Steps

1. Reset the admin screen context with a screen object `{ id: 'ppcart_page_ppcart-future', base: 'ppcart_page_ppcart-future' }`.
2. Call `PPCart_Admin_Screens::is_plugin_screen()`.

## Expected result

`is_plugin_screen()` returns `true`: the screen id begins with the `ppcart_page_` (`MENU_HOOK_PREFIX`) canonical prefix, so it is recognized as a Cart child screen even though `ppcart-future` is not an explicitly listed hook.

## Edge cases

- Demonstrates recognition for future canonical submenu slugs; the opposite of UT-009, where a non-`ppcart_page_` foreign id is rejected.
