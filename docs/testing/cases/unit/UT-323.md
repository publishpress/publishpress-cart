# Admin notices stay on Cart or Plugins screens and support dismissal

## Scenario

Payment and integration notices must not appear on unrelated WordPress admin screens. The non-blocking Stripe Connect success notice persists dismissal per user. Blocking currency, payment-method, integration, and Stripe Connect warning notices stay visible on Cart screens. The Studiocart conflict notice stays limited to Plugins screens where an admin can act.

## Steps

1. Call the notice screen gate with `admin_notices` on a non-Cart screen and on settings shell hooks.
2. Assert Stripe Connect success dismiss meta is read from `_ppcart_dismiss_admin_notice_stripe_connect_success`.
3. Render the Studiocart conflict notice on dashboard vs plugins / plugins-network screens.

## Expected result

Global notices skip unrelated screens, custom Cart notice hooks still render, dismissed Stripe Connect success notices stay hidden for that user, and the Studiocart conflict notice prints only on Plugins screens for users who can activate plugins.

## Edge cases

- Settings and customer-report custom shell hooks still show notices.
- Missing payment methods, integration errors, currency case errors, and Stripe Connect warnings remain non-dismissible.
