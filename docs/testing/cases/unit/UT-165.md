# Legacy Cancelled Spelling Remains Available As Early Fallback

## Scenario

The plugin standardizes on the American spelling `canceled`, but historical data may still carry the British `cancelled` spelling. The fallback table keeps a distinct entry for the legacy `cancelled` key so old records resolve to a proper label instead of being humanized generically.

## Steps

1. Leave the stubbed `get_post_status_object()` returning `null` for every key (no statuses registered).
2. Call `PPCart_Status_Labels::get('cancelled')` (double-l legacy spelling).

## Expected result

The method returns `Cancelled` (matching the legacy spelling), distinct from the modern `canceled` key which resolves to `Canceled`.

## Edge cases

- Both spellings coexist in the table: `canceled` -> `Canceled` and `cancelled` -> `Cancelled`, so neither legacy nor current records get mislabeled.
