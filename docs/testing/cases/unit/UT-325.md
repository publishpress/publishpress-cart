# Product tracking tab and field group are no longer registered

## Scenario

Freeform product tracking fields were a Guideline 8 remote-code path. The product settings tabs and save field groups must not expose a `tracking` group, so a posted `_ppcart_tracking_main` value has no field to persist through.

## Steps

1. Read the product setting tabs and the render/save field group lists.
2. Assert neither list contains `tracking`.

## Expected result

The Tracking tab and field group are absent from both the UI tab list and the save field groups.

## Edge cases

- Pro support being off or on does not restore the tracking group in Free.
