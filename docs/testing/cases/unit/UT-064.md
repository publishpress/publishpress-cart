# Paid To Paid Transaction Change Title Explains Stripe Detail Sync

## Scenario

Sometimes an order stays `paid` but its Stripe transaction identifier changes (for example from a PaymentIntent id `pi_123` to a charge id `ch_123`). The group title should explain this is a Stripe payment-detail sync rather than a status change. This case verifies the title for order 706.

## Steps

1. Parse two lines under `flow_id` `unit-transaction-update` for order 706 where both `previous_status` and `status`/`next_status` are `paid`, but the transaction id changes from `pi_123` to `ch_123`.
2. Assign sequences and pass both entries to `group_entries()`.
3. Inspect the resulting group's `title`.

## Expected result

- The group's `title` is exactly `Stripe payment details updated for Order #706`, signaling a detail sync rather than a paid transition.

## Edge cases

- A paid-to-paid flow with no transaction-id change should not be titled as a Stripe detail update.
