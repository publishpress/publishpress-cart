# Database schema comparator detects column and index drift

## Scenario

`PPCart_DB_Schema_Comparator` diff expected `PPCart_DB_Table_Schema`
definitions against live column/index shapes without touching the database.

## Steps

1. Normalize `bigint(20) unsigned` vs `bigint unsigned`.
2. Compare a schema missing a live column.
3. Compare mismatched column types.
4. Compare index column order, missing `Sub_part`, and unique flag drift.

## Expected result

Each drift produces the matching `PPCart_DB_Schema_Issue` type; equivalent
integer display widths normalize to the same type token.
