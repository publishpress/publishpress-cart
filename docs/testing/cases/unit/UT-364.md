# Guest checkout never reuses a Stripe customer found by email

## Scenario

A guest posts the email of another person to a public checkout endpoint.
The checkout must not find or reuse that person's Stripe customer.

## Steps

1. As a guest, ask the payment controller for a cached customer for `victim@example.com`.
2. Ask it to get or create a customer with that email.
3. Create a customer with an empty email and phone.

## Expected result

1. No customer ID is returned.
2. Stripe customers are never listed by email. A new customer is created. No user meta is written.
3. Empty email and phone are not sent to Stripe.

## Edge cases

- A Stripe customer list call would return the other person's customer; it must not be made.
