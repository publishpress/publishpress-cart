# Edit Last Meta Is Not Copied

## Scenario

`_edit_last` records the WordPress user who last edited the original post. It is post-specific provenance that should not be transplanted onto a fresh copy. This verifies `_edit_last` is excluded and absent from the duplicate.

## Steps

1. Seed the source with `_edit_last` (e.g. `'5'`).
2. Duplicate it and read the duplicate's full meta array.
3. Assert the `_edit_last` key is missing.

## Expected result

The duplicate's meta does not contain `_edit_last`; it is filtered out by `get_excluded_meta_keys()`.

## Edge cases

- "Not copied" WP-internal meta, alongside `_edit_lock` (UT-136); the new draft starts its own edit history.
