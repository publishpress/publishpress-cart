# Debug Log Rotates When Max Size Is Exceeded

## Scenario

To prevent the debug file from growing unbounded, the logger rotates the active file to a `.1` archive once it exceeds the `PPCART_DEBUG_LOG_MAX_BYTES` cap (520 bytes in the test). This case writes enough large lines to trigger rotation and verifies the rotated file appears.

## Steps

1. Instantiate `PPCart_Debug_Logger` and write 8 padded rows (each `Rotation row <i>` plus 140 `x` characters) via `log_debug()`.
2. Read the active log file name from the `_sc_log_file` option.
3. Check the filesystem for `<log_file>.1` in `PPCART_DEBUG_LOG_DIR`.

## Expected result

- The rotated file `<log_file>.1` exists, confirming the active log was archived after exceeding the size cap.

## Edge cases

- Writing fewer/smaller lines that stay under the cap should not create a `.1` rotation file.
