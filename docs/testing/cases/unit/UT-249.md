# Companion loader resolves the Compatibility plugin directory from active plugins

## Scenario

Cart loads companion packages only when PublishPress Cart Compatibility is an
active plugin. `PPCart_Companion_Loader::plugin_dir()` must read
`active_plugins` and network `active_sitewide_plugins` and return the
companion directory or empty.

## Steps

1. Stub `active_plugins` without the companion basename and call `plugin_dir()`.
2. Stub `active_plugins` with `publishpress-cart-compat/publishpress-cart-compat.php`.
3. Clear site plugins and stub `active_sitewide_plugins` with that basename.

## Expected result

`plugin_dir()` is empty when the companion is inactive. When it is site-active
or network-active, the return value is `WP_PLUGIN_DIR/publishpress-cart-compat/`.
`ppcart_companion_plugin_dir()` matches the class method.
