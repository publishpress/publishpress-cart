# Stripe Product Identity Is Not Copied

## Scenario

`_sc_stripe_prod_id` is the source product's Stripe Product object id — a unique external identity. The duplicate must be an independent product, so it must not point at the source's Stripe Product. This verifies `_sc_stripe_prod_id` is excluded entirely (the whole key is dropped, not just blanked).

## Steps

1. Seed the source with `_sc_stripe_prod_id` set to `'prod_source'`.
2. Duplicate it and read the duplicate's full meta array.
3. Assert the `_sc_stripe_prod_id` key is missing.

## Expected result

The duplicate's meta does not contain `_sc_stripe_prod_id`; it is filtered out by `get_excluded_meta_keys()` so the copy's next save creates its own Stripe Product.

## Edge cases

- Note the difference from Stripe price/coupon ids: those keys are kept but blanked inside their rows (UT-113/UT-123), whereas the Stripe product id key is omitted altogether.
