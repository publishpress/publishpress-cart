# Order edit status select maps stored pending-payment to Pending option

## Scenario

Checkout stores order status as `pending-payment`, while the admin Edit Details Order Status dropdown uses the `pending` option value. The helper must align stored values with select options so Pending is selected on first edit, matching list and account screens.

## Steps

1. Call `PPCart_Status_Labels::edit_select_value('pending-payment')` and `edit_select_value('initiated')`.
2. Call `edit_select_value` for `paid`, `pending`, and an empty string.

## Expected result

`pending-payment` and `initiated` return `pending`. Other inputs are returned unchanged.

## Edge cases

- Saving with blank `-- Select --` must not overwrite status (covered by order save template behavior; render mapping is the focus of this case).
