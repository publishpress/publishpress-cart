# Product Excerpt Is Copied

## Scenario

The product excerpt (short description) should travel with the duplicate. This verifies `post_excerpt` is copied verbatim from source to copy.

## Steps

1. Seed the source product with `post_excerpt` `'Source product excerpt.'`.
2. Duplicate it and read the duplicate post object.
3. Inspect its `post_excerpt`.

## Expected result

`post_excerpt` equals `'Source product excerpt.'`, copied unchanged from the source.

## Edge cases

- Excerpt is preserved alongside content (UT-106), so both descriptive fields survive duplication.
