# Embedded Json Detects Product Id

## Scenario

Some messages append a bare JSON object (without the `context=` prefix) carrying request data. The parser should still detect known fields such as `product_id` inside that embedded JSON. This case verifies the product id is extracted from an inline JSON payload.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with `[05/12/2026 6:33 AM] - WARNING : Checkout form validation failed. {"product_id":45,"nonce":"abc"}`.
2. Inspect the `product_id` field of the returned parsed entry.

## Expected result

- The parsed entry's `product_id` is the integer `45`, read from the embedded JSON.

## Edge cases

- An embedded JSON object without a `product_id` key should leave the field neutral rather than throwing.
