# Settings debug preview reads uploads log directory

## Scenario

The settings Debug tab preview must read the same directory writers use:
`wp_upload_dir()['basedir']/publishpress-cart/logs` (or `PPCART_DEBUG_LOG_DIR`).
It must not look under `WP_CONTENT_DIR/publishpress-cart/logs`.

## Steps

1. Stub `wp_upload_dir()` to a unique temp basedir.
2. Write `log.txt` under `{uploads}/publishpress-cart/logs` with a marker line.
3. Call `PPCart_Debug_Logger::get_admin_log_data()`.

## Expected result

- `exists` is true.
- `preview` contains the marker line from the uploads path.

## Edge cases

- A `PPCART_DEBUG_LOG_DIR` override may still point elsewhere; this case only
  locks the uploads default when that constant is undefined (same skip gate as
  UT-221).
