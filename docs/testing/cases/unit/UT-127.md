# Confirmation Repeater Meta Is Copied

## Scenario

Post-purchase confirmation messages are stored in the `_sc_confirmations` repeater. The duplicate must inherit them. This verifies the `_sc_confirmations` meta key is present on the copy.

## Steps

1. Seed the source with an `_sc_confirmations` entry (including an `int_plan` reference to `plan_recurring`).
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_confirmations` key.

## Expected result

The duplicate's meta contains the `_sc_confirmations` key; confirmation configuration is carried over.

## Edge cases

- Confirmation rows reference plan `option_id`s, which remain valid because those ids are preserved (UT-112).
