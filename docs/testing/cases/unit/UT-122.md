# Coupon Code Is Copied

## Scenario

The human-facing coupon code is local configuration that should carry over so the duplicate offers the same discount. This verifies the first coupon's `code` value is copied.

## Steps

1. Seed the source coupon with `code` `'SAVE10'`.
2. Duplicate it.
3. Read `_sc_coupons[0]['code']` from the duplicate.

## Expected result

`_sc_coupons[0]['code']` equals `'SAVE10'`, copied unchanged onto the duplicate.

## Edge cases

- The coupon `code` is preserved (local) while the same row's `stripe_id` is cleared (external, UT-123).
