# Cart detects leftover Studiocart and does not match itself

## Scenario

PublishPress Cart must not load beside leftover Studiocart. Detection uses the active plugin basename so Compatibility Mode shims are not mistaken for a live Studiocart install.

## Steps

1. Call `PPCart_Studiocart_Conflict::is_studiocart_basename()` with `Studiocart-main/studiocart.php` and with Cart’s own basename.
2. Stub `active_plugins` to Cart only and call `is_active()`.
3. Stub `active_plugins` to include Studiocart and call `is_active()`.

## Expected result

Studiocart’s basename matches; Cart’s does not. `is_active()` is false without Studiocart and true with it.
