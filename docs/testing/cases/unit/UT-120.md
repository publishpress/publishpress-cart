# Payment Method Setting Meta Is Copied

## Scenario

A product's payment-method configuration (such as the disable-Stripe toggle) is stored under `_sc_disable_stripe`. The duplicate must inherit this setting. This verifies the `_sc_disable_stripe` meta key is present on the copy.

## Steps

1. Seed the source with `_sc_disable_stripe` set to `'1'`.
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_disable_stripe` key.

## Expected result

The duplicate's meta contains the `_sc_disable_stripe` key; the payment-method setting is carried over.

## Edge cases

- This setting is local configuration (copied), unlike Stripe object ids (cleared, UT-113/UT-123/UT-139).
