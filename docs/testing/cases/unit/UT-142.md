# Custom Product Taxonomy Terms Are Copied

## Scenario

Beyond categories and tags, products can have additional taxonomies such as `sc_product_visibility`. Duplication must cover every taxonomy registered for the product type, not just the well-known two. This verifies a third/custom taxonomy's terms are copied to the duplicate.

## Steps

1. Seed the source with `sc_product_visibility` terms `[31]`.
2. Duplicate it (`copy_taxonomies` loops over all `get_object_taxonomies('ppcart_product')`).
3. Read the duplicate's `sc_product_visibility` terms.

## Expected result

The duplicate's `sc_product_visibility` terms equal `[31]`, copied from the source.

## Edge cases

- Confirms taxonomy copying is generic (iterates all product taxonomies), so custom/extension taxonomies are not silently dropped.
