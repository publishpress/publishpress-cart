# Direct Key Source Keeps Destination Charges Enabled

## Scenario

Stores that paste their own Stripe keys are not charging through Connect, so
destination charges must stay enabled. This is the inverse of UT-179 and guards
against the OAuth branch being applied to every store.

## Steps

1. Set the Stripe test key source to `direct`.
2. Read the Stripe Connect config from the payment, checkout, subscription, and hosted checkout paths.

## Expected result

1. All four paths report `is_oauth_access_token_key` as false.

## Edge cases

- An unset key source must fall back to the OAuth behaviour covered by UT-179.
