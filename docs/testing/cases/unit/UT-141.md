# Product Tags Are Copied

## Scenario

Products can be tagged via the `ppcart_product_tag` taxonomy. The duplicate must keep the same tags. This verifies the source's tag term IDs are reassigned to the copy.

## Steps

1. Seed the source with `ppcart_product_tag` terms `[21]`.
2. Duplicate it.
3. Read the duplicate's `ppcart_product_tag` terms.

## Expected result

The duplicate's `ppcart_product_tag` terms equal `[21]`, copied from the source.

## Edge cases

- Copied alongside categories (UT-140); `copy_taxonomies` iterates every taxonomy returned for `ppcart_product`.
