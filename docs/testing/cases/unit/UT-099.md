# Product Duplicate Setting Disables Duplicate Action

## Scenario

An admin can switch off product duplication site-wide. This verifies that storing the disable value in `_ppcart_product_duplicate_enable` makes the feature report itself as unavailable, so the admin row action is suppressed.

## Steps

1. Set the `_ppcart_product_duplicate_enable` option (`PPCart_Product_Duplicator::OPTION_NAME`) to the string `'0'`.
2. Call `PPCart_Product_Duplicator::is_enabled()`.

## Expected result

`is_enabled()` returns `false`. The string comparison `'0' !== (string) get_option(...)` is the only condition that disables the feature.

## Edge cases

- Only the exact string `'0'` disables it; this is the inverse of the default-on case (UT-098) and is reverted by re-enabling with `'1'` (UT-100).
