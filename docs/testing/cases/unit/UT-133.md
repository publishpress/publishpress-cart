# Quantity Field Meta Is Copied

## Scenario

The quantity-field toggle for a product is stored under `_sc_qty_field`. The duplicate must inherit it. This verifies the `_sc_qty_field` meta key is present on the copy.

## Steps

1. Seed the source with `_sc_qty_field` set to `'1'`.
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_qty_field` key.

## Expected result

The duplicate's meta contains the `_sc_qty_field` key; the quantity-field setting is carried over.

## Edge cases

- A scalar setting copied directly, like the other product configuration flags.
