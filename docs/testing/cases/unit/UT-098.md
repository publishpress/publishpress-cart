# Product Duplicate Setting Defaults To Enabled

## Scenario

The "Duplicate product" admin action is gated behind the `_ppcart_product_duplicate_enable` option. When a site has never touched that setting, duplication must be available out of the box. This verifies the default-on behavior so fresh installs expose the action without any configuration.

## Steps

1. Start with no `_ppcart_product_duplicate_enable` option stored (empty options state).
2. Call `PPCart_Product_Duplicator::is_enabled()`.

## Expected result

`is_enabled()` returns `true`. With the option absent, `get_option(self::OPTION_NAME, '1')` falls back to `'1'`, which is treated as enabled.

## Edge cases

- Default-on is distinct from an explicit enable: only the stored value `'0'` turns the feature off (see UT-099); every other state, including "never set", keeps it enabled.
