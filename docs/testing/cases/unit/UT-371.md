# Embed body classes name only the set appearance values

## Scenario

The embed stylesheet scopes every appearance rule by a body class, so an unset
value must produce no class and the Cart default stays.

## Steps

1. Build body classes for an appearance with every value set, a zero radius,
   and the 2-step layout.
2. Build body classes for an empty appearance and for one with only an accent
   and the standard layout.

## Expected result

1. `ppcart-embed--accent`, `--text`, `--bg`, `--font`, `--radius`, and
   `--layout-2-step`, in that order.
2. An empty list, then `ppcart-embed--accent` alone (the standard layout adds
   no class).

## Edge cases

- A radius of `0` is a set value and gets the class.
