# Helper logger writes under uploads not plugin directory

## Scenario

`PPCart_Helper::ppcartLogger()` must not write `debug.log` into the plugin
directory. WordPress.org review requires logs under `wp_upload_dir()` (same
`publishpress-cart/logs` folder as the debug logger).

## Steps

1. Stub `wp_upload_dir()` to a unique temp basedir.
2. Call `ppcartLogger('hello-749')`.

## Expected result

- `{uploads basedir}/publishpress-cart/logs/debug.log` exists and contains
  `hello-749`.
- `{plugin dir}/debug.log` is not created.

## Edge cases

- A `PPCART_DEBUG_LOG_DIR` override may still point elsewhere; this case only
  locks the uploads default when that constant is undefined (same skip gate as
  UT-221).
- Uploads `error` or a failed mkdir/fopen returns false and still must not
  fall back to the plugin directory.
