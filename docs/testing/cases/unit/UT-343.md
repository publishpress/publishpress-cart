# Subscription Args Cannot Remove Or Change Free Connect Fee

## Scenario

`ppcart_checkout_stripe_subscription_args` can rewrite classic subscription
create args after Connect fees are applied. A filter that removes
`application_fee_percent` or sets any value other than
`PPCART_STRIPE_CONNECT_EXTRA_PERCENT` (2.0 on Free) must fail validation.
Args are not rewritten.

## Steps

1. Build subscription create args with a valid fee, a missing fee, a wrong fee, and a zeroed fee.
2. Run `ppcart_stripe_connect_fee_is_valid()`.

## Expected result

1. Valid Free fees return true and the input array is unchanged.
2. Missing, zero, or non-constant percents return false.

## Edge cases

- Pro is expected to keep a 0% fee (not covered in this Free unit case).
- Connect disabled or missing destination does not invent a fee.
