# Prefixed Stripe client promotes StripeObject lists to Collection

## Scenario

Prefixed stripe-php can hydrate a list payload as `PublishPress\Stripe\StripeObject`.
Stock `requestCollection` then throws. `PPCart_Stripe_Client` must let
`webhookEndpoints->all()` and `invoices->search()` return Collection/SearchResult
so callers keep using client service methods.

## Steps

1. Build a client whose `request()` returns a StripeObject list of one webhook
   endpoint. Call `webhookEndpoints->all()`.
2. Build a client whose `request()` returns a StripeObject search payload. Call
   `invoices->search()`.

## Expected result

1. `all()` returns a Collection whose `data[0]` has the endpoint id and url.
2. `search()` returns a SearchResult whose `data[0]` has the invoice id.

## Edge cases

- A payload with no `data` still throws UnexpectedValueException.
