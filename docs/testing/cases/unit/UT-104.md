# Duplicate Is Created As A Draft

## Scenario

A duplicate should never go live automatically; the admin must review and publish it. This verifies the copy is created with `draft` status regardless of the source's status.

## Steps

1. Seed the source product with `post_status` `'publish'`.
2. Duplicate it and read the duplicate post object.
3. Inspect its `post_status`.

## Expected result

`post_status` is `'draft'`. `duplicate()` hardcodes draft status, so a published source still yields an unpublished copy.

## Edge cases

- Source is `publish` but the copy is `draft`, proving status is forced rather than inherited.
