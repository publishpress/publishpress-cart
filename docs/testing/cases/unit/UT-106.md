# Product Content Is Copied

## Scenario

The product's main body content must carry over to the duplicate so its description is not lost. This verifies `post_content` is copied verbatim from source to copy.

## Steps

1. Seed the source product with `post_content` `'Source product content.'`.
2. Duplicate it and read the duplicate post object.
3. Inspect its `post_content`.

## Expected result

`post_content` equals `'Source product content.'`, copied unchanged from the source.

## Edge cases

- Unlike the title, content is copied as-is with no prefixing or transformation.
