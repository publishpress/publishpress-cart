# Structured Context Detects Checkout Flow Id

## Scenario

To group all log lines from a single checkout request, each structured context can carry a `flow_id`. The parser must extract this id so the viewer can later cluster related entries. This case verifies the `flow_id` is read from context.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with `[05/12/2026 6:32 AM] - STATUS : Checkout form validation started. context={"event":"checkout.validation.started","flow_id":"checkout-flow-1","product_id":45}`.
2. Inspect the `flow_id` field of the returned parsed entry.

## Expected result

- The parsed entry's `flow_id` is exactly `checkout-flow-1`.

## Edge cases

- A context without a `flow_id` should produce an empty/neutral flow id rather than an error.
