# Connect Config Always Includes Free Extra Percent

## Scenario

The Free Stripe Connect service fee is stored as `free_extra_percent` on the
shared connect config. If a checkout path omits that key, `total_fee_percent`
looks like a legitimate 0% fee and Stripe is charged with no application fee.

## Steps

1. Read the Stripe Connect config from the shared helper and from the payment,
   checkout, subscription, and hosted checkout paths.

## Expected result

1. Every config includes `free_extra_percent` of 2.0, matching `ppcart_stripe_connect_extra_percent()` on Free.
2. `total_fee_percent` equals `platform_fee_percent + 2.0`.

## Edge cases

- A path that still built its own config array could drop the key while others keep it.
