# Featured Image Meta Is Copied

## Scenario

The product's featured image is referenced by the WordPress `_thumbnail_id` meta (an attachment ID). The duplicate should show the same featured image. This verifies the exact `_thumbnail_id` value is copied.

## Steps

1. Seed the source with `_thumbnail_id` set to `'555'`.
2. Duplicate it.
3. Read `_thumbnail_id` from the duplicate via `get_post_meta(..., true)`.

## Expected result

The duplicate's `_thumbnail_id` equals `'555'`; the featured-image attachment reference is copied unchanged.

## Edge cases

- Asserted on the concrete value (not just key presence), confirming the thumbnail points at the same attachment as the source.
