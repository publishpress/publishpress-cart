# Credit note amount subtracts prior post-payment credit notes

## Scenario

A customer may already have partial credit notes issued against the same invoice. The cancellation refund must only credit what remains, so it subtracts the invoice's `post_payment_credit_notes_amount` from its `amount_paid` before requesting a new credit note. This test confirms the requested credit-note `amount` reflects that subtraction.

## Steps

1. Build a Stripe client stub whose latest invoice `in_test` has `amount_paid = 2000` and `post_payment_credit_notes_amount = 500` (cents).
2. Call `ppcart_issue_stripe_subscription_cancellation_refund()` with order `{ id: 321, subscription_id: 'sub_test' }` and subscription `{ id: 'sub_test', latest_invoice: 'in_test' }`.
3. Read the arguments captured by the credit-note service stub (`creditNotes->last_args`).

## Expected result

The credit note is requested for `amount = 1500`, i.e. `2000 - 500`.

## Edge cases

- Only the already-credited portion (`500`) is removed; if no prior credit notes existed the full `amount_paid` would be credited instead.
