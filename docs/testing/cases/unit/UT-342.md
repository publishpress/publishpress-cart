# Payment Intent Args Cannot Remove Or Change Free Connect Fee

## Scenario

Classic PaymentIntent create and amount-update args carry `application_fee_amount`
at the top level. A missing fee or any amount other than 2% of the Stripe
amount (floored to 1 cent) must fail validation. Args are not rewritten.

## Steps

1. Build create and update PaymentIntent args with a valid fee, a missing fee, and a wrong fee.
2. Run `ppcart_stripe_connect_fee_is_valid()`.

## Expected result

1. Valid Free fees return true and the input array is unchanged.
2. Missing or non-constant fees return false.
3. A $0 payment still requires a 1-cent fee on Free.

## Edge cases

- Pro is expected to keep a 0% fee (not covered in this Free unit case).
- Connect disabled or missing destination does not invent a fee.
