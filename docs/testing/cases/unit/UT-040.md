# Standard Debug Log Line Detects Workflow

## Scenario

Beyond severity, the viewer classifies each entry into a high-level `workflow` so admins can scan related activity. For a plain message that mentions an order, the workflow should be inferred from the message text. This case checks that an "Order #..." message is categorized under the `Order` workflow.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with `[05/12/2026 6:31 AM] - SUCCESS : Order #627 saved successfully with status paid.`.
2. Inspect the `workflow` field of the returned parsed array.

## Expected result

- The parsed entry's `workflow` is `Order`, derived from the message referencing an order.

## Edge cases

- A line with no recognizable workflow keyword should fall back to a generic/default workflow instead of misclassifying as `Order`.
