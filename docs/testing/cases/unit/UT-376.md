# The redirect bounce page hands the target URL to the frame bridge, escaped

## Scenario

The bounce page prints a merchant-configured URL into a link and into a script.
A URL with quotes, `&` or `</script>` must not break out of either.

## Steps

1. Build the bounce page for a URL that contains `&`, double quotes and
   `</script>`.

## Expected result

The exact page: an HTML-escaped `target="_top"` link, the frame bridge script,
and a `window.ppcartNavigate(...)` call whose argument is JSON with `<`, `>`,
`&` and quotes as unicode escapes.

## Edge cases

- Without the bridge script, the link still lets the buyer continue.
