# Section Breaks Are Skipped

## Scenario

The raw log writes dashed separator lines between sections for human readability. These are visual noise and must not appear as parsed entries in the viewer. This case verifies a separator line is rejected by the parser.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with a separator line of dashes (`----------------------------------------------------------`).
2. Inspect the return value.

## Expected result

- `parse_line()` returns `false` for the separator line, signaling the viewer to skip it rather than emit an entry.

## Edge cases

- A line that is only whitespace or empty should likewise be skipped instead of becoming an `UNKNOWN` entry.
