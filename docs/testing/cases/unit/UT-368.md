# Invoice retry refuses an invoice of another customer

## Scenario

The subscription invoice retry returns an invoice with its confirmation secret only
when the invoice belongs to the bound customer.

## Steps

1. Check invoices for another customer, no customer, and an empty customer.
2. Check invoices for the bound customer, as an ID and as an expanded object.

## Expected result

1. Refused.
2. Accepted.

## Edge cases

- An empty bound customer never matches.
