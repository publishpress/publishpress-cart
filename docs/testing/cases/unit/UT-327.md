# Account link markup escapes URL and label

## Scenario

Account portal anchors must apply late context escaping: `esc_url()` on the
href and `esc_html()` / `esc_html__()` on the visible label. Caller-supplied
shortcode labels and configured account URLs must not inject raw HTML.

## Steps

1. Render `ppcart_account_link` with a malicious label and a URL containing a quote.
2. Render the lost-password login-form link on the configured account page.
3. Render `ppcart_account_link` with no `label` attribute.
4. Render `ppcart_account_link` when no account page URL is configured.

## Expected result

The shortcode returns an anchor whose label is HTML-escaped and whose href has
quotes neutralized. The lost-password link keeps a safe relative href and an
HTML-escaped translated label. Omitting `label` falls back to the default
translated text. A missing account URL yields no markup.

## Edge cases

- On the account page itself, the shortcode returns false and emits no markup.
