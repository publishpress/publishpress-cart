# Session Filter Cannot Remove Or Change Free Connect Fee

## Scenario

`ppcart_stripe_checkout_session_args` can rewrite Checkout Session args after
Connect fees are applied. A filter that removes the fee or sets any percent
other than `PPCART_STRIPE_CONNECT_EXTRA_PERCENT` (2.0 on Free, 0 on Pro) must
fail the checkout with a JSON error. Session args are not rewritten.

## Steps

1. Build payment and subscription session args with a valid fee, a missing fee, and a wrong fee.
2. Run `ppcart_stripe_connect_fee_is_valid()`.

## Expected result

1. Valid Free fees return true and the input array is unchanged.
2. Missing or non-constant fees return false.
3. A $0 payment still requires a 1-cent fee on Free; 0, missing, or any other amount is invalid.

## Edge cases

- Pro is expected to keep a 0% fee (not covered in this Free unit case).
- Connect disabled or missing destination does not invent a fee.
- 2% of a $0 amount rounds to 0 and is floored to 1 cent.
