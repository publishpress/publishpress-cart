# Order Bump Repeater Meta Is Copied

## Scenario

Order bumps (upsell offers) are stored in the `_sc_order_bump_options` repeater. The duplicate must inherit them. This verifies the `_sc_order_bump_options` meta key is present on the copy.

## Steps

1. Seed the source with an `_sc_order_bump_options` entry.
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_order_bump_options` key.

## Expected result

The duplicate's meta contains the `_sc_order_bump_options` key; order-bump configuration is carried over.

## Edge cases

- A plain copied repeater with no Stripe ids to clear, unlike `_sc_pay_options`/`_sc_coupons`.
