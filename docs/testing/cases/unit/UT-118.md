# Default Fields Meta Is Copied

## Scenario

The product's built-in checkout fields are stored under `_sc_default_fields`. The duplicate must inherit this configuration. This verifies the `_sc_default_fields` meta key is present on the copy.

## Steps

1. Seed the source with a `_sc_default_fields` entry.
2. Duplicate it and read the duplicate's full meta array.
3. Check for the `_sc_default_fields` key.

## Expected result

The duplicate's meta contains the `_sc_default_fields` key; the default-fields configuration is carried over.

## Edge cases

- This is a "copied" meta key, in contrast to excluded keys like `_edit_lock` (UT-136) that must be absent.
