# Full Or Over Refunds Are Not Detected As Partial Refunds

## Scenario

`PPCart_Order_Refunds::is_partially_refunded()` must return `false` when an order is fully or over-refunded, because a partial refund requires the refund total to be strictly less than the gross amount. For a $200.00 order with a $250.00 stored refund, the refund total meets/exceeds the gross, so the order is not partial.

## Steps

1. Seed order `669` post meta with `_sc_amount = "200.00"` and `_sc_refund_amount = "250.00"` (no refund log).
2. Call `PPCart_Order_Refunds::is_partially_refunded(669)`.
3. The method computes gross (200.00) and refund total (250.00), then evaluates `refund_total > 0 && refund_total < gross`.

## Expected result

The method returns `false` because `250.00 < 200.00` is false, so the partial-refund condition fails.

## Edge cases

- A refund total exactly equal to the gross ($200.00) also returns `false` (full refund, not partial).
- A zero gross amount returns `false` regardless of the refund total.
