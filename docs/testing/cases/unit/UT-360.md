# Logical statuses resolve to stored post_status values

## Scenario

`ppcart_query_post_statuses()` returns the stored `post_status` values for one
or more logical statuses. Queries pass these values as `$wpdb->prepare()`
arguments. `ppcart_sql_in_post_statuses()` stays for back-compat and quotes
the same values.

## Steps

1. Resolve `paid` and `pending-payment`.
2. Resolve a list with a duplicate status.
3. Resolve an unmapped status and an empty list.
4. Call `ppcart_sql_in_post_statuses()` with no database object.

## Expected result

- A mapped status returns its registered slug and its logical slug.
- A list returns each value once.
- An unmapped status returns as given; an empty list returns no values.
- The back-compat helper quotes the same values.
