# Source Coupon Stripe ID Is Not Mutated

## Scenario

Clearing the copy's coupon `stripe_id` must not affect the original. The source coupon still needs its real Stripe id. This verifies the source's coupon `stripe_id` is left intact after duplication.

## Steps

1. Seed the source coupon with `stripe_id` `'coupon_source'`.
2. Run the duplication.
3. Re-read the source's stored `_sc_coupons` and inspect coupon 0's `stripe_id`.

## Expected result

The source's `_sc_coupons[0]['stripe_id']` is still `'coupon_source'`; only the duplicate's copy was cleared.

## Edge cases

- Confirms the clear acts on the duplicate's value, not the shared source array (no by-reference mutation), mirroring UT-115 for payment plans.
