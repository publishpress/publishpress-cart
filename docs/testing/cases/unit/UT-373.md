# Embed frame header lines allow only valid frame ancestors

## Scenario

An embed response replaces `X-Frame-Options` with a
`Content-Security-Policy: frame-ancestors` header built from the
`ppcart_embed_frame_ancestors` filter. `ppcart_embed_frame_header_lines()` builds
the header line from the filtered sources.

## Steps

1. Build the lines for the default `['*']`.
2. Build the lines for `'self'`, two origins (one padded with spaces), and a
   duplicate.
3. Build the lines for sources that are not CSP source expressions, and for an
   empty list.

## Expected result

1. `Content-Security-Policy: frame-ancestors *`
2. `Content-Security-Policy: frame-ancestors 'self' https://merchant.example https://*.shop.example:8443`
3. `Content-Security-Policy: frame-ancestors 'none'` in both cases, so nothing
   may frame the page.

## Edge cases

- Non-string entries are dropped without an error.
