# Payment Setup Group Title Explains Payment Intent Phase

## Scenario

When a flow represents creating a Stripe PaymentIntent, the group title should describe the payment-setup phase for the relevant order. This case verifies the title generated for a single `checkout.payment_intent.created` event tied to order 704.

## Steps

1. Parse a line whose context event is `checkout.payment_intent.created` with `flow_id` `unit-payment-setup` and `order_id` 704.
2. Assign the entry a `sequence` and pass it to `PPCart_Debug_Log_Viewer::group_entries()`.
3. Inspect the resulting group's `title`.

## Expected result

- The group's `title` is exactly `Payment setup for Order #704`.

## Edge cases

- A payment-intent event without an order id should still produce a sensible payment-setup title rather than a broken one.
