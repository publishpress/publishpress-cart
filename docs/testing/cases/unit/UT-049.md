# Stripe Subscription Ids Still Appear In Stripe Details

## Scenario

Although a Stripe subscription id must not become the local `subscription_id`, it is still valuable context. The parser collects it into the `stripe_ids` list so admins can correlate with the Stripe dashboard. This case verifies the `sub_...` id is preserved there.

## Steps

1. Call `PPCart_Debug_Log_Viewer::parse_line()` with `[05/12/2026 6:32 AM] - SUCCESS : Stripe subscription created - ID sub_1TWCmcCgxOWS1li105rAItSD`.
2. Inspect the `stripe_ids` array in the returned parsed entry.

## Expected result

- The `stripe_ids` array contains `sub_1TWCmcCgxOWS1li105rAItSD`, keeping the Stripe id visible in the entry's details.

## Edge cases

- The same Stripe id appearing twice in a message should not produce duplicate noise that breaks downstream display.
