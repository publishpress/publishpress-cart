# Rendered email HTML declares language, subject title, and presentation tables

## Scenario

Screen readers in mail clients need the email's language and a document title, and must not announce layout tables as data tables (WCAG 3.1.1, 2.4.2, 1.3.1).

## Steps

1. Render the transactional email shell with a subject, headline and body while the site language is `fr-FR`.
2. Render it again without a subject.

## Expected result

- The `<html>` element has `lang="fr-FR"`.
- The `<title>` is the email subject; without a subject it falls back to the headline.
- Every layout table in the shell has `role="presentation"`.

## Edge cases

- With neither subject nor headline the title falls back to the site name.
