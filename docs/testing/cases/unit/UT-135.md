# Multi-Value Meta Is Copied As Multiple Rows

## Scenario

Some meta keys store multiple separate values (multiple `add_post_meta` rows under one key) rather than a single serialized array. Duplication must preserve that multi-row shape, not collapse it. This verifies a multi-value meta key is reproduced as multiple values on the copy.

## Steps

1. Seed the source `_sc_multi_value_meta` with two distinct rows: `'first'` and `'second'`.
2. Duplicate it (`copy_meta` iterates each stored value and re-adds it individually).
3. Read `_sc_multi_value_meta` from the duplicate with `get_post_meta(..., $key)` (all values, single = false).

## Expected result

The duplicate's `_sc_multi_value_meta` equals `['first', 'second']` — two separate meta rows, preserving order and count.

## Edge cases

- Distinguishes multi-row meta (each value re-added) from single serialized-array meta; the copy must not merge the two rows into one.
