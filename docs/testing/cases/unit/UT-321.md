# Frontend kses allowlist keeps checkout plan data attributes

## Scenario

Shortcodes and Gutenberg checkout run HTML through `ppcart_kses_frontend_html()`.
The allowlist must keep plan-radio `data-price` and `data-installments` so
checkout JS can size the order and dispatch PayPal instead of the $0 COD path.

## Steps

1. Call `ppcart_frontend_allowed_html()`.
2. Assert the returned allowlist includes `data-price`, `data-installments`,
   `data-val`, and `data-ppcart-qty-price` on `input`.

## Expected result

Those attributes are present on the frontend kses allowlist return value.

## Edge cases

- `data-testid` and `data-form-wrapper` were already allowed and must stay.
