# Checkout completion requires order access

## Scenario

Automated by `tests/playwright/regression/rt021-checkout-completion-requires-order-access.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `url_one_time_stripe` is configured for the target site.

## Steps

1. Open the checkout page configured as `url_one_time_stripe`.
2. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
3. Enter the Stripe test card details.
4. Click Order Now.
5. Open the checkout page configured as `url_one_time_stripe`.

## Expected result

1. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.

## Edge cases

- None.
