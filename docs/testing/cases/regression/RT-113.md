# Popup link opens the checkout in a dialog on a page with the loader

## Scenario

Some site builders only let a button link to a URL. On a page with the loader, a link to the product with `?ppcart-embed=popup` opens the popup instead of leaving the page.

Automated by `tests/playwright/regression/rt113-embed-popup-link-opens-dialog-with-loader.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_free` is configured for the target site.

## Steps

1. Open a host page with `<a href="<free product permalink>?ppcart-embed=popup">Buy now</a>` and the loader.
2. Click the link, then press Esc.

## Expected result

1. The Checkout dialog opens and the form renders in its frame.
2. The popup frame URL has `ppcart-embed=1`.
3. The top window URL is still the host page URL.
4. Esc closes the dialog and focus returns to the link.

## Edge cases

- None.
