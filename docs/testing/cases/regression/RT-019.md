# Purchase free checkout flow

## Scenario

Automated by `tests/playwright/regression/rt019-purchase-free-checkout-flow.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

## Steps

1. Open the checkout page configured as `url_product_free`.
2. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
3. Click Order Now.

1. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.
