# Purchase one-time PayPal checkout flow first price

## Scenario

Automated by `tests/playwright/regression/rt010-purchase-one-time-paypal-checkout-flow-first-price.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `url_one_time_paypal` is configured for the target site and PayPal sandbox credentials are configured.

## Steps

1. Open the checkout page configured as `url_one_time_paypal`.
2. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
3. Choose PayPal as the payment method.
4. Click Order Now.
5. Switch to the PayPal checkout window.
6. Log in to the PayPal sandbox and approve the payment.
7. Return to the merchant site.

## Expected result

1. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.

## Edge cases

- None.
