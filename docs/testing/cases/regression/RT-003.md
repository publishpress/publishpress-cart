# Purchase one-time Stripe checkout flow first sale price

## Scenario

Automated by `tests/playwright/regression/rt003-purchase-one-time-stripe-checkout-flow-first-sale-price.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `url_one_time_stripe_with_sale_price` is configured for the target site.

## Steps

1. Open the checkout page configured as `url_one_time_stripe_with_sale_price`.
2. Review payment plan 1.
3. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
4. Enter the Stripe test card details.
5. Click Order Now.

## Expected result

1. Payment plan 1 is visible and shows both its original price and its sale price.
2. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.
