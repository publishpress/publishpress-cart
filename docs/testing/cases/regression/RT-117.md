# Stripe one-time order inside the inline embed shows the receipt in the frame

## Scenario

The buyer pays by card in the inline checkout. The order completes and the receipt shows inside the frame.

Automated by `tests/playwright/regression/rt117-embed-inline-stripe-order-shows-receipt-in-frame.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_stripe` is configured for the target site.

## Steps

1. Open a host page with the inline snippet for the one-time Stripe product and the loader.
2. Fill the contact fields and the card inside the frame (the local Stripe mock in mocked runs).
3. Accept the terms and click Order Now.

## Expected result

1. The frame URL has a numeric `ppcart-order` and `ppcart-embed=1`, and the confirmation message is visible inside the frame.
2. The top window URL is still the host page URL.

## Edge cases

- Payment Element methods that redirect to a bank page navigate the frame. Cards, wallets, and Link do not redirect.
