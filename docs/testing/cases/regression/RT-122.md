# A server redirect to another site from an embed navigates the top window

## Scenario

Some flows end with a server-side 302 to another site: a closed cart with a
redirect URL, or a subscription whose confirmation redirects. Inside the frame
that 302 would load the other site in the frame, where it is often refused. An
embed request gets a bounce page instead, and the frame bridge asks the host page
to open the target in the top window.

## Steps

1. Open a host page with an inline embed of a closed-cart product that redirects
   to `https://thanks.merchant.example/closed/`.

## Expected result

The top window lands on the redirect page, and no iframe is left on it.

## Edge cases

- A redirect inside the same site still loads in the frame.
