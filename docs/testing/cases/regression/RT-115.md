# Order of a product that redirects to an external page navigates the top window

## Scenario

The product sends the buyer to an external thank-you page after the order. That page must open in the browser window, not inside the small frame.

Automated by `tests/playwright/regression/rt115-embed-external-redirect-navigates-top-window.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_redirect` is configured for the target site.

## Steps

1. Route `https://thanks.merchant.example/**` to a page with the heading Thanks for your order.
2. Open a host page with the inline snippet for the redirect product and the loader.
3. Complete a free order inside the frame.

## Expected result

1. The top window URL is `https://thanks.merchant.example/thank-you/`.
2. The heading Thanks for your order is visible and the page has no iframe.

## Edge cases

- The redirect goes through `window.ppcartNavigate`, which asks the loader for a `navigate` to another origin.
