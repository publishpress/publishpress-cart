# Purchase one-time PayPal checkout flow first sale price

## Scenario

Automated by `tests/playwright/regression/rt012-purchase-one-time-paypal-checkout-flow-first-sale-price.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `url_one_time_paypal_with_sale_price` is configured for the target site and PayPal sandbox credentials are configured.

## Steps

1. Open the checkout page configured as `url_one_time_paypal_with_sale_price`.
2. Review payment plan 1.
3. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
4. Choose PayPal as the payment method.
5. Click Order Now.
6. Switch to the PayPal checkout window.
7. Log in to the PayPal sandbox and approve the payment.
8. Return to the merchant site.

## Expected result

1. Payment plan 1 is visible and shows both its original price and its sale price.
2. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.

## Edge cases

- None.
