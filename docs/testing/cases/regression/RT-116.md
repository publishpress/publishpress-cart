# Saved embed appearance styles the checkout and the receipt inside the frame

## Scenario

The merchant sets the embed look on the product Embed tab. The buyer sees those colors, corners, and font inside the frame, on the form and on the receipt.

Automated by `tests/playwright/regression/rt116-embed-styled-product-applies-appearance.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_styled` is configured for the target site.

## Steps

1. Open a host page with the inline snippet for the styled product (accent `#ff5a1f`, text `#112233`, background `#fffbe6`, font `Georgia, serif`, radius `12`) and the loader.
2. Read the computed styles inside the frame.
3. Complete a free order inside the frame.

## Expected result

1. The Order Now button background is `rgb(255, 90, 31)`.
2. The First Name field border radius is `12px`, and its font family starts with Georgia.
3. The frame body background is `rgb(255, 251, 230)`.
4. The First Name label color is `rgb(17, 34, 51)`.
5. The receipt confirmation message color is `rgb(17, 34, 51)`.

## Edge cases

- None.
