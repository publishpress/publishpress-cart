# Render checkout form using product shortcode

## Scenario

Render checkout form using product shortcode

## Steps

1. Create StudioCart product.

2. Add [ppcart_form id=&quot;PRODUCT_ID&quot;] to a WordPress page.

3. Publish page.

4. Open as guest and complete checkout.

## Expected result

1. Form renders correctly.

2. Product details and price are correct.

3. Checkout succeeds.

4. Order links to correct product ID.

## Edge cases

1. Invalid product ID; draft product; multiple forms on one page; page builder wrapper.
