# Embed flag on a page without checkout content keeps the theme template

## Scenario

The `ppcart-embed` flag lifts the site framing policy. It must do that only for products and checkout pages, so it cannot make, for example, an account page frameable.

Automated by `tests/playwright/regression/rt120-embed-flag-on-plain-page-keeps-theme.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_plain_page` and `url_embed_product_free` are configured for the target site.

## Steps

1. Open the free product permalink with `?ppcart-embed=1`.
2. Open the plain page (no checkout content) with `?ppcart-embed=1`.

## Expected result

1. The product response has `Content-Security-Policy: frame-ancestors *`, and its body has the `ppcart-embed` class and one `main.ppcart-embed__main`.
2. The plain page responds 200 with its own content, sends no `frame-ancestors` policy, has no `ppcart-embed` body class, and has no embed shell.

## Edge cases

- The `ppcart_embed_allows_post` filter can allow other posts, such as an upsell page.
