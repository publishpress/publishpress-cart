# On a phone the popup fills the screen and the inline form does not scroll sideways

## Scenario

Most buyers on a builder site use a phone. The inline form must fit the width, and the popup must use the whole screen.

Automated by `tests/playwright/regression/rt118-embed-phone-viewport-fits-screen.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_free` is configured for the target site.

## Steps

1. Use a 375 x 812 viewport.
2. Open a host page with a popup button, the inline snippet for the free product, and the loader.
3. Measure the inline frame document, then click Buy now.

## Expected result

1. Inside the inline frame, `scrollWidth` is not larger than `clientWidth`.
2. The dialog box is `{x: 0, y: 0, width: 375, height: 812}`.
3. The popup iframe is 375px wide and reaches the bottom of the screen.

## Edge cases

- None.
