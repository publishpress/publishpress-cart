# Purchase subscription Stripe checkout flow annually

## Scenario

Automated by `tests/playwright/regression/rt006-purchase-subscription-stripe-checkout-flow-annually.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `url_subs_stripe` is configured for the target site.

## Steps

1. Open the checkout page configured as `url_subs_stripe`.
2. Review payment plan 1.
3. Select payment plan 2.
4. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
5. Enter the Stripe test card details.
6. Click Order Now.

## Expected result

1. Payment plan 1 is visible on the checkout form.
2. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.

## Edge cases

- None.
