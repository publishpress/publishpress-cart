# Popup button opens the checkout in a dialog that closes with Esc or the backdrop

## Scenario

A merchant pastes the popup button snippet. The buyer opens the checkout in a modal dialog and can close it with the keyboard or the mouse.

Automated by `tests/playwright/regression/rt112-embed-popup-button-opens-and-closes-dialog.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_free` is configured for the target site.

## Steps

1. Open a long host page with `<button data-ppcart-popup="<free product permalink>">Buy now</button>` and the loader.
2. Click Buy now, then press Esc on the host page.
3. Click Buy now, click the First Name field inside the frame, then press Esc.
4. Click Buy now, then click the backdrop.

## Expected result

1. The dialog has `role="dialog"`, the accessible name Checkout, and `aria-modal="true"`.
2. The Close checkout button has focus, and its box ends above the top of the iframe box.
3. The popup iframe has an `allow` attribute that contains `payment`.
4. While the popup is open, the page scroll is locked (`overflow: hidden` on the root element).
5. Each of the three ways closes the dialog, removes the iframe, returns focus to Buy now, and unlocks the scroll.

## Edge cases

- Esc inside the frame works because the frame sends an `escape` message to the loader.
