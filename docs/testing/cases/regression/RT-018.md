# Purchase custom price PayPal checkout flow

## Scenario

Automated by `tests/playwright/regression/rt018-purchase-custom-price-paypal-checkout-flow.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `url_custom_price_paypal` is configured for the target site and PayPal sandbox credentials are configured.

## Steps

1. Open the checkout page configured as `url_custom_price_paypal`.
2. Enter the custom price from `modify_price` and wait for the total to update.
3. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
4. Choose PayPal as the payment method.
5. Click Order Now.
6. Switch to the PayPal checkout window.
7. Log in to the PayPal sandbox and approve the payment.
8. Return to the merchant site.

## Expected result

1. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.

## Edge cases

- None.
