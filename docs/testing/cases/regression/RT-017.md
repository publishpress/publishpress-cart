# Purchase subscription PayPal checkout flow annually sale price

## Scenario

Automated by `tests/playwright/regression/rt017-purchase-subscription-paypal-checkout-flow-annually-sale-price.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `url_subs_paypal_with_sale_price` is configured for the target site and PayPal sandbox credentials are configured.

## Steps

1. Open the checkout page configured as `url_subs_paypal_with_sale_price`.
2. Review payment plan 1.
3. Review payment plan 2.
4. Select payment plan 2.
5. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
6. Choose PayPal as the payment method.
7. Click Order Now.
8. Switch to the PayPal checkout window.
9. Log in to the PayPal sandbox and approve the payment.
10. Return to the merchant site.

## Expected result

1. Payment plan 1 is visible on the checkout form.
2. Payment plan 2 is visible and shows both its original price and its sale price.
3. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.

## Edge cases

- None.
