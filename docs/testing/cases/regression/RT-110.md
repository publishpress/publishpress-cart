# Inline embed renders the checkout in a cross-origin frame that follows its content height

## Scenario

A merchant pastes the inline snippet into a page on another site. The buyer sees the checkout in the page, and the frame grows and shrinks with the form, so there is no inner scroll bar.

Automated by `tests/playwright/regression/rt110-embed-inline-frame-follows-content-height.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_free` is configured for the target site.

## Steps

1. Open a host page with `<div data-ppcart-checkout="<free product permalink>">` and the loader.
2. Wait for the checkout form inside the iframe.
3. Tick and untick the required terms box inside the frame.
4. Complete a free order inside the frame.

## Expected result

1. The loader inserts one iframe with `title="Checkout"` and an `allow` attribute that contains `payment`.
2. The frame document is on the WordPress origin and the host page stays on `https://merchant.example`.
3. The iframe height is within 4px of the frame document height, and taller than the 480px start height.
4. After the terms message shows, the iframe is taller than before and still within 4px of the document.
5. On the receipt, the iframe is shorter than the form and within 4px of the document.

## Edge cases

- An inline frame below the fold keeps its old height until it scrolls into view. Chrome pauses rendering of an off-screen cross-origin frame.
