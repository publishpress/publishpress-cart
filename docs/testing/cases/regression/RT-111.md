# Free order inside the inline embed shows the receipt in the frame

## Scenario

The buyer completes a free order in the inline checkout. The receipt replaces the form inside the frame and the host page does not move.

Automated by `tests/playwright/regression/rt111-embed-inline-free-order-shows-receipt-in-frame.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_free` is configured for the target site.

## Steps

1. Open a host page with the inline snippet for the free product and the loader.
2. Fill the contact fields inside the frame, accept the terms, and click Order Now.

## Expected result

1. The order confirmation message (`ppcart-order-confirmation-message`) is visible inside the frame.
2. The frame URL is the product permalink with `ppcart-embed=1` and a numeric `ppcart-order`.
3. The frame body has the `ppcart-embed` class, so the receipt renders in the embed shell.
4. The top window URL is still the host page URL.

## Edge cases

- None.
