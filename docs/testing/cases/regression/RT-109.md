# ppcart_order_complete hook fires after completed order

## Scenario

ppcart_order_complete hook fires after completed order

## Steps

1. Add temporary test snippet/log listener for order complete hook.

2. Complete purchase.

3. Review captured hook data.

4. Compare with order record.

1. Hook fires once after completed order.

2. Hook data includes expected order/customer context.

3. Failed checkout does not fire completion hook.
