# Popup link on a page without the loader opens a working checkout page

## Scenario

The merchant uses the popup link on a page that does not load the loader. The link must still sell: it opens the embed checkout as a full page.

Automated by `tests/playwright/regression/rt114-embed-popup-link-without-loader-opens-checkout-page.spec.ts`. The host page is served from `https://merchant.example` through `page.route`, and its snippet loads `public/js/ppcart-embed.js` from the WordPress site.

The test is skipped unless `url_embed_product_free` is configured for the target site.

## Steps

1. Open a host page with only the popup link, without the loader.
2. Click the link.
3. Fill the contact fields, accept the terms, and click Order Now.

## Expected result

1. The browser goes to the product permalink with `ppcart-embed=popup`, and no dialog opens.
2. The page body has the `ppcart-embed` class.
3. The order completes: the URL has a numeric `ppcart-order` and the confirmation message is visible on the shop origin.

## Edge cases

- None.
