# An inline embed below the fold fits its content before it is scrolled into view

## Scenario

Chrome pauses rendering of an off-screen cross-origin frame, and with it
`ResizeObserver` and `requestAnimationFrame`. A sales page often places the
checkout below the fold. Its frame must report its real height anyway, so the
page does not jump when the buyer scrolls to it, and a Showit "Grow with
Content" section has the right height from the start.

## Steps

1. Open a host page at 1280x720 with 1600px of content above an inline embed of
   the free product.
2. Wait until the frame shows the form, without scrolling.

## Expected result

The embed is still below the fold, the iframe height matches the frame document
height within 4px, and the page scroll position is still 0.

## Edge cases

- Without the timer and `MutationObserver` in the frame bridge, the iframe kept
  its first height (797px for 678px of content) until it scrolled into view.
