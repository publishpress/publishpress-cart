# Purchase custom price Stripe checkout flow

## Scenario

Automated by `tests/playwright/regression/rt009-purchase-custom-price-stripe-checkout-flow.spec.ts`. This case documents what that test actually does; edit the test first, then regenerate.

The test is skipped unless `url_custom_price_stripe` is configured for the target site.

## Steps

1. Open the checkout page configured as `url_custom_price_stripe`.
2. Enter the custom price from `modify_price` and wait for the total to update.
3. Fill the checkout contact fields: first name, last name, a unique email, phone, and company.
4. Enter the Stripe test card details.
5. Click Order Now.

## Expected result

1. The browser lands on a URL carrying a `ppcart-order` id and the order confirmation message is visible.

## Edge cases

- None.
