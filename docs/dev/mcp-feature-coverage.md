# Cart MCP feature coverage

Native object permissions and active-edition requirements apply to every action. Registered schemas and field discovery describe accepted types and choices; list replacement semantics differ from object patches.

| Native area | Discovery and changes | Permission and scope |
| --- | --- | --- |
| Feature inventory | `list-features` | Requires a native Cart operation capability; lists scopes, related tools and edition boundaries without private record values. |
| General, currency, account page and email reports | `get-settings`, `update-settings` | `manage_options`; native sanitizers, booleans for checkboxes, string IDs for page selectors; live object choices and configuration locks. |
| Transactional email templates | Store settings actions | Native field allowlist and email HTML sanitization; effective defaults separated from stored/absent options. `send-test-email` uses synthetic customer data and configured test/admin recipients. |
| Payment methods | Store settings actions expose native enable switches, API mode, statement descriptor and related safe options | `manage_options`; `get-checkout-experience` / `set-checkout-experience` manage the combined selector; `get-service-setup` links to native credential authorization. |
| Product titles, content and publication | `list-records`, `get-record`, `create-record`, `update-record` | Native post-type creation/edit/publication and per-object capabilities; drafts by default, revision on edits. |
| General, plans, purchase restrictions, confirmation, email switches | `get-product-settings`, `update-product-settings`; `get-payment-plans`, `set-payment-plans` | Native product/collection editing permission, explicit field schemas and sanitizers. Hidden gateway IDs are preserved internally. |
| Additional Purchase Notifications | `get-product-notifications`, `set-product-notifications` | Native per-product edit capability; complete ordered rows, strict booleans/nulls, preview and revision; configuration does not send mail. |
| Categories and tags | `list-product-terms`, `create-product-term`, `update-product-term`, `get-product-terms`, `set-product-terms`, `get-product-term-deletion`, `delete-product-term` | Native taxonomy, term and related product checks; assignment validates all terms and preserves the other taxonomy. Deletion protects default terms and checks affected products and immediate children with a bounded scope. |
| Orders and subscriptions | Record actions, manual order/detail actions, native Stripe refresh, `refund-order`, `cancel-subscription`, `pause-subscription`, `resume-subscription` | Native record permissions and financial capability; amounts constrained to refundable balance, persisted gateway identity, preview and revision. Restocking checks product edit permission. |
| Monthly Overview | `get-monthly-overview` | Native manager capability plus edit-others/read-private permissions for aggregated record types. Native calculations. |
| Pro invoice, tax/VAT and extra email settings | Store settings actions | Actual Pro edition, native choices and configuration locks; no license or payment credentials. |
| Pro custom tax-rate table | `list-tax-rates`, `save-tax-rate`, `delete-tax-rate` | Actual Pro, `manage_options`; native formatting, integer priority and decimal-string percentage, table revision and local preview. Gateway metadata is never accepted or returned. Native local deletion; uncertain synchronization is not automatically retried. |
| Pro checkout presentation, quantity and shipping | Product settings actions | Active native modules and per-object editing; scalar controls and fixed shipping prices. `get-checkout-fields` / `set-checkout-fields` patch native default/address grids with presence-based flags. |
| Pro coupons, custom fields and additional bumps | `get-coupons`, `set-coupons`, `get-custom-fields`, `set-custom-fields`, `get-order-bumps`, `set-order-bumps` | Actual Pro and product/collection edit permission; exact native field types and validation of all rows before saving. Hidden IDs and password defaults excluded. |
| Pro collections | `get-collection-settings`, `update-collection-settings` and catalog record actions | Native collection permissions and each referenced product; one-time/free plans; product-derived pricing locks direct plan editing. |
| Pro upsells/downsell paths | `get-upsell-path-settings`, `update-upsell-path-settings` and catalog record actions | Native path permissions, published related products/pages and native plan references; six offer positions. |
| Pro upgrade paths | `get-upgrade-path-settings`, `update-upgrade-path-settings` and catalog record actions | Native path permissions; recurring plan references; list-valued filters remain arrays. |
| Blocks, shortcodes and checkout execution | Native editor and checkout | Catalog content can contain native markup. MCP does not run checkout, impersonate a customer or generate authenticated checkout links. |
| Secure downloads | `get-product-files`, `set-product-files`, `get-order-downloads`, `update-order-download`, `revoke-order-download` | Native secure-root attachment validation, upload/object/order permissions, Pro expiry/visibility, revisions and previews. `upload-product-file` accepts bounded base64 uploads with SHA-256 verification and native MIME checks. No bearer/source URLs. |
| Native integration rules | `get-product-integrations`, `set-product-integrations` | Settings plus product permissions, native active providers, typed rules and revisions. No rule execution, privileged role grants or secret authentication fields. |
| Pro branding and configuration CSV | Store settings; `export-pro-csv`, `import-pro-csv` | Native branding controls; bounded tax/coupon CSV, all-row preflight, revisions and explicit partial failures. Credentials remain in native authenticated setup. |
| Customer report CSV | `export-records-csv` | Native export/report capabilities and per-record read/edit access. Orders include customer/contact/address and purchase fields; subscriptions and contacts use fixed projections. Bounded pages, native filters and formula escaping; no credentials, bearer links or arbitrary custom fields. |
| Duplication and trash/delete | `get-catalog-lifecycle`, `update-catalog-lifecycle` | Native duplicator and catalog lifecycle, revisions, previews, taxonomy/object permissions and copied grant validation. Payment records are excluded. |

Preview validates the same input and permissions but makes no writes or gateway calls. Native gateway effects may outlive a local failure; inspect Cart and the provider before any retry. Action availability is not authorization: each executing service repeats native permission and dependency checks.

| Native area | Discovery and changes | Permission and scope |
| --- | --- | --- |
| Pro conditional confirmations and notification conditions | `get-confirmations`, `set-confirmations`; product-notification actions | Product editing, live native condition choices and related-object checks; complete positional rules. |
| Pro affiliate profiles and product eligibility | `list-affiliates`, `get-affiliate`, `create-affiliate`, `update-affiliate`, `delete-affiliate`; settings and product settings | Active module, settings/user visibility and related user/product permissions; immutable linked accounts. Deletion additionally requires `delete_users`, without deleting a WordPress account. |
| Pro affiliate commission configuration | `get-affiliate-commissions`, `set-affiliate-commissions`; affiliate coupon fields | Active module and product/settings permissions; native numeric/string/list representations, current plans and personalized affiliate coupon identifiers. |
| Pro affiliate financial reports and bookkeeping | `list-affiliate-payments`, `get-affiliate-payment`, `update-affiliate-payment`, `get-affiliate-statistics` | Native financial permissions and every contributing record/user/product; bounded scope, revisions and previews. Paid payout bookkeeping does not transfer funds. |
| Bundled extension activation | `get-extensions`, `set-extension` | Settings management, native installer and revision. Disabled-module configuration is rejected. |
| Credential setup, licenses, raw logs and secret maintenance | Native admin destinations | Credentials and raw diagnostics are not exposed as AI-readable records. |
