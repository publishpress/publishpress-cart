# FluentCRM

Do you use FluentCRM? The FluentCRM integration allows you to automatically add or remove new users to your email lists. You can integrate your account with [PublishPress Cart](https://publishpress.com/links/cart) by adding installing the plugin on your WordPress site.

**How To Integrate FluentCRM With [PublishPress Cart](https://publishpress.com/links/cart)**

Get started by Installing and Activating the FluentCRM Plugin on your WordPress site. Configure your settings and set up your email lists in FluentCRM.

From here you can set up a FluentCRM integration by going to a PublishPress Cart product and selecting “FluentCRM” from the services menu in the Integrations tab. You’ll see a List dropdown with all the email lists you previously created in FluentCRM. Choose the email list you would like to link to this product.

If you have created Tags with this list, select the name from Tags dropdown.

If you have created custom fields in Fluent CRM that you would like to fill with data from a PublishPress Cart order, you can add the Fluent custom field slug to the Contact Field Map along with PublishPress Cart corresponding Order Key or a Custom Field ID from your PublishPress Cart checkout form.

In the example below the following will occur from the settings chosen. When a product is purchased with any payment plan a contact is added to the ‘User Type 1’ list in FluentCRM. The Coupon Code that was used at checkout and the Product Name will be added to the contact details along with the default field information.

![](https://docs-media.publishpress.com/publishpress-cart/fluentcrm-integration-592a461738.webp)

Once you have finished filling out all the settings needed for your product, complete the order form by selecting Publish or Update.
