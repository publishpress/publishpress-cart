# Create an Upgrade Paths

Upgrade Paths is a feature that allow you to add Upgrade and Downgrade functionality to the account page. Here is the guide on how to create it:

- Go to **WP-admin > Cart > Upgrade Paths**, then click “Create Upgrade Paths”

![](https://docs-media.publishpress.com/publishpress-cart/create-upgrade-paths-754a4e84cb.webp)

- Then you will be redirected to this Upgrade Path screen:

![](https://docs-media.publishpress.com/publishpress-cart/upgrade-path-screen-678e14595c.webp)

- First you fill in the title, then enable it. You can choose to upgrade/downgrade **at the end of billing** or **immediately**.
- Next, you need to add the product and all the plans you want to added:

![](https://docs-media.publishpress.com/publishpress-cart/plan-on-upgrade-paths-c0441b9822.webp)

- After you are done, you can publish it.
- Whenever the customer on the account page, they will see “Change plans” button:

![](https://docs-media.publishpress.com/publishpress-cart/account-page-0a0d2b1673.webp)

- If it’s being clicked, it will show the 3 plans that you added on Upgrade Paths:

![](https://docs-media.publishpress.com/publishpress-cart/change-your-plan-e1784909306731-39c1c622a7.webp)
