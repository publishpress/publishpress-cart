# Customize Product Template

If you are using block themes, [PublishPress Cart](https://publishpress.com/links/cart) has built-in product template. You can access the template on **Appearance** > **Editor** > **Templates**

![](https://docs-media.publishpress.com/publishpress-cart/product-template-ff1775eb1b.webp)

You can make changes to the template here and it will automatically apply to all products from [PublishPress Cart](https://publishpress.com/links/cart).

When editing the template, make sure the Checkout block is set to **Dynamic Product** so it automatically adapts to each product. If you select a specific product instead, that product’s checkout will appear for all products

![](https://docs-media.publishpress.com/publishpress-cart/dynamic-product-a61bdf4c39.webp)
