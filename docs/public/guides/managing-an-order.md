# Managing an Order

In [PublishPress Cart](https://publishpress.com/links/cart), all of the order both one time payment or recurring will be recorded as Order, and it is saved in Orders menu. You can find it on **WP Admin > Cart > Orders:**

![](https://docs-media.publishpress.com/publishpress-cart/order-screen-c76695dcd0.webp)

In this screen, you will have overview screen of all of your orders, including the name, email, amount, products, and also the status.

If you open each of the order, you will get more detailed view on the order:

![](https://docs-media.publishpress.com/publishpress-cart/edit-order-screen-f470769459.webp)

Here are all detailed action that you can do on an order:

1. **Invoice:**Generate an invoice (unpaid) for the order.
2. **Receipt**: Generate an receipt (paid) for the order.
3. **Resend email**: Send a purchase confirmation email again to the customer.
4. **Edit details**: Allow you to edit the order details, including customer and billing details.
5. **Issue refund**: Send refund for that specific order.
