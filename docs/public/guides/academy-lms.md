# Academy LMS

Table of Contents

- [How To Integrate Academy LMS With PublishPress Cart](#0-toc-title)

Do you use Academy LMS? [PublishPress Cart](https://publishpress.com/links/cart) has direct integration for Academy LMS that allows you to automatically enroll or cancel new subscribers in a course. You can integrate it by installing the Academy LMS plugin on your WordPress site.

## How To Integrate Academy LMS With PublishPress Cart [#](#0-toc-title)

![](https://docs-media.publishpress.com/publishpress-cart/academy-lms-ec6cffdfe0.webp)

1. Make sure your website has installed and activated Academy LMS plugin.
2. If you have Academy LMS activated, when you create a product on [PublishPress Cart](https://publishpress.com/links/cart), you should be able to see it listed in the integration tab:

![](https://docs-media.publishpress.com/publishpress-cart/academy-lms-integration-product-067708d4da.webp)

There are 2 actions available:

- Add student to course

- Remove student from course
