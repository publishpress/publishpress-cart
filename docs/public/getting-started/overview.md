# Getting started

PublishPress Cart lets you sell digital and physical products from WordPress
without WooCommerce. Create products, embed checkout forms, and accept payments
through gateways such as Stripe and PayPal.

## Install the plugin

1. Install and activate **PublishPress Cart** from the WordPress Plugins screen.
2. Open **Cart → Settings** and configure your currency and payment
   gateway. See [Configuring settings](configuring-settings.md).
3. Create your first product under **Cart → Products**.

## Create a product

1. Go to **Cart → Products** and click **Add New**.
2. Enter a product name, price, and payment plan.
3. Configure the confirmation page and any integrations you need.
4. Copy the product shortcode and embed it on a page. See
   [Embed an order form anywhere](../products/embed-order-form.md).
